# 弱高音的相同幅度独奏补充

2026-11-10，在原83例已经开始运行、尚未全部结束时固定本补充；这是发现评价中的幅度混淆后的新实验，不伪装成最初的预注册。原83例的协议、输入和结果不修改。

原 `weak_high` 的高音增益是总 gain 的四分之一。因此，gain1 的弱高音不能直接与 gain1 单音比较后把差异归因于加入低音；高音分量本身也变小了。gain4 的弱高音则与 gain1 单音幅度相同，已有可用的配对独奏。

补充固定8个高音（48、60、72、84、96、67、79、66），使用已审计的16k源PCM、内部锚点1600、十秒输入、2秒目标锚点和增益0.25，各运行一次冻结ONNX。完整范围在补充推理前固定，不按哪组失败取子集。原模型、默认解码、±100ms锚点评分不改变，不训练或调门槛。

比较 gain1 弱叠奏与新 gain0.25 独奏，以及 gain4 弱叠奏与原 gain1 独奏。逐样本核对高音分量相同；添加低音引起的整体电平和上下文变化也是混音条件的一部分，不据此宣称具体神经机制。每个高音分别报告独奏/叠奏是否匹配、全部额外预测、onset/frame激活和音量身份。独奏也漏检的例子不能归因于只有叠奏才造成。仍保留低音检测及完整原83例结果。

本补充仅能说明固定钢琴、力度与构造混音的检测差异，不评价真实自然松键或LN，也不把控制分数当作应用收益。音频和逐事件数据保留在本地 `test-data`。
