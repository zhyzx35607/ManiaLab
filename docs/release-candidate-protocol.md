# 独立放手候选实验

2026-11-09，运行前记录。继续解决同曲长 LN 与跨歌曲表达，目标未完成。

上轮发现了两类无法由训练解决的候选缺口：小于100ms的短 LN，以及没有新起音的独立放手。本轮保留所有输入起音，将放手候选改为已知红线上的节拍位置与输入起音的并集。使用分段积分时钟处理变速；16拍视野，近处分辨率高、远处较稀，额外保留常见相对时值与最多32个原起音。相距3ms以内合并时优先保留原起音。候选不读取人工尾部、成品列号、书签或绿线，也不把转录物理音尾直接添加为答案。

每个端点带有来源与拍位特征。仅输入人工起音的社区任务仍不是听音；《樱花草》仍使用冻结检测草稿与作者 Timing。数据、歌曲分组、每组采样预算及训练24轮/适配80轮保持上轮协议，改变候选后必须重新准备数据。80ms以上音符和短LN分别统计，避免宽容差夸大很短条的准确性。

同时改正比较的边界盲点：额外报告“起点在评分段内的全部 LN”，即使预测尾部越出评分段也保留在分母。原先“完整落在片段内”的指标作为历史对照保留。校准按新的起点范围完整LN F1，仍用预设偏置 `[0, .5, 1, 1.5, 2]`、协调 `[0, .25, .5]`；所有候选和特征上下文必须位于校准范围内。

第一版继续使用原来的联合端点分布和整数投影，以单独观察候选扩展效果。不同时引入强制配额、人工长条提示或标签修正。之后若发现解码器偏差，另行记录对照，不覆盖失败实验。

固定20个社区比较片段已经被开发者查看过；此轮仍称开发比较。报告逐曲退步、候选上限、无新起音放手、两秒以上长条、原始起音不变量和无冲突导出。结果未经音乐验收不进入默认应用或正式 Release。
