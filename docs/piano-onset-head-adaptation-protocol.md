# 钢琴最终起音头的有界声学适配

2026-11-10，在本批 MAESTRO 首次声学前向和训练之前固定。目标是检验已有声学特征上的小规模监督更新能否减少漏采/多采。本轮只训练最终起音线性头，不是符号键型训练，也不宣称能恢复之前声学网络完全丢失的信息。

## 数据与时钟

- 数据源为已下载的 MAESTRO v3.0.0，selection SHA256 `34947943dcf11daf1b68939d005e05fd7331fe40413e575e70140a88248eb1aa`。沿用官方split和已固定的作品/年份选集：6 train、4 validation。另4份test仅保留名单，本轮准备/训练不下载、不读取。
- 每份输入原录音前180秒，44100Hz stereo int16 转 float32 双声道均值、除32768，再 `resample_poly(160,441)` 到16kHz。无需增益、归一化、乐器分离、拍线量化或MIDI拟合偏移。官方原配对同步作为实验假设；不从录音尾长推断offset。
- 每曲35个10秒窗，起点0,5,…,170秒；所有窗只属于原录音的split。首窗监督帧0:750，中间窗250:750，末窗250:1000，合并后恰好覆盖18000个100fps帧，每帧归属唯一。
- 训练监督前180秒；验证推理给足180秒上下文，起音评分仅前170秒，保留尾部10秒。完整保存所有预测；验证范围内起音的预测音尾越界也留在分母，分别报告不可观察的参考音尾。
- 旧SMD、Iowa控制、Nova《樱花草》都不训练、不用于选epoch。公共MAESTRO可能参与原模型预训练，年份隔离也不证明演奏者/钢琴身份独立，不能称对基础模型未知的盲测。

## 模型与缓存

固定Kong推理提交 `0226e74cbc805660e34bbd6a8fed2083890ebb88`、checkpoint SHA256 `c3fa9730725bf4a762f1c14bc80cd5986eacda01b026f5a4a2525cd607876141`。两个分支strict加载并逐tensor核验；全部模型eval，CPU两线程，无BN/dropout更新。

唯一训练对象是 `note_model.reg_onset_fc` 的88×512权重和88偏置，共45144参数。从原头复制到独立模块训练，其余模型状态保持冻结。每窗缓存该FC之前的512维 H、原 `frame_model` 的88维 F0，以及原7项输出和目标。hook只读、不更改上游输入。缓存原PCM、输入/源码/模型/标签hash和窗口时钟；不把增强输入与旧缓存混用。

每窗先做epoch0缓存重放：`sigmoid(fc(H))` 得到onset；重新执行完整窗 `frame_gru(cat(F0,onset.detach(),offset.detach())) -> frame_fc -> sigmoid`，其余输出取原缓存。全部7输出必须逐样本相同，并核验拼接与官方deframe相同。整曲原输出与重放输出的解码也必须一致。只有完整350窗验证通过才允许训练。缓存/重放不算新增独立音频。

改变onset数值会改变frame，即使其输入使用了detach。训练后不能复用旧最终frame，必须每窗重新计算双向GRU；记录frame变化与真实解码音尾变化。

## 标签与唯一配置

100fps帧 `t = window_start + j/100`，每pitch监督为 `max_onsets(max(0,1-|t-onset|/0.05))`。保留MIDI浮点起音，考虑窗外50ms内事件，不把越界pitch夹为21/108。此定义是精确物理距离三角目标；上游原标签函数在相邻起音中点附近存在residual引用差异，因此不称逐bit复制原训练标签。

固定seed42，float32，AdamW `lr=1e-5, weight_decay=1e-4`，梯度范数裁剪1，batch4窗，完整训练2个epoch，每轮固定seed生成的新排列覆盖全部210个训练窗。BCEWithLogits软目标，正负相同权重，仅上述归属帧计损失，分母为该batch有效帧数×88；没有额外正样本权重、阈值搜索、伪标签或数据增强。保存epoch0/1/2，全部报告，不在结果后增加epoch或更改配置。

## 验证、选择与后续

使用原默认解码门槛onset0.3、offset0.3、frame0.1、pedal offset0.2，无音高/时长过滤。按原同pitch50ms一对一最大匹配，另列40ms；逐曲报告precision/recall/F1、漏采与额外预测、同pitch紧邻真实重弹（按键空隙0–80ms）的双起音覆盖。按键和踏板延音的区间指标分别报告，均不是LN真值。

候选选轮只使用4份validation：50ms下每曲起音F1不低于epoch0，合并precision与recall不低于epoch0、额外预测不增加、各曲紧邻重弹双起音覆盖不减少，且合并踏板延音完整区间F1不低于epoch0。全部条件满足的候选按合并起音F1最高选取；同分优先epoch0，再优先较早epoch。epoch0始终可选。训练loss不作为效果或选轮依据。

若仍选epoch0，不读取test、不追着旧控制改参。本轮结束后重新判断是否需要更充分数据或训练更早声学层。若选到新epoch，先另行固定真实声源控制、旧SMD/Nova回归与未读取资料的核查计划，再判断产品可用性。本轮无论结果如何都不自动替换应用、不发Release。

运行中每窗/每轮保存身份与进度。中断后只能在相同身份下继续未完成缓存，不重跑已完成案例；失败日志及部分输出保留。原音、标签、特征和权重留在忽略目录，公开仅代码、方法与汇总。
