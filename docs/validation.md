## 已解决的问题与证据

- **BPM 小数与落线**：`210.00073 → 210`，保留常见分数；整理后固定 BPM 重新拟合整数 Offset。真实特殊小数若取整会漂移，展示精确候选。短键和 LN 两端完整量化，导出回读红线，最多允许 0.501ms 整数毫秒舍入。自动 Timing 不稳定时停止生成。
- **Offset 时间基准**：BASS / FFmpeg 同源解码对照未发现起始时钟差异。分析Timing输出前固定减 22.5ms；osu! 官方编辑器另有 20ms 波形视觉补偿。新项目将「制谱提前量」作为可见设置，默认 22.5ms，原始检测数据不变。反复切换时钟不累计舍入误差，过期的异步校准结果不能覆盖新输入。见 [调查记录](timing-investigation-165340.md)。
- **持续音与 LN**：实际运行四声部分离和逐声部音高模型；人声持续段可以跨音高，保留覆盖率与支撑音高。不用空闲轨道推导音乐尾音。起音与 LN 分别受全曲约束，显示目标、实际及可达比例，不靠删除短键达标。
- **6–10K 定轨**：连续搜索保存 LN 占轨和释放状态，按当地红线 BPM 评价变速图。严格重定轨保留全部原始时间、数量、类型、音效和 TimingPoints。小型学习先验仅在达到验证条件的 6K/7K/10K 启用，8K/9K 保留普通搜索。

固定 210 BPM，四声部证据重新拟合为 **93ms**，参考工具固定 210 也是 93ms。参考工具自动 209.998 BPM 时是 91ms，两组不同 BPM 下的结果不能混为同一个输入条件。

| 四声部 | 5,771 | 1,411 | 536 | 37.99% | 12,429ms | 1,947 / 0 |

## 真实音乐与定轨评价

[真实音频审计](audio-audit.md) 将原始采音、制谱时钟下采音、已知人工网格生成和完全自动 Timing 路径分别报告。人工谱面表示谱师取舍，不是所有可听声音的完整标注。自动失败、变速跳过、下载配对失败都保留；不将人工修正后的成绩称为自动成功。

[LN 起止对照](ln-audit.md) 单独检查长条的起点、尾端和持续区间，并区分默认设置与参考风格条件。当前匹配仍有明显差距，不能将候选更多或 LN 更长当作已解决音乐表达。原始配对来源、文件哈希与下载失败见 [audio-sources.json](audio-sources.json)。

[训练报告](training-report.md) 记录实际训练快照、分组、权重哈希与每个键数成绩。1790 份图参与轨道偏好训练；它只给可行轨道排打分，不决定声音或 LN 长度。10K 的验证 / 测试歌曲组为 7 / 6，规模仍小。

26 份真实片段（6K 5、7K 5、8K 3、9K 3、10K 10；每片约最多 1000 物件）的启用 / 关闭先验对照均保持物件不变量并通过结构检查；8K/9K 关闭先验时结果一致。10K 启用后合计少 1 次快速同轨，但峰值手压合计略升 0.086，不能宣布所有手感指标都改善。

原版 Mapperatorinator V32 在同曲前 60 秒完成 CPU 对照：约 669 秒，337 物件、45 LN，最长 LN 857ms。两引擎生成选择和密度不同，这份记录只能证明原模型实际运行过，不能据 LN 数量宣称全面超过它。

## 未完成的质量验收

尚未有另一台用户电脑上的 osu! 实际游玩验收、玩家盲评或独立人工音符 / 音尾标注。第三方大模型 API 只通过本地兼容协议测试，未使用真实供应商密钥。自动多段变速制谱、成熟的手工拖音编辑器和端到端 10K/LN 大模型训练仍未完成。

源码审计、单位测试和可运行的便携包证明程序行为可以检查；它们不能证明输出已经达到成熟谱师或全面超过 Mapperatorinator 的音乐质量。
