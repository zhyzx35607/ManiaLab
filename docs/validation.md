# 验证记录

测试环境：Windows 10 x64、Python 3.12.10、Intel i5-9600K、CPU 推理。记录日期：2026-11-07。

## 自动化测试

`python -m pytest -q`：25 项通过。

- 6 / 7 / 8 / 9 / 10K `.osu` 读写与严格重定轨；逐物件检查起止、类型、音效字段，并保持原始 TimingPoints。
- 同轨 LN / 短键冲突、重复起音、超过键数的同时占轨会失败；没有静默删音或缩短。
- 300 个随机间隔物件的可行定轨，跨局部重写边界的锁定 LN。
- LN 不超过检测候选的原始结束时间，`ln_ratio=0` 输出短键。
- 实际 Basic Pitch ONNX 在 30 秒合成信号上的 5 个持续音，跨 19 个推理窗口。匹配音高，起点误差小于 120ms、终点误差小于 180ms；释放瞬间不重复计为新瞬态。
- 静音、ZIP 路径越界、CSRF / Origin / Host 限制、API 参数越界和本地 HTTP 模拟服务。

合成信号通过不能推断真实混音准确率；本次没有对完整真实歌曲做听音质量验收。

## 浏览器和独立程序

用 Edge / Playwright 走通真实页面：上传音频、分析、生成、检查 LN 统计、下载 `.osz`、切换证据视图、导入原谱并重新定轨。没有捕获到页面脚本异常；390px 宽度未出现横向溢出。源码运行与第一轮 PyInstaller 独立 EXE 均已完成这一流程。

开发时可复跑：

```powershell
npm install --prefix test-data/ui --no-save --package-lock=false playwright@1.56.1
# 先在 tests/artifacts/ 准备 synthetic.wav 和 public-maps/5900981.osu，或修改脚本为自己的素材。
$env:MANIALAB_URL='http://127.0.0.1:8976'
node scripts/ui_smoke.cjs
```

测试脚本依赖本机 Edge 路径；不随应用自动运行，也不要求最终用户安装 Node。

## 原模型集成

可选安装器已在隔离环境安装 CPU PyTorch / torchaudio 2.9.1 和上游推理依赖，下载固定 revision 的 V32 `gamemode=3` 权重。通过上游实际 `inference.py` 在 CPU 上完成 8 秒合成片段的 timing / map / SV 生成，导出后通过新定轨器回读检查。

这次原模型输出只有 1 个完整 LN，并报告片段末端的另一条 LN 没有配对结束事件。上游会丢弃该不完整 LN；ManiaLab 会保留并展示原模型警告。该结果证明原模型入口能运行，**不证明制谱质量足够好**，也说明“原模型权重接入”和“改善 LN 理解”是两项不同的工作。

真实第三方 LLM 服务未用实际密钥测试；当前只完成兼容协议与模拟服务测试。尚未在另一台无开发环境的电脑或 osu! 客户端中进行实际游玩验收。
