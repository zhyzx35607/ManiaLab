# alpha.6 dev.2 便携验证

2026-11-09。本次验证对象是实际`ManiaLab.exe`，机器记录见[完整验证JSON](alpha6-dev2-validation.json)，使用方法见[测试说明](alpha6-dev2-guide.md)。这是开发测试版本；这些结果证明列出的工程流程可运行，不证明已经达到作者制谱水平。

- 全量363项测试通过，44.89秒。
- 打包源码、音频程序及钢琴模型哈希校验通过；构建阶段拒绝未记录来源、源码变更或程序哈希不符的音频worker。
- 清理Python相关环境和PATH，以不可用代理阻止下载，在中文数据目录启动真实EXE。四声部分离分析56.37秒，六声部分离分析74.15秒。
- 6–10K生成、实际`.osu`回读、无同轨冲突和完整落线检查通过。可控五个持续音在五种键数下均保留五个LN。
- 本地编排建议、过期BPM拒绝、试听和波形、`.osz`、项目重开、取消任务、坏音频失败后服务继续可用均通过。
- 真实SMD Bach钢琴前12秒以已有声轨导入，包内专用模型冷分析17.72秒、44候选；重启后的缓存分析1.26秒、候选逐项一致。模型默认关闭。
- 手动连续起音表达44物件/11LN，切回持续表达43物件/30LN；原始采音不变，手动方案及候选重开后保留。这一导出检查明确使用固定120 BPM格线，不据此声称正确找到了演奏Timing或改善了音乐效果。
- 主程序关闭后，正在运行的音频worker在10秒等待期限内退出。

旧包音频EXE与本次构建EXE的SHA256相同；时间戳不足以判定程序陈旧。新增校验使以后能直接核对源码与可执行文件身份。浮点音频输入的修复由更新后的主应用路径提供。

源码研究的YourMT3伴奏模型、没有通过对照的训练权重，以及测试歌曲、参考谱与SMD录音均不随包分发。11首SMD与《樱花草》的表达研究保留失败和退步，详见[完整比较](articulated-expression-research.md)。
