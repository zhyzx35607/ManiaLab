# 段内固定节奏骨架对照

2026-11-11。在读取本轮生成结果前固定方案。精度对照后，持续覆盖奖励
仍会挤掉整组钢琴或鼓；现有组只能保留整段起音顺序或完全放弃，没有显式
的较简节奏。此研究检查这一能力，不把半数采音自动认定为正确伴奏。

范围为已确认恒速拍格下，某段、某来源、某模型类别共同遵守的整数tick
子集。原完整起音先分组，再保留 `tick % stride == phase` 的整个起音行，
之后由原和弦层数和容量约束选择。保留原两拍source group边界；原本容量
不可能的组在简化后可能无需拆成逐起音family，这不等于最终family完全
不变。被省略时刻的局部容量检查仍保留。每段规则固定，段边缘和两拍组首均不
重置相位；原Offset、BPM、制谱提前和LN首尾不改变。不补最强音来填空组。
保留音的收益只能来自保留音本身，被删起音不借分给剩余音，也不算被LN
表达。省略原因单列`rhythm_policy_omitted`，与容量落选、降和弦分开。

这轮不引入自动伴奏身份。`support`、段落相似组、起音分组都不足以证明
重复伴奏；主旋律、独奏、插奏和切分可能被固定拍格破坏。因此功能只作
显式研究参数，默认无策略；不组合尚未验证的相邻组连贯惩罚。

固定验证：

1. 合成反例：同段钢琴四分之一拍起音与持续贝斯竞争；完整钢琴组只能整体
   落选时，半拍子集能否按同一相位和原LN共存。独奏、偏移、三连网格、
   分段、空组和多音高行均有控制。验证实际起音价值，不能继承删音奖励。
2. 原《樱花草》冻结候选、人工74 BPM/178ms/四细分/提前22.5ms不变，
   两种覆盖权重0和0.25、全部6–10K。每个键数和权重先跑完整方案，再跑
   两种相位；全部方案预先固定。首先无策略重放全部10组，与
   `expression-precision-v1`逐Note/逐定轨/决策比较。
3. 所有有钢琴候选的段内scope固定stride=2，分别以phase=0和phase=1做
   全曲独立对照，两种相位都报告，不按目标值挑“最好”。不改其他声部。
   这是两个诊断性对照，不能声称整曲钢琴适合半拍简化。
4. 保存每段候选起音、策略允许/省略、实际选中/容量省略、连续省略串和
   两个被选起音之间的间隔；本轮不新增原声窗口，既有音频审阅目录不等于
   本轮已完成试听。
   重点关注钢琴稀疏是否牺牲独奏/插奏，而不是只报其他声部多了多少LN。
5. 输入哈希、源码快照、完整decisions、逐音变化、求解状态与时间、容量、
   落线、osu回读均保存到新的ignored目录。无新推理、标签读取或训练。

即使结构验证通过，也不能自动打开应用默认。是否连贯和符合听觉，仍需
原声、段落与实际生成内容对照。固定相位一致不保证容量竞争后的起音连续。
