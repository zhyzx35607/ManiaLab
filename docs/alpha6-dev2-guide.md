# alpha.6 dev.2 对照测试版

本版把已经实现的声轨导入、可选钢琴采音和逐段表达带入便携包，方便换一台电脑比较。对音、鼓音细分、声音流归属和LN音乐设计仍需继续改进，不称完整制谱已验收。

## 建议测试顺序

1. 完整解压后启动`ManiaLab.exe`，导入原曲。
2. 有Nova分离轨时，导入从同一原曲起点导出的声轨，并标记鼓、贝斯、钢琴等声部；不要剪去每个声轨开头的静音。可以只导入部分乐器。
3. 对独立钢琴轨，可选择“钢琴专用采音（测试）”。该项默认关闭，只在六声部分离或已有钢琴声轨模式中生效，便携包已经包含所需模型。
4. 先单独试听乐器、检查原始起音和持续，再核对BPM、Offset、制谱提前量。不应靠量化把错误采音伪装成正确。
5. 在“先规划音乐 → 段落与声部表达”检查段落。为每段指定主声部，并分别选择各乐器用持续音、起音或不采。
6. 钢琴连续起音被拖尾铺满时，可试“连续起音优先，组尾可延长”，保存后重新生成，并与“持续音用LN”比较。它是表达规则，不是手指松键检测；可能把同一钢琴声轨中的不同旋律流混为一组。
7. 生成6–10K候选并导出`.osz`。程序检查同轨冲突和落线，实际听感和游玩仍需比较。

## 本版变化和范围

- 已有声轨保持原曲时钟；浮点音频不再错误缩小幅度，缓存身份包含输入及分离流程。
- 可选钢琴模型给出独立起音、持续和音尾来源。模型截断、未决尾不能自动作为LN放手。
- 容量不足的复音和弦允许减层保留起音，减少整组省略。
- “连续起音优先”只在手动选择时使用。新自动活动/长短建议出现过鼓保留退步，未替换默认规则。
- 构建校验音频程序源码、程序哈希及可选钢琴模型，避免新应用附带旧音频程序。
- YourMT3伴奏转录和未通过比较的训练权重仍在研究阶段，没有进入这个包。

《樱花草》只用于参考声部分工、段落和表达思路。作者也可能有错漏，不要求逐音符一致。参考指标和LN数量均不能替代声音与音乐判断。

已知限制与实验结果见[音乐质量目标](music-quality-target.md)、[真实钢琴研究](piano-acoustic-research.md)、[起音与持续表达比较](articulated-expression-research.md)及[伴奏转录研究](accompaniment-transcription-research.md)。此轮桌面自动化初始化报路径错误，未完成新版界面视觉检查；便携程序验证另附Release验证文件，不把API测试写成界面验收。
