# Nova鼓轨再分离：LarsNet冻结模型实验

2026-11-09，推理及评分之前记录。前面的局部模板没有改善作者事件F1，不能将更多检测等同于更好采音。此次改为先分出可单独试听的kick、snare、toms、hihat、cymbals，再检查起音；不使用谱面来生成分离声轨。

来源是作者仓库`https://github.com/polimi-ispl/larsnet`，固定提交`17d631fd18e77ee2f1d23ee7b3fc0fb46ae629e2`，README所链接的官方Google Drive预训练包。模型许可证为CC BY-NC 4.0，仅本地研究，不进入发行包。权重压缩包、各检查点、源码、配置均记录哈希；使用`torch.load(weights_only=True)`并严格加载全部参数。

输入为已确认的Nova原鼓MP3，用FFmpeg解码为原幅度44.1kHz双声道float32，保存源身份。不使用有削波的试听文件，不从22.05kHz单声道反采样假装原始立体声。采用默认非Wiener版本，避免观察结果后在多变体之间挑选。

直接使用上游UNet、STFT、掩码及逆变换。为限制内存，只改变模型批大小：同一全曲STFT按上游512帧的固定折叠分块，逐块运行网络，再按原顺序展开。首个模型在前两个块对照整批与逐块的输出，最大差异不得超过1e-5绝对误差加1e-4相对误差；不拼接单独解码的小音频，以免新增时钟边界。音源不接收作者BPM、Timing、书签或事件。输出保留float、不归一化、不截断。

预定检查：声轨有限值、样本长度相同、5类全部保存；将每条分离轨分别重采样至应用22.05kHz，使用原`rhythmic_evidence(estimate=False)`采起音，不为此曲改阈值。原始起音与统一减22.5ms的作者对照分开保留。第4列严格hihat以及hihat+toms/cymbals诊断分别报告，不挑较高者冒称纯音色准确率。还要检查声轨串音、分离残留产生的假起音与漏音，Reference并不是完整物理转录。

如果物理音色证据改善，也不能自动把所有事件写成note，仍需独立学习乐段选择及层数。没有新歌曲验证、实际试听对照和完整成品验收之前，不默认启用。
