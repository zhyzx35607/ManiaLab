# ADT事件语法对照

2026-11-09，完整原模型运行中，尚未检查谱面评分。第4/5块的64-token诊断发现第4块连续重复相同时间、kick和速度，未给EOS；第5块正常结束。这解释了原512-token推理的长耗时，不是复杂音乐分析的证据。诊断原token保留。

新增第二项独立实验，固定相同模型、音频和2.56秒分块。只限制事件类型顺序、片段内0–2.55秒时间、时间非递减、项目26类音色、0–127力度，以及同一10ms时间同一鼓类不重复；不同鼓同刻发声、下一10ms同鼓重击都允许。EOS仅在完整事件后可选，首事件可为空或silence。始终选择原logit里最高的合法token，不读取谱面、节拍、期望数量或人工分类，不补音、不对输出拍线吸附。

两种结果均保留；语法合法不代表采音正确。对完整序列独立严格解析，并与官方decode比较每个起音/类别/力度，禁止zip把不完整三元组错配。若任何块达到原512-token上限仍未结束，保留失败，不强补EOS冒充成功。报告音色匹配、漏音、所有类别数量和总音数，不能仅以重复少或速度快宣称改善。
