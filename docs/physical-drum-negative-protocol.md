# 用单独鼓录音消除音色共现捷径

2026-11-09，第二轮训练之前记录。第一轮从零训练的物理模型在保留集kick F1约0.964、snare约0.807，hi-hat在真实MDB录音只有0.541。事后错例诊断显示许多假hi-hat与kick、snare、镲片重合；这支持检验共现捷径，但并没有证明其唯一原因。

只添加第一轮IDMT拟合记录对应的`#KD#train.wav`、`#SD#train.wav`、`#HH#train.wav`。这些文件由原数据集作为该乐器的训练录音提供，但没有对应独奏起音标注。因此**不使用检测器生成伪真值**：已知单一类别的整个时间轴标记为未知（不参与损失），另外两个未出现类别监督为0。原混合录音保留原物理起音标签和全部三个已知类别。负例仅使用原拟合音色组，校准与测试音频、标签逐项不变。

保留原混合训练集的归一化统计、同一75,267参数时间卷积模型、seed42、30轮、Adam0.0003、正例权重10及峰值规则。损失只对有效时间中已知标签求平均，未知标签梯度必须为零；训练前验证全已知时与原损失相同。训练例增加导致每轮更新数增加，这不是严格等更新次数的单变量比较，报告该限制。只用原4条校准BCE选epoch，再用校准F1选阈值；不按测试或《樱花草》选模型。

第一轮已读取71条测试结果并用于诊断，第二轮将这些记录称为**固定开发回归集**，不能再包装成全新盲测；需要另找真正未用过的录音做最后验证。无论回归分数怎样，均不直接默认启用。训练不使用用户Reference，也不学习人工制谱取舍、LN或定轨。
