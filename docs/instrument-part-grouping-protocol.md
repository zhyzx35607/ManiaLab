# 同类别不同演奏声部的补充检查

2026-11-11，在35份音色推理运行到铜管输入、尚未读取本轮逐音参考或分类
成绩时固定。准备脚本表明URMP标签保存了原始`part`，可区分两把小提琴，
因此补查“广义类别正确，但声部被混组”的情况。没有新增推理、训练或调参。

使用相同0–30秒窗口，按原起音50ms及相同音高建立全部候选对应关系。
只有参考音恰好对应一个预测、该预测也恰好对应一个参考时，才纳入声部分组
诊断。不得用模型类别、聚类或参考part打破同音重叠的歧义。
未检出、无参考对应、歧义及独立对应覆盖率全部报告，不能把只含易对应音的
结果称为完整聚类准确率。原35份分类成绩仍使用全部音，分母不变。

在同一份录音的可对应子集内，计算属于同一真实part的音符对数、属于同一
预测组的对数，以及同时满足二者的对数。分别给出成对precision、recall和F1，
分母为零记为不可计算。比较原类别、逐音新类别、聚类后类别及音色cluster；
最后两者不同，多个音色cluster可能仍被命名为同一类别。

这些指标仅评价该子集的声部聚合；检测是否正确、音尾是否合适及LN表达仍
需单独检查。独奏与混奏分别汇总，不跨录音构造音符对，不把公开重复演奏
当作独立测试样本。不会为了增加一致性而给全部音符统一命名或改写起止。

离线入口为`scripts/audit_instrument_refinement.py`，同时独立复算原分类
匹配计数、保存logits下的聚类类别和查询覆盖。它不会重新推理或改变原分组。
