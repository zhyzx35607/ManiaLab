# 小型定轨先验 · alpha.4

这是固定起止时间下的轨道候选打分模型，不是音频转录器、LN 长度模型或完整 10K 制谱模型。

## 数据与划分

公开数据来自 `project-riz/osu-beatmaps`，固定 revision `b82117a5de13b7df5290482aed7cffc49cb76e6d`，另补充 osu! 公开 ranked/loved 谱师图。原始谱面、音频和下载缓存不公开再分发。

本轮训练快照筛选出 2,078 份图；按歌曲组最多 5,000 对样本限额后，实际使用 1790 份图。只用原生 6–10K；验证轨道冲突、文件哈希、重复、Inverse 标签与手布局。10K 排除标明 4+6K 的图，8K 排除标明 7+1 / IIDX 的图。标签无法识别所有未标注转换，仍是数据限制。

歌曲名、谱包 ID、音频哈希通过并查集合并后分割，避免同曲多个难度跨集合。元数据缺失、不同标注的同一歌曲仍可能漏合并。用户个人谱面没有加入此训练快照。

## 模型与指标

101 个特征描述当前和弦、每轨 LN 占用、释放时间及两排历史。64/32 隐藏层 MLP，pairwise softplus，按键数均衡批次和镜像增强，固定随机种子 20261107。验证损失选第 23 轮，NumPy 导出最大数值误差 1.1920928955078125e-05。

**准确率的含义**：给定人工谱面的历史状态，是否给人工当前排高于一个随机可行替代排的分数。它不是生成谱面的好评率，不能表示玩家偏好或音乐性。

| 键数 | 训练/验证/测试歌曲组 | 验证准确率 | 测试准确率 | 默认启用 |
|---|---|---|---|---|
| 6K | 78/9/6 | 76.8% | 78.9% | 是 |
| 7K | 316/36/40 | 78.2% | 76.7% | 是 |
| 8K | 32/2/1 | 71.3% | 64.6% | 否 |
| 9K | 20/2/1 | 77.5% | 58.4% | 否 |
| 10K | 40/7/6 | 72.3% | 71.8% | 是 |

启用门槛：至少 8 个训练歌曲组、3 个验证歌曲组、验证准确率 ≥60%。8K/9K 只有 2 个验证组和 1 个测试组，因此保留普通连续搜索、关闭学习先验。9K 测试成绩也提示明显泛化风险。门槛在开发过程中曾调整，本报告不能当作预注册盲测。

本轮开发查看过之前模型的验证与测试结果；这是迭代后的报告，不声称从未见过的独立测试。扩大语料还会改变并查集分组，不能把不同快照的百分点变化直接归功于模型。

## 生成中的使用

默认强度 0.35，分数差经 tanh 限幅；物理占轨、时间不变量及手感代价始终优先。学习先验可关闭。完整重定轨对照另见验证记录；结构通过不证明每一种键型更好。

模型 SHA256：`0245b1cce5a08dc1650b911eea6c26905e2cb423fcb6bb89bf8320ac0c1e1a10`。训练清单 SHA256：`58c4e82082d0e1ad88bfb50b02aa3c61b17e8cad5aba2c58a1b2d16439d6d3ca`。逐谱 ID、哈希、匿名歌曲组及划分见 `training-report.json`。

复现：先用 `collect_corpus.py` / `collect_author_corpus.py` 收集固定来源并核验，再使用 `train_layout_network.py`。当前本地语料仍继续扩大；若不按此报告的逐谱哈希恢复快照，新训练不是同一实验。
