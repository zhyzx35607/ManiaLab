# alpha.4 下载包核验与资源观测

公开包为 `ManiaLab-0.1.0-alpha.4-windows-x64.zip`，644,726,038 字节，源码提交 `fcafd949686daa283b1ad094ffc3c10ef851d061`。发布后从公开地址匿名完整下载，SHA256 与本地发布包一致：

```text
4faede8993471ac6c418089149ad29b2371e82af5a1395ab0ed20d2f04566ff1
```

ZIP CRC、包内 EXE、音频 worker、轨道权重和界面文件标记均核对。完整 Windows [CI 42409431833](https://github.com/zhyzx35607/ManiaLab/actions/runs/42409431833) 通过；中文加空格安装目录也通过深度分析、全部键数生成/导出、恢复、取消和坏音频恢复。机器可读记录见 [release-verification.json](release-verification.json)。

随后再次使用匿名下载并解压的 EXE，观测资源占用。环境是 Intel Core i5-9600K、Windows 10、32 GiB RAM，CPU 分析，未启动浏览器；其他本机任务仍存在。下表是单次观测，不是最低配置、速度承诺或版本加速比较。

| 输入 | 首次深度分析 | 缓存分析 | 峰值进程树专用内存 | 项目磁盘占用 |
|---|---:|---:|---:|---:|
| 用户 235.20 秒 MP3 | 141.39 秒 | 8.09 秒 | 3.31 GiB | 173 MiB |
| 20 分钟原创合成音 | 641.52 秒 | 28.27 秒 | 5.78 GiB | 884 MiB |

专用内存与工作集不是同一个指标；这里每 250ms 采样主进程及子进程的 Windows 专用内存，峰值仍可能落在采样间隔内。原始报告同时保留工作集数据。用户短曲磁盘统计在生成前，长曲统计在生成后。

20 分钟输入由已有原创 40 秒复音样例重复 30 次组成，验证容量与时间轴，不能用于宣称自然歌曲质量。它生成 5882 物件、3235 LN，全部 9117 端点落线；生成和导出用时 24.34 秒。浏览器实际打开保存项目，跳转 1/600/1190 秒、切换谱面和采音证据、读取末尾波形并下载 `.osu`，没有页面异常或窄屏溢出。

详细记录见 [resource-profile.json](resource-profile.json)、[long-duration-validation.json](long-duration-validation.json)。开发者可以用 `profile_portable.py` 复测自己音源的资源使用，输出目录含私人音频和项目，应留在本地。

这些补充工具与研究报告晚于 alpha.4 标签；它们没有改变已经发布的应用或 ZIP。发布版 126 项功能测试与后续四项评估工具测试分别记录。
