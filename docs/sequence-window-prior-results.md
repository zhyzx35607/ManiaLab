# 四排序列先验评估结果

日期：2026-11-11

## 范围

模型在作者谱面里抽出的四排窗口上学习轨道偏好。每个窗口固定音符、起音和
LN尾端，只比较作者布局与满足同轨占用约束的替代布局。本评估不生成新音符，
也不预测LN长度、声部或采音。

训练语料包含7,907张6–10K Ranked/Loved谱；《樱花草》及对应Reference没有进入
训练、验证或测试。模型于第20轮按验证集选择，训练时使用2个CPU算子线程、
1个跨算子线程；导出网络与训练网络最大绝对误差为`2.29e-5`。权重、全量缓存
和原始报告留在ignored的`test-data`目录，不进入公开源码。

逐窗口10K测试的7,672个排序对准确率为77.05%；LN为75.13%，tap为78.57%。
主要结果再按独立歌曲组等权聚合，降低歌曲内多难度图重复出现对指标的影响。
区间通过固定seed `20261112` 对歌曲组进行5,000次percentile bootstrap计算。
二分类排序机会水平为50%，不代表现有runtime prior的A/B基线。

## 解释与限制

- 模型在独立歌曲组上高于50%机会水平，说明语料中的作者轨道布局含有可学习的
  局部偏好；这是继续做整谱对照的依据，不是成品质量证明。
- 参考布局与负例只涉及轨道分配。采音、事件密度、段落角色、LN起止均未由该
  排序任务判断；模型不能决定何时做LN、LN应持续多久或放手是否合适。
- 四排窗口训练格式`sequence-window-v1`与当前`manialab.pattern_prior`运行时
  格式及特征不同，权重尚未接入生成器。
- 局部窗口测试结果不等于整谱收益。接入前要检查beam状态中所有未来评分所需的
  历史字段，随后使用冻结的候选音符运行同输入整谱A/B，检查LN协调、放手、
  反键、重复声部连贯性、手部负担、耗时及`.osu`回读。
- 《樱花草》应按共同bookmark检查段落和声部表达，不把Reference当作逐音真值；
  最终仍需实际游玩验收。

## 复现

全量训练：

```powershell
.\.venv-audio\Scripts\python.exe scripts\train_sequence_prior.py --threads 2 --cache test-data/corpus-expanded/sequence-window-cache-v3 --output test-data/sequence-prior-v1
```

10K歌曲组主评估：

```powershell
.\.venv\Scripts\python.exe scripts/evaluate_sequence_prior_groups.py --output test-data/sequence-prior-group-eval-v1.json
```

6–10K附录：

```powershell
.\.venv\Scripts\python.exe scripts/evaluate_sequence_prior_groups.py --keys 6 7 8 9 10 --output test-data/sequence-prior-group-eval-6-10-v1.json
```

评估入口会校验模型、训练报告和v3缓存的schema及manifest，再根据每图采样记录复现
歌曲组预算抽样。所有预测、权重和评估JSON均为本地ignored产物；公开仓库只包含
评估代码、测试及本结果说明。
