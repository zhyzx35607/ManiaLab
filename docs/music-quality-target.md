# 音乐质量目标与参考谱的用途

2026-11-09，按用户补充意见修订：尽量接近《樱花草》的声部清晰度和表达效果，不要求逐音符复刻。作者也可能有错音或漏音，Reference 和成品都不是绝对正确答案。

## 先判断声音，再判断表达

1. **采音**：先在原始混音和实际分离声轨中定位起音、重复触发、持续和中断。分离串音、混响和模型强制截断要保留来源记录。具备独立 MIDI 起止的录音用于物理采音测试；人工谱不充当完整物理标签。
2. **声部与段落**：同一乐句内选取的乐器、起音密度和长短表达要有连贯规则。副歌换主声部可以合理；没有声音或乐句变化依据的短键/LN反复切换需要检查。重复段落可以变化，但应能说明变化来自配器、强度或难度安排。
3. **LN 表达**：物理延音、乐句覆盖和配合其他声部放手是不同的依据。不能把踏板延音直接当手指松键，也不能要求所有长条只等于一个乐器的物理持续时间。需要检查遮住重新起音、穿过明显停顿、无依据延长、放手拥挤等问题。
4. **演奏**：在保留音乐表达的前提下检查6–10K布局、双手负担、LN占轨、反键与放手后的重新按下。没有同轨冲突只是结构要求，不证明手感好；也不以绝对消灭连打或左右完全相等为目标。

## 如何使用《樱花草》

用户确认的列含义用于理解声部：1列主要kick，2/3列snare且可双押，4列主要hi-hat并有tom等例外，5/6列钢琴，7–10列其他伴奏；Reference不采人声。这不是其他歌曲必须照抄的分列模板。

与参考谱的差异应分成：检测分歧、分离输入分歧、表达取舍差异，以及仍需检查的情况。多检测一个音高不自动算误检，少放一个note也不自动算漏音；先看声音是否存在，再看难度和本段策略是否要求表达。

参考起音/放手匹配分数只用于定位差异。不能为了追分而删掉有声学依据的音、添加没有依据的音，或记住单首歌的时间位置。历史匹配表保留原值，但不将低匹配单独作为音乐失败结论，也不将高匹配称为完成度。

## 后续比较

同时保留声音检测结果、段落取舍记录和最终谱面，区分错误来自哪一层。比较开头、中间、结尾及重复段落，保留有改善和退步的歌曲。模型选择依据适用声音及独立对照；最终仍要结合试听和实际试打，而不是只看训练loss、LN比例或某张谱的匹配率。
