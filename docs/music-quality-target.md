# 音乐质量目标

ManiaLab 的长期目标是让 6–10K 谱面听起来来源清楚、声部与段落表达连贯、长条（LN）收放合理，并在 osu! 中具有可演奏的手感。10K 和 10K LN 是重点场景。

## 验收顺序

1. **采音**：回听原混音和可用声轨，区分真实起音、重复触发、混响、串音与模型截断。自动检测数量或模型置信度不能代替声学依据。
2. **声部与段落**：检查同一乐句的主次关系、密度和表达是否连贯。允许为了难度舍弃候选，但应保留“未选择”与“未检测”的区别。
3. **LN**：结合可听的持续、重新起音、停顿和手势放手判断；不能把踏板尾音或模型截断直接当成玩家的按放动作。
4. **演奏**：在保持音乐表达的条件下检查键型、双手负担、LN 占轨、快速接续和实际 6–10K 手感。

## 参考谱

参考谱用于定位差异和理解表达思路，不是绝对真值，也不要求逐音符复刻。多一个或少一个物件都需要结合声音、段落策略和演奏目标判断；匹配率、音符数、`pytest` 通过或合成音频测试都不能单独证明音乐质量。

## 证据边界

工程回归、模型身份和便携包验证应分别记录为软件验证，不得表述为采音或游戏手感已验收。真实歌曲的试听、Timing 复核和 osu! 实打仍由人类作最终判断；没有回收的反馈要明确标记为待验收。
