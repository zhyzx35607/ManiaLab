# 相邻节奏组连贯取舍对照

2026-11-11，在运行真实输入前固定。目标是减少同一段内相邻节奏组轮流落选，
不把乐器类别稳定、LN增多或这个目标函数的分数提高当作音乐验收。

原选择器两拍一组，组间没有连贯项。实验对同段、同声轨、同模型类别、同角色
的相邻音高组建立联系，组间起音间隙不超过既有的1.25拍分组边界；跨段、跨类、
长间隙和局部参数边界不连接，鼓瞬态不参加。联系是节奏取舍假设，不是物理
持续、独立乐器或旋律身份。

两个组都选或都不选时无额外得分。只有一个被选时，扣除固定权重0.25乘
两组中较小的保守单起音价值。每个起音先取该组候选的最低价值，再对组内
起音求平均；不让落选的高分和弦音把连贯权重借给低分代表，不奖励增加和弦
层数。邻接两端最多扣除约半个起音价值，明确的证据优势仍可胜出。现有密度、
占轨、持条和音尾约束保持；不造新音、不连接音尾。

输入采用已完成PR15的 `test-data/chord-evidence-ties-v1`；先在默认关闭
实验的路径上逐音复现该基线，再以同候选、同方案、同人工时钟重放0.25版本。
完整运行6–10K，不以部分键数或某几个有利片段代替。原三个选窗16–24、96–104、
200–208秒全部保存新旧取舍。不得针对它们调整权重、阈值、密度或Timing。

保存新增/移除的候选和声部起音、LN变化、求解状态、取舍转换及总代价。
原组间转换指标只验证实现作用，不是独立音乐指标。检查默认不变、端点来源、
代表关系、完整容量与实际谱面回读；保留所有退步和求解间隙。
