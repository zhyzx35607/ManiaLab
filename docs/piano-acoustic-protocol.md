# 自然钢琴起止对照协议

2026-11-09，在本批音频推理与评分之前固定。此项补充作者《樱花草》的取音参考，不用人工谱面的省略代替物理漏音真值。

来源为 Saarland Music Data v2，Zenodo 固定记录 13753319（概念记录 10847280）。使用 `SMD-piano_v2.zip` 中真实录音的 `wav_22050_mono` 与同名 MIDI/CSV，不使用 `midi_wav_22050_mono` 合成音。元数据在本地保存。通过 HTTP Range 获取指定成员，校验 ZIP CRC32、长度并记录 SHA256；没有下载整个归档时不得声称核验了整个包的提供方 MD5。音频和逐事件标签不公开或打包。

按作曲家分组，每组按文件名排序取第一条；Rachmaninov 与 Rachmaninoff 合并。此规则在已读取的归档目录上产生 11 条，不按音频内容或模型成绩选择。评分各录音前 60 秒起音，推理提供前 70 秒（不足则读完整录音）。完整区间评分包含评分窗内起音的所有预测，预测音尾越过评分窗不能从分母删除。若参考音尾超出输入上下文，单列不可观察数量，不能以截断答案取得分数。

比较原应用 Basic Pitch 加既有起音融合/音尾检查与官方固定起音/音尾回归钢琴模型。后者沿用 `piano-offset-research.md` 的源码和权重，默认阈值不变。各模型只读音频，无人工 BPM、拍线、谱面、书签或 MIDI 输入。保留真实采样时钟，不扣制谱提前量，不按标签搜索时间偏移。所有返回音符参与评价，不能因音高/类别错误删掉。

标签是 MIDI 的按键起止。先核验发布方 CSV 的字段与 MIDI 一致性，明确是否含踏板延音；按键放开、踏板延音和谱面 LN 放手分开解释。标准匹配为起音 50ms、音尾 max(50ms, 20% 参考长度)、同半音；严格匹配为起音 40ms、音尾 80ms、同半音，一对一最大匹配。另报告长音（≥2秒）匹配、预测长音数和同音高短间隔重弹，防止平均分掩盖错误连接。

不训练、不使用这批结果选阈值。逐录音及汇总均保留。专用模型若只在局部改善，不因此全局替换通用检测；后续接入必须明确钢琴适用范围并保留已有反例。纯钢琴录音不等价于分离后的复杂流行伴奏。公共数据可能进入某些预训练来源，因此不称作对所有预训练模型均未知的盲测，更不能称作成品 LN 验收。

引用：Meinard Müller, Verena Konz, Wolfgang Bogler, Vlora Arifi-Müller, *Saarland Music Data (SMD)*, ISMIR Late-Breaking/Demo, 2011；v2 数据发布方说明与许可随本地来源记录保存。
