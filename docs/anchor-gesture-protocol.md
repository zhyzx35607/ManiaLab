# 起音锚点与 LN 编排实验协议

2026-11-09，实验前记录。研究入口默认关闭，不替换应用生成器。

## 问题和输入

前一轮检测草稿可以恢复 Mapper 输出，但完整 LN 起止匹配仍只有 9/57；加状态约束后降为 5/57。本实验固定输入起音及物件数，只学习在已有起音锚点之间安排 LN。乐器的物理 note-off 不作为 LN 结束标签。

- 候选起点来自输入草稿，终点来自之后八拍内的其他起音；最短 100ms，最多 32 个终点。超过上限时保留最近 16 个，其余按距离等间隔抽样，不读取目标选择候选。
- 特征只读取输入起音、层数、显式来源、已提供红线、目标键数与用户 LN 风格条件；不读取输入长条音尾、成品轨道、书签、绿线、段落答案或歌曲绝对位置。
- 预测短键、各终点或“没有可表达终点”的分布。后者保留短键并单列计数，不能把未匹配标签悄悄当成短键真值。
- 同时起音的多个源无法从成品唯一反推乐器归属；监督是整组端点分布，不伪造逐乐器作者标签。
- 用整数优化统一分配各组端点，保持全部输入起音/物件数。占轨容量覆盖整个候选区间；无可用长条方案时保留短键。共同放手只作为可调的规划偏好，不能靠事后剪尾或删音修复。

## 学习与比较

先用已核验的 Ranked/Approved/Loved 快照训练通用节奏先验：排除 `layout_only`，沿用按歌曲名、音频、谱包连通分组划分。输入由人工谱去除所有尾部和轨道形成，因此属于**给定人工起音的表达任务**，不是采音成绩。按歌曲及键数共享采样预算，包含所有 LN 比例。

《樱花草》额外提供单曲来源适配实验：输入冻结的检测草稿，0–149367ms 拟合，162340–188286ms 校准，188286ms 以后比较。完整上下文不得跨拟合/校准边界。重复乐句存在相关性，不称盲测。已知作者 Timing 和全曲 LN 比例被显式提供，与已有 Mapper 实验相同。

模型保存后才读取比较标签。训练预算固定；只在校准组选择 LN logit 偏置 `[0, 0.5, 1, 1.5, 2]` 和共同放手代价 `[0, 0.25, 0.5]`。先比较完整 LN F1，再比较放手 F1，再选择较小改动参数。保留全零短键、固定下一起音终点、通用先验和来源适配对照。

报告必须包含：起音与数量不变量、候选可表达上限、完整 LN、放手组、共同放手、长条长度分布、全曲/后段以及两个既有片段；另外检查 6–10K 独立歌曲组。与作者不同的配对不必然音乐错误，但低匹配也不能用“创作自由”免除检查。全曲合法、测试通过和该单曲相似度均不能代替音乐验收。
