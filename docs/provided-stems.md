# 使用 Nova 等工具已有的声轨

此功能从alpha.6 dev.2便携测试包开始提供。它允许直接使用已经分离好的声音，单独检查采音与编排，不再重复运行本程序的分离模型。

1. 导入原始混音。
2. 展开「使用已有声轨」，按鼓、贝斯、人声、其余伴奏、吉他或钢琴分别选文件。可以只选一种；每次保存的声部集合就是本次选择，不混入上一次的文件。
3. 保存后选择「使用已导入声轨：逐乐器采音」，点击分析音频。
4. 在试听声部中选择乐器，检查原始采音、波形、段落和声部表达，再决定如何写谱。

声轨必须与混音同起点、同长度，保留开头静音。导入不会裁掉静音或猜测起点偏移；只容许解码重采样产生的末尾两采样以内差异。长度一致不能证明内部已经同步，仍需在前、中、后试听。文件名不用于猜测乐器，因此中文文件名或原谱包乱码不会自动指定错误声部。

声轨按内容身份分别保存，重新分析可复用音高缓存；更换声轨不会复用旧声轨的模型输出。失败或取消的导入不改变已保存的声轨、分析或候选。导入后已有分析仍可查看，只有重新点击分析才切换到新音轨集合。不提供鼓轨时，Timing 读取混音起音。

「钢琴声轨使用专用采音（测试）」仅在六声部分离，或已导入钢琴声轨时可选。dev.2测试包包含所需的 `assets/deep/piano-regression.onnx`；旧包没有此组件。默认不勾选，其他乐器继续使用原检测方式。专用模型采用固定阈值，页面的通用起音/持续门槛不改变它；专用激活单独缓存，切换回通用检测不会覆盖对照结果。

钢琴模型的持续区间包含踏板延音。音符检查器会区分检测释放、持续激活消退、同音重弹，以及输入/时长截断。后两种截断的候选保留在原始采音中，但自动编排只使用其起音，不把截断点当作可靠 LN 尾端。音高数量不等于制谱的单双层数；声部表达与定轨仍需进一步验证。自然钢琴与《樱花草》的对照见 [钢琴专项记录](piano-acoustic-research.md)。

这项功能解决声音输入与独立检查的流程，不代表已完成乐器转录、LN 表达训练或达到作者《樱花草》的效果。现有 Basic Pitch 与持续音规则仍有误检、漏音和层数问题；研究权重未默认启用。

验证：真实《樱花草》215.853–227.853 秒的 Nova 鼓和钢琴，完成上传、逐声部分析、波形/音频读取、缓存复用、项目重开，以及桌面/390px 布局检查。自动检查覆盖长度不符、取消、不完整缓存、文件内容改变和旧结果保留；原音频与截图仅在本地测试目录。
