# 冻结真实钢琴候选的三权重局部连接对照

2026-11-09，在本轮推理前固定。只读取已冻结《樱花草》1557个钢琴候选及 `probe-v3/sakura-graph-input.json` 的一一对应诊断坐标。沿用旧74 BPM、Offset178ms、22.5ms提前量、每拍四细分与480 ticks/quarter；它们是人工已知拍线的诊断转换，不是自动Timing成绩。原音频起止、音高、ID、力度始终保存在旁表，不重跑采音、不删音、不改LN或谱面。

新表示不能复用旧 `graph_from_rows/predict`：后者采用上游几何、不同候选集合及官方后处理。此次用源事件训练相同的DTYPE/几何/网络边界，构建无标签窗口，全部监督mask为false。不能伪造MusicXML的written/part/voice来调用源标签构造器。

从拍线0起固定连续4小节core，左右各1小节halo，按完整观测区间重叠纳入carry。全曲观测关系先确定，再诱导窗口；节点和音尾不在边界裁断。每个起音仅归属一个core；边结果归属目标起音所在core，谱表节点归属自身core。GraphNorm始终在该固定窗口计算，三个权重完全同输入。不追加全曲/切边/归一化四因子实验，不按结果改变窗口。

比较固定原始预训练权重、源事件clean适配epoch1、重叠观测适配epoch4。分别保存raw voice/chord logits和staff输出，阈值固定logit>=0，无官方后处理、无连通分量合并。所有跨人工小节候选另列为未验证；展示的同小节局部边也只是模型假设，不是已知旋律身份。音频没有书写tie终止小节，禁止用声学end所在小节伪造该监督。谱表和未直接训练的和弦head仅供比较，不进入自动LN。

输出共同graph输入/ID映射、三套逐窗预测、完整汇总与4个可读片段。片段在推理前按原音源时长的1/8、3/8、5/8、7/8定位对应core；若对应core为空，则选离目标时刻最近的非空core，同距取较早者。相同core不重复选择，候选不足4个则明确保留实际数量。每段展示原始物理音符区间和三模型局部连接，并附原Nova钢琴回放。曲外部分按真实PCM长度裁剪，不补边界起音，不把量化坐标画成原始采音位置。

报告候选/正连接数、同小节与跨小节区分、节点分类变化和不同后继起音组数等结构诊断，不把分叉或跨音区自动判为错，不计算无真值的声部准确率。权重、输入和代码快照留痕；原音源、逐事件数据与研究权重留在本地忽略目录。此轮未启用应用，也不算音乐验收。
