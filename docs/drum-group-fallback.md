# 鼓组落选后的有限补充

2026-11-11。完整鼓组受其他声部、同押或密度限制而落选时，现在允许从该组
保留一个已有瞬态起音。先按原规则选择完整音组，再固定全部已选音符，仅用
剩余容量补充鼓点。钢琴、贝斯、其他伴奏及原有鼓点的 ID、起止不会因此被
删除或改写；后续定轨仍会重新安排轨道。

每组只提出一个候选，沿用原起音评分：强度、声部权重和量化移动的惩罚。
这是编排简化，不是新的鼓音色识别或采音模型。其他鼓点仍标记为省略，
不能声称它们的音色已经被一个 note 表达。选中记录含
`group_simplification=strongest_drum_attack` 和 `reason=drum_group_fallback`。

## 约束与验证

补充选择共同检查滚动一秒密度、同时起音和可用轨道，并保留原 LN 放手间隔。
检查时刻包含第一阶段全部候选起音；即便某个起音已落选，它所在段的较低
密度限制仍然有效。新增项都是短键，因此不会增加同时持有 LN 的数量。
两个求解器的成绩分别记录，第二阶段只是在固定原方案后的条件优化，不能
称为所有长短表达组合的全局最优。

局部检查 **89 passed**，覆盖6–10K、完整鼓组保留、对齐权重、同音时刻的
不同鼓音、静音选择、多个补充候选竞争，以及落选起音处的分段密度边界。
边界反例在修复前实际失败，修复后通过。

## 《樱花草》固定结果

复用 `expression-current-replay-v1` 的完整候选和时钟：74 BPM、Offset178 ms、
音频提前22.5 ms、四细分。没有神经推理或读取作者参考谱。
关闭本次补充步骤时，5种键数均精确复现旧选中音符及逐音选择记录。

| 键数 | 物件数（旧→新） | 鼓（旧→新） | LN数（保持） |
|---|---:|---:|---:|
| 6K | 1486→1491 | 316→321 | 359 |
| 7K | 1492→1496 | 312→316 | 369 |
| 8K | 1495→1499 | 312→316 | 373 |
| 9K | 1495→1499 | 312→316 | 373 |
| 10K | 1495→1499 | 312→316 | 373 |

原选中 ID 和所有音符起止全部保留。新增鼓点的量化移动，6K最大12 ms，
其余最大5 ms。五种键数均通过实际定轨、容量检查、完整网格检查和 `.osu`
导出回读；没有同轨冲突。第二阶段均正常结束，gap为0。
鼓起音之间的最大间隔从18.649秒变为15.202秒，这只是输出变化，不证明
全部空缺都应该填满，也不证明原采音、自动Timing或音乐表达已正确。

仅选择每组预定的最强起音；如果它受阻而较弱起音有空位，这一组仍可能落选。
本次没有扩展到旋律音组或 LN，也没有发布新 Release。最初直接将简化组放进
全局竞争的本地实验会改变其他声部，未采用；旧结果保留在 `v1` 目录。


公开源码上传。脚本拒绝覆盖既有输出。
