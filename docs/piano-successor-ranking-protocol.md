# 监督范围内的后继起音组排序训练

2026-11-09，首次运行前固定。前一轮单组解码表明，删掉分叉不保证正确连接：重叠模型在+1/+2输入丢失188/291条真边，65/130条涉及未监督最高分。此次只检验一个辅助训练目标，不将未知连接作为负例，不更改标签或候选集合。属于已见开发结果驱动的实验，不能称盲测。

沿用已核验clean/+1/+2缓存。对每个来源事件，P为监督mask内全部正例边，其目标起音tick必须唯一；N_t为其他目标tick的已监督负例边集合。若P或N_t不存在，则不提供排序损失。否则计算：各负tick组取最大logit，与每个正确目标边计算softplus(max_negative_logit - positive_logit)，先对正边平均，再对负tick组平均，最后对合格来源事件平均。和弦中所有正确目标均参与，不能只选最容易的一个正例；正确tick内的错误边仍由原BCE负责。未监督边完全不进入这个辅助项。共享编码器可能间接改变未知边的输出，不能声称未知预测不受训练影响。

监督覆盖审计：clean train有17810个正例源，其中14212个同时有已知其他tick负组；3598个没有这类负组，另1931个有监督候选的源没有正例。validation分别为1328/981/347/117。三种观测的监督身份不变。现缓存每源监督只归属一个目标core窗口，训练前再次断言，无重复来源排序监督。

固定总损失=原voice BCE（正例权重5）+原staff CE+0.1×排序损失；没有margin或参数扫描，不新增和弦loss。从固定原预训练权重重新开始；seed42、4轮、AdamW lr1e-4、weight_decay5e-4、梯度裁剪1，输入变体仍为(i+epoch-1)%3且遍历随机打乱。和已完成的仅BCE重叠训练逐项比较；不从其最优轮继续加训。

逐轮保存raw边指标、固定单组解码指标和谱表正确数。按三种输入逐曲raw后继F1宏平均的等权均值选轮，epoch0参与，精确同分取早轮；解码成绩不参与重新选择参数或轮次。解码仍允许未监督边竞争，必须记录真边损失、误边减少和被未监督最高分抢走的真边。只读取原train/validation，不读test。

正式训练前核验loss的未知边直接梯度为0、全部和弦正例参与、无P/无N跳过、同tick负例不进辅助项，并做一次丢弃的反向更新；正式训练重置随机种子。固定四轮完成后运行原六个已见开发控制，保留交叉和踏板反例；不新增控制来挑结果。是否再进入真实采音对照，由正确连接与误连的实际变化决定，不能因平均分上升自动替换应用。

本轮不改声学采音、不改LN规则、不生成或发行新安装包。数据、逐事件与研究权重继续只保留本地忽略目录；训练通过不是音乐验收。
