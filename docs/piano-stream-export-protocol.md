# 钢琴声部分组的实际制谱对照

2026-11-09，在适配模型评价与本轮导出结果产生前固定。只研究已冻结的钢琴分组如何影响表达、选音和定轨，不修改应用默认算法。用户《樱花草》作为声部分工与表达清晰度的参考，允许作者错漏和合理的不同写法；本实验不读取作者谱，不做逐音符复刻或以人工匹配率验收。

输入使用 `instrument-expression-v1/instrument-analysis.json`，必须核对它与声部分组使用的 `piano-full-pipeline-v1/specialist-analysis.json` 中全部钢琴候选逐字段一致。其余声部使用已有的新 other 检测结果。段落、主次角色和非钢琴表达固定为 `articulated-expression-v2` 的独立持续表达方案。既定时钟为 74 BPM、Offset 178 ms、四细分、22.5 ms 制谱提前量；这不是自动 Timing 成绩。

固定比较共十三项：10K 原方案基线；10K 原模型按谱表、按小节内声部连通块分组；10K 适配模型对应的两种分组；适配模型的两种分组分别导出 6–9K。使用相同采音和已有设置，仅改变键数。模型检查点必须已经由验证集选定；不按 LN 数量、最终谱面密度、作者匹配或留出测试分数重新选权重、阈值或分组方案。可另作三项原模型预检，其结果单独留在新目录，不称完成适配比较。

只有已进入 `expression_evidence` 的钢琴候选可以替换表达。每个候选只能使用原始已观测音尾或变成短键，保持原始起音、音高、来源、强度、段落与主次角色。弱检测及被既定方案省略的候选仍省略；不新增起音，不改原采音，不把未决尾升级为 LN。分组中的谱表和连通块只是模型输出，不是整曲稳定旋律、物理手指松键或听觉声部真值。

每项都真实运行时钟转换、量化、分组选音、定轨和 `.osu` 导出。保留物件在选音与定轨之后不得剪短音尾来腾空间。检查同轨冲突、6–10K 边界、完整落线、`.osu` 回读的起止及轨道一致、原始采音不变、未决尾禁用、非钢琴表达不变及弱音省略不变。10K 原方案必须逐事件和逐轨道复现上一轮基线。

完整保存方案、表达输入、量化输入、取舍 trace、最终物件、导出谱和文件哈希。统计各声部物件数、独立起音数、LN 数、超过 30 ms 的起音量化移动、表达变化数、选音求解状态、实际耗时及鼓组相对同键数原方案的增减。鼓组按“段落＋量化起音”定义；报告整组丢失与恢复，并保留组内原候选 ID 和实际选中 ID，不能把同起音多鼓音色误算成多个独立鼓组。

在原模型预检后、完整适配对照前补充解释统计，不改变表达和选音：对分组后新增的钢琴 LN，分别报告表达阶段与最终保留阶段的规则原因、节奏组起音数小于 3 的数量、原始单音组件数量，以及经过既定强度和段落筛选后仅有一个音、一个起音组或两个起音组的组件数量。原始组件计入弱检测，表达组件只计实际进入表达的候选，二者分别命名；“独立持续音”只是规则标签，不能视为已经确认的声音语义。已完成预检的原文件不覆盖，只从已保存表达和取舍结果重算廉价诊断到新目录。

全部原音频、逐事件与生成谱面只在忽略目录 `test-data`。没有独立听辨、可演奏性和歌曲表达验证时，工程检查通过与任何统计变化都不等于音乐质量验收，也不据此发布新默认模型。
