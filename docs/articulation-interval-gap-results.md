# 区间空隙保护的验证结果

2026-11-11。修复了一个可复现的表达问题：后段的连续拖尾会把前段已经结束、
彼此有间隔的音也一并短键化。新规则只在原来已判为连续敲击的音组内，根据
已观测区间的空隙细分；不新增短键化，不把重弹截断视为已观测松键。

**《樱花草》和11份SMD的最终表达没有变化。本轮没有证明真实歌曲音乐性
改善，也没有解决钢琴内部独立旋律分组。** 实施前条件和中途失败修订见
[协议](articulation-interval-gap-protocol.md)。

## 行为与验证

新增边界要求此前候选区间均已结束至少80ms，当前原起音组内未出现未知尾
或非音高事件；更早音组的持续音仍参与检查。按整个来源处理，段落切分不
制造假尾；手动持续音等其他模式不变。新边界标记为`observed_interval_gap`。
它说明的是候选区间空隙，不证明录音静音，也不自动识别旋律主次。

初版完整v2重放中，Beethoven有9个原持续音被局部拖尾比例重新判为短键，
117条持续表达变为108。新增最小反例确认此副作用后，限制为只细分旧规则
已短键化的组，保留原持续表达。v2及其统计完整保留，未调整80ms等阈值。

旧代码两项核心反例实际失败；初版一项“不新增短键化”反例实际失败。
最终20项专项与相关测试共216 passed，覆盖更早持续音、和弦中未结束的一层、
未知尾、短间隔、重复观测、其他乐器、段落边界和手动模式。
