# 连续起音与延音的表达对照

2026-11-09，实施与比较之前记录。以原始声音证据和表达规则为依据，不按《樱花草》逐音符匹配调参。

## 本轮改动范围

1. 自动主声部的活动统计不再使用已知强制截断、输入边界或未决音尾延长覆盖。起音仍有250ms活动窗口；重叠区间只计一次，并按段落边界精确裁剪。统计描述的是检测活动，不声称是人耳判断的旋律主次。
2. 将主声部优先级与长短表达分开。为钢琴和吉他增加可编辑的“连续起音优先，组尾可延长”方式。默认中等LN倾向下建议该方式，不因其是主声部就将所有延音变成长条；明确的持续音、只表示起音、连续人声乐句和不采仍可独立选择。LN倾向为0时只用短键，至少0.75时仍建议完整持续音，属于用户表达偏好，不叫质量指标。
3. 同声部相距不超过30ms的起音组成和弦组，以首起音为边界，不链式吞并相邻触发。组间距大于等于本段中位起音间距2.5倍（下限500ms，上限1600ms）时另起一组节奏。分组不使用作者拍线、书签或note位置。
4. 一个节奏组至少有3组起音，且至少一半的相邻起音之间存在中位可靠音尾延续到下一起音80ms以后，才属于本轮要处理的拖尾敲击序列。该序列内部使用短键；末组可保留原有、已观测且满足最小长度的音尾。其余序列保留已有持续表达，不凭空延长或把尾巴截到下一音。
5. 该表达不等于钢琴手指松键或踏板识别，不声称抽出了旋律声部。统一的组内规则用于避免逐note随机切换；末组保留长音是编排选择，需要试听。原采音起止、音高、来源ID始终保存，选音和定轨阶段仍不剪短已选LN腾位置。

## 固定比较

- 复用上一轮《樱花草》的完整浮点输入和冻结预测，分别保留旧other检测与新other检测；不重跑采音网络。
- 使用同一分段、密度、LN设置及人工确认的74 BPM、Offset178、四细分、22.5ms提前量。分别运行旧方案、只修活动统计、新长短方案，比较主次变化、候选与最终起音、保留LN、被容量省略音组、超过30ms的量化移动及6–10K结构。
- 11首已固定SMD真实钢琴检测仅用于检查新表达没有新增/挪动起音、错误利用截断尾或修改原采音，不将与MIDI的长短一致当作制谱优劣，也不按结果换阈值。
- 保留所有比较及失败；公开统计不带音频和逐事件资料。音乐验收仍需对照声音、段落与实测，不能以LN更少或更多宣布成功。
