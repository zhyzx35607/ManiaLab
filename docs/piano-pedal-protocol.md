# 钢琴音尾语义补充：在首次推理之前固定

2026-11-09。数据仍在下载、尚未运行本批模型时，核验训练仓库 `bytedance/piano_transcription` 固定提交 `1ade7dcd4348add669a67c6e6282456c8c6633bd` 的 `utils/utilities.py`：`TargetProcessor.process()` 默认 `extend_pedal=True`，将踏板按住期间松开的音延续至踏板释放，并处理同音高再触发。它不是单纯按键释放预测器。

因此主完整区间对照采用明确的踏板延音参照，同时保留原 MIDI 按键释放的独立结果。原 CSV 与 MIDI 核对仍按按键语义进行，绝不改写原标签。延音参照按以下固定规则由标签生成，只用于评分，不进入推理：

- 每个 MIDI 通道独立处理 CC64；值 ≥64 为按下，下降到 <64 为放开。连续非零取值不会产生新的起音。
- 按键释放严格处于一个踏板区间内时，延音至踏板释放；遇到同通道、同音高的下一次起音则在该处截止。不同音高、不同通道不能截断它。
- 踏板最后未闭合时截止到原录音结束，并记录这种情况。该参照是 MIDI 控制器定义的延音，并非人耳判定的混响终点，更不是谱师 LN 放手真值。
- 原按键起止、延音起止与两套完整区间结果同时保存，不在看到模型成绩后择优选一种。起音指标不受此语义变化影响。

固定模型阈值、11 条音频、首 60 秒评分/70 秒上下文、时间容差沿用 `piano-acoustic-protocol.md`。双方所有评分窗内起音的预测都留在完整区间分母；参考尾部超出上下文的数量单列。此补充在本批预测前制定，准备清单记录两份协议的哈希。
