# 分离后是否保留音符：固定后续对照

在Mega53全部32份分离控制完成后，使用固定Tsumugi `other_v1_5`，比较每份
原输入与分离输出的采音。本协议在转录前写定，不挑分离收益最好的乐器。
8种乐器、4种控制、分离前后共64个用途；只有逐样本完全相同的浮点PCM
才复用推理。转录器不接收目标类别，所有声学推理串行，两计算线程、一跨算子线程。

复用既有 `research_tsumugi_transcription.py`，保留原始事件、窗口和区间
构造证据，不经过MIDI、吸拍或谱面表达，也不额外按类别/强度删音。
沿用固定解码器的 -72 dBFS 静音门控；被门控跳过不能称为网络实际前向。
来源、模型、依赖和全部
输入均记录身份；输入WAV为float32，保存后逐样点验证，没有整数PCM量化。

源音频20–26秒，评分范围为中间22–24秒的所有起音。头容差50ms、音高
精确半音；音尾容差max(50ms,参考时长20%)。参考音尾若到达或超过26秒，
该项完整区间分数记不可评，起音仍评；不凭预测音尾筛除错误预测。没有用
音尾评分判断实际LN放手，六秒上下文也不能代表整曲转录。

报告三类结果：

- 每个指定目标在混音中的采音：报告召回与目标定向精度。分离前混音采出的
  其他真实乐器在这里也会计为非目标，因此**这个精度不是混音整体采音质量**。
- 仅目标输入的分离前后对照，检查已有的真音是否被分离器损伤；目标缺席
  和全静音时同时报告全部/中央预测数量。
- 第12、31首的预定目标恰好覆盖其全部源乐器，另比较原混音一次转录与所有
  分离目标转录的并集。保留重复和串音，不用参考答案筛类别或消重。
  这两首才可比较所有来源的整体采音，不能外推为八种乐器都已改善。

参考标签在全部声学推理完成后才读取。公共训练重叠未知，16kHz单声道升采样、
人工混音、短上下文等限制沿用分离实验。无论结果如何都保存完整8组，不据
表现改样本、增益、类别或阈值。生产程序和已发行包不随研究分数自动改变。

下面是原始运行命令。需要已完成的分离产物、冻结URMP来源、Tsumugi研究
模型与隔离运行环境，干净源码仓库不包含这些资产。再次运行须改用新的输出
目录，不能覆盖已存在的 `test-data/mega53-transcription-v1`。

```powershell
.venv/Scripts/python.exe -B scripts/check_mega53_transcription.py --separation test-data/mega53-separation-v1 --output test-data/mega53-transcription-v1
```
