# 鼓叠奏的非负模板对照

2026-11-09，在本次拟合与后段评分之前记录。用户确认第1列kick、2/3列snare、第4列主要hi-hat，也包含tom等；这些是作者选择，不能视为完整的物理鼓标签。

Reference中，第4列与其他鼓同刻的数量由拟合段7/41、中段6/16升至后段53/75。先验证非负、可相加的局部音色模板是否能恢复被其他鼓遮盖的成分，不继续用后段挑阈值。这是独立的候选起音局部非负重建实验，不声称复现某篇论文的算法。

固定1387个原声学起音，不添加人工起音、不吸附拍线，统一减22.5ms对照作者谱。使用已审计的原float32鼓PCM，保留旧int16研究。另重跑同一线性方法的float输入对照，避免把输入格式差异混成算法收益。

训练结束162340ms，校准结束188286ms。模板只取训练段中仅有一个作者类别、同一候选附近没有其他类别的已匹配事件；每个音频窗的末端必须早于训练结束。这只能称作者标注上的独立事件，不保证物理独奏。64个对数频带，三个起音后窗口（-5至25、25至70、70至140ms），减去起音前45至5ms的平均功率并截断负值。每维缩放仅由训练候选求得；不做对数压缩，以保留近似叠加。功率可加是近似，混合相位和非负截断会破坏严格相加。

每类模板数固定尝试1、4、8，用确定性最远点初始化和球面聚类求模板；每个候选用非负最小二乘拟合，保留三个类别的同时激活和残差。不使用互斥分类。每类系数和除以输入向量范数作为证据，**不是概率**；阈值固定尝试0.02至0.90、步长0.02。仅中段选择各类模板数/阈值，后段不得重新选择。完整搜索表和原始证据保存。

分别报告全部事件F1及作者独立/叠奏事件召回，子组召回使用全类一次匹配的结果，不把其他子组预测算成假阳性。模板、校准表、逐事件和哈希写入忽略目录；不改变应用默认模型。单曲反复开发和重复乐句仍不构成跨曲泛化或物理采音验收。
