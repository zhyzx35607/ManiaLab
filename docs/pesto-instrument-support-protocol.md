# PESTO 乐器持续音辅助对照

2026-11-10，在第一次声学推理前固定。使用作者 PESTO 推理仓库
`62bc0c9702558f19af4593752947fb9db1eadac9`，只使用默认 `mir-1k_g7`，
SHA256 `16c32e06ddd950e3e4866dfa3c7f8a87c4988f8adf43e57977b189f031f26f3e`。
不选多套权重取最好结果。代码为 LGPL-3.0；仓库未找到独立的权重许可，
当前只本地研究，不将模型作为 ManiaLab MIT 文件发行。

输入为已冻结的全部28个URMP独奏与7份混音，与Tsumugi比较同一0–40秒PCM，
评价0–30秒；它们共享七次演奏，不能算35首独立歌。固定纯零、MIDI40/57/69
正弦及57+69双音控制。不读取保留的MAESTRO测试，不训练、不归一化、
不从标注选择模型或参数。模型只看到波形和采样率。

CPU两计算线程、一跨算子线程，逐例串行；一个片段完整计算，不拼接无重叠
窗口。用权重安全读取及完整匹配，拒绝上游loader的广泛strict=False回退。
先载入学习权重，后按作者算法生成CQT核，保留全部原始音高、voicing、能量、
激活；每帧时刻由整数采样hop计算。补帧原值保留但不作为音频证据，尤其不能
把最后补帧变成可用音尾。未知/没有帧的区间明确标空。

PESTO只有每帧一个F0，voicing是发声判别而非音高正确率，也没有同音重弹、
多音和弦或起止事件。实验只检查Tsumugi已有候选的音高持续支持：固定voicing
至少0.5、音高误差至多半音，逐音保存覆盖比例；固定“至少一半区间得到支持”
作为诊断过滤实验，不改变任何原音的起止，也不自动应用于软件。报告过滤前后
的误采、漏采和完整区间分数，混音负例也全部保留。它可能错误丢掉复音中的
正确音，不能用声部标签假定每轨只有一个音。

另按参考音符区间统计单音帧与静音帧；这只是离散音符标注上的一致性，不能称
逐帧F0真值或完整音高准确率。结果出来前不接默认采音、主次选择或LN放手。

一手源码：`https://github.com/SonyCSLParis/pesto`。原始仓库和权重在ignored
`test-data/pesto-source`，可复用入口为`scripts/research_pesto_pitch.py`，固定对照为
`scripts/check_pesto_instrument_support.py`。
