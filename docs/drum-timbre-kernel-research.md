# 局部鼓音色非线性分类：未通过

2026-11-09。同一批1387个声学起音与局部频谱，训练/校准/后段区间不变。原线性模型的所有区间分数逐项重现。核宽度及阈值只用中段选择，没有后段调参。

|后段类别|线性F1|非线性F1|非线性匹配/参考|
|---|---:|---:|---:|
|kick|0.9555|0.8482|95/127|
|snare|0.9286|0.7500|27/45|
|第4列（主要hi-hat，也有tom等）|0.3814|0.2919|27/75|

第4列的中段F1从0.2712升到0.2899，但后段退步，kick/snare的中段均为1也没有保证后段召回。更复杂的局部分类器没有解决段落、音色变化和作者取舍，不接入应用；原默认模型保持原样。Reference不是完整物理鼓转录，未选声音不能简单视为不存在。

首次数值优化未收敛，保留在`test-data/sakura-benchmark/drum-kernel-v1/failure.json`。在同核矩阵的正交坐标中求解后，九个模型均收敛，导出logit核验通过；完整校准、模型、逐事件与结果位于`drum-kernel-v2`。未使用未收敛的临时系数评分。

下一步调查更完整的打击乐音色转录，用原Nova鼓轨独立验证，不能靠继续调这首歌的后段阈值来声称改善。[事前协议](drum-timbre-kernel-protocol.md)。
