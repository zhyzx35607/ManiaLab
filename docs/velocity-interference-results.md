# 真实弦乐与铜管的力度干扰结果

固定的两组真实乐器已完成五条件对照。大部分查询对自身12dB衰减方向正确，
但另一声部变化会影响当前声部的估计，且存在反向响应。此模型继续作为研究
证据，不能独自决定音符取舍或段落主声部。没有修改默认采音、LN或候选强度。

按[事先固定协议](velocity-interference-protocol.md)，使用既有URMP0–40秒
原始分轨和冻结单轨预测，小提琴/大提琴与小号/圆号分别线性混合。不是原始
完整合奏，也没有把参考标签输入模型。509个原候选扩展为4307个显式GM假设
查询，每个跑五条件；不把这些重复假设当独立样本或新增采到的音。

|---|---:|---:|---:|

反向响应涉及至少一个GM假设的小提琴原候选21个、小号4个。最明显分别是自身
衰减后力度上升1.29和2.90；这些是未取整期望velocity的变化，不是声压dB。
原候选可能含错采及错误类别，不能将它们全部标为真实音符的力度错误。
大提琴和圆号本次没有反向查询，也不代表它们已通过全部真实音乐评估。

关闭目标来源、只播放另一声部时，目标查询仍能得到非零输出；小号查询最高
约63.29。这不能直接算误报率，因为模型没有无音类别，而且查询集合在所有
条件中保持不变。它说明不能把velocity当作“这个音存在”的判断。

记录保留所有输出、假设program、已知实验来源索引、模型原起音标志和未知尾
原因。来源索引只用于统计，没有送入模型。没有按结果移动音头、修改音尾、
调整阈值或挑选program。输入文件与PCM前后核对不变；本机串行前向约188.33秒。
