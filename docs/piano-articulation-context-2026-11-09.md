# 段落边界不再制造钢琴尾音

完整声轨中的连续起音此前按谱面段落分别判断。当段落切开和弦或连续弹奏时，局部最后一组音会失去下一次起音的上下文，可能被保留为长条。现在先在完整声轨、相同置信度筛选条件下计算连续起音，再应用各段自己的表达模式。显式长音、单点、乐句或忽略模式仍由该段方案决定。

判断区分下一次起音、已观测的起音间隙和未知右侧上下文。间隙只表示检测结果中没有后续起音，不证明真实乐句已经结束；音频末端不足以观察间隙时，不据此认定连续弹奏已经收尾。不同声轨的上下文分别计算。这仍不是钢琴内部旋律声部分离，漏检和踏板重叠仍可能影响判断。

在《樱花草》冻结的1557个钢琴候选上，使用同一音源分析、相同参数、各段相同的连续起音表达方案：修复前后均选入1532个起音，长条由36个变为16个；20个hold变为tap，0个反向变化。所有候选与选入起音的ID、位置、音高、力度保持不变。这里验证的是段落上下文错误被排除，不以长条变少作为音乐质量改善证据，也不宣称通过试听。

连续起音模式现在要求有效音频时长；空、重复或非字符串的音符ID会明确报错，避免跨段字典覆盖。表达方案签名新增音频时长，旧签名方案需要重新生成，不能静默沿用缺少上下文的方案。

固定对照由 `scripts/check_articulation_context.py` 产生，最终本地产物为 `test-data/sakura-benchmark/articulation-context-after-v3`，基线报告SHA256为 `1655edf7ef9b7abbb6ea0f8654610d03443d87c6a82f96adafe0e87bbdb43ad1`。新增控制覆盖切开和弦、模式切换、短右上下文、声轨隔离、乱序及无效输入。相关83项测试通过；此处未重新运行声学模型。
