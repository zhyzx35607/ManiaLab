# 钢琴低活动区间的原声核查结果

2026-11-11。完整测量104个SMD候选覆盖空隙内的低活动区间，以及《樱花草》
6个固定候选空隙。原声不能支持“模型低活动就是物理停音”的解释；这轮不将
低活动规则接入默认生成，不重写音尾，也没有训练或新增安装包。

这不是亲耳试听或音乐验收。频谱中的持续成分、参考按键保持、实际可闻性和
适合制谱的放手位置是不同的判断，不能互相替代。协议见
[原声核查](piano-gap-audio-protocol.md)。

512窗在110处都有完整帧；2048窗有16处、8192窗有100处不能测量完全位于
间隔内的频带功率。对应字段为null，不是零。长窗图仍包含跨越边界的帧，
不能用这些帧判断短间隔的精确音尾。图的频谱仅覆盖间隔前后500ms，波形
显示前后1000ms，两边白色区域表示未绘制频谱。

28个按键重叠中，4个不超过10ms，7个不超过50ms，1个超过500ms；29个
踏板重叠中分别为4、8、1个。计数为包含关系，不把毫秒级差异与数秒持续
混称一种失败，也未据此改动原标签或容差。两组功率比范围有重叠，不能
从上述汇总构造可靠的静音阈值。

## 复算与复现

11项专项控制验证了衰减、边界泄漏、缩放、直接Hann FFT、短输入与非法
区间；和已有频带/低活动检查共105 passed。独立脚本核验480个文件哈希，
110份片段与原PCM逐样本相同，检查34830项频带区域统计。对预选10份
片段的三种窗共7665帧另用直接periodic Hann+rFFT计算，频谱最大绝对
误差为5.551115123125783e-17。没有重跑神经模型；不是声学准确率测试。

```powershell
.venv/Scripts/python.exe scripts/review_piano_gap_audio.py --output test-data/piano-gap-audio-new --plot-dependencies test-data/audio-review-deps
.venv/Scripts/python.exe scripts/audit_piano_gap_audio.py --source test-data/piano-gap-audio-new --output test-data/piano-gap-audio-audit-new
```

以上入口需要本机已有的冻结音源、标签、模型活动和候选文件，以及绘图
依赖目录；不是只下载源码即可运行的公共数据基准。不覆盖已有目录。
