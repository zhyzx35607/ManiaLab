# 先学物理音色，再学作者选音

2026-11-09。按[预先固定的协议](physical-drum-training-protocol.md)，新增独立物理鼓起音实验。它使用鼓录音的人工音色/起音标签，从零训练75,267参数的时间卷积网络；没有用《樱花草》、作者Reference、谱面BPM或键位来训练。

实际读取94条IDMT混合录音与23条MDB鼓录音，拟合42、校准4、测试71；总时长分别1108.57、175.82、1455.41秒。原始包的一条音源名称/标注不一致记录隔离；10个略早于采样零点的官方事件保留，未删分母。音色组/歌曲划分不交叉，归一化逐项重现为只用拟合记录的统计。

IDMT来源为Zenodo 7544164的官方V2包，压缩包MD5与官方一致；MDB为作者仓库`CarlSouthall/MDBDrums`的`b29e2d63c3a023506f4bf353c5b2e8a558eed135`。原录音、标注及权重仅本地研究，不打包分发。IDMT音色组之间可能共享节奏型，MDB也可能被其他预训练模型使用，因此不声称这里证明了整个工程从未见过这些作品。

## 第一轮：物理起音有收益，hi-hat误检仍多

固定30轮，校准BCE选择第28轮，校准loss 0.4004。校准事件F1选择阈值kick 0.60、snare 0.70、hi-hat 0.10；最后一项落在预定搜索下界，没有依据测试集扩大或改选范围。模型SHA256：`1782d77f747a3f4aa542dade0d3c1f0b1b3f54c665fdcda5392afd77a9df8c0f`。

测试F1：

|物理标签数据|容差|kick|snare|hi-hat|
|---|---|---:|---:|---:|
|IDMT，60段未拟合音色组|20ms|0.9547|0.8386|0.8165|
|IDMT，60段未拟合音色组|40ms|0.9635|0.8398|0.8340|
|MDB，11段保留歌曲|20ms|0.9624|0.7839|0.5225|
|MDB，11段保留歌曲|40ms|0.9635|0.7864|0.5413|
|合并微平均|20ms|0.9579|0.8055|0.6960|
|合并微平均|40ms|0.9635|0.8075|0.7141|

合并40ms时，kick匹配2047/2168、提出2081；snare匹配1625/2192、提出1833；hi-hat匹配3249/3307、提出5793。hi-hat召回0.9825，但精确率只有0.5608。不能因为召回高就把额外事件全部写成note。MDB中的hi-hat精确率更低，为0.3748。

事后诊断显示，IDMT的861个未匹配hi-hat中，533个与kick、134个与snare同刻；MDB也有大量与kick/snare/cymbal同刻的未匹配hi-hat。这是后续模型设计的开发线索，不是另一轮盲测。

## 《樱花草》不是物理鼓真值

冻结上述模型和阈值，输入原float Nova鼓轨，不在本曲调整。统一既定22.5ms作者提前量后：

|全曲作者类别|匹配/作者事件|模型提出|作者选择F1|
|---|---:|---:|---:|
|kick|346/360|420|0.8872|
|snare|123/140|285|0.5788|
|第4列对模型hi-hat|124/132|1029|0.2136|

第4列含tom等，且Reference记录作者选音，不能将额外897个事件全部称为物理误检。与此同时，独立物理数据已经证明存在明显的真实误检，所以也不能辩称它们都是用户未选的合法声音。需要继续先解决音色混淆，再独立做段落取舍。该模型不接入默认生成。

本地证据：

```text
test-data/physical-drums/dataset-v2
test-data/physical-drums/model-v1
test-data/physical-drums/inference-v1
test-data/physical-drums/evaluation-v1
```

首次准备失败目录`dataset-v1`保留，未用于训练。第一轮训练及评分代码快照已经保存。模型输入分块与整段的最大logit差为1.19e-7；这只证明边界一致，不代替采音和音乐验收。

## 下一项：没有起音标签的独奏不伪造起音

按[新的事前协议](physical-drum-negative-protocol.md)，从原拟合音色组加入96条不重复的单独鼓训练录音；3条重复文件未重复计权。已知的本类没有起音标注，整个类别屏蔽损失；另外两类监督为不存在。原混合起音真值、归一化、校准及测试记录全部保留。未知标签梯度必须为零，全已知时损失须等同原实现。

由于第一轮已查看71段测试并据此诊断，后续重跑这批数据必须称为固定开发回归。不能靠反复开发它来声明全新歌曲泛化，也不能把本项采音训练声称为LN编排训练。

第二轮已完成30轮，校准BCE选择第21轮、loss 0.3520；阈值0.45/0.65/0.15。模型SHA256为`9e35d090dff1a34297375c2e9feb4b16be5df036fae8b24181b619dd19c3a151`。原117条混合录音、校准/回归特征及归一化逐项未变；96条单独鼓录音仅来自拟合组，未知标签屏蔽和梯度检查通过。

|固定开发回归40ms F1|第一轮kick/snare/hi-hat|加入独奏负例|
|---|---|---|
|IDMT|0.9635 / 0.8398 / 0.8340|0.9767 / 0.9027 / 0.8600|
|MDB|0.9635 / 0.7864 / 0.5413|0.9685 / 0.8205 / 0.5741|
|合并微平均|0.9635 / 0.8075 / 0.7141|0.9733 / 0.8524 / 0.7454|

合并hi-hat假阳性从2544降到2125，同时匹配由3249降到3227，精确率0.6030仍不足；真实MDB的hi-hat精确率仅0.4091。第二轮每轮754个训练窗，第一轮457个，更新数差异保留说明，不把所有收益单独归因于负例。

《樱花草》全曲对作者选择F1变为kick 0.8687、snare 0.6649、hi-hat对第4列0.2063。snare改善，但kick和第4列退步，hi-hat仍提出1041个事件。**拒绝默认启用**。下一步需要更细粒度的鼓音色、同音色重复起音判别和新的独立录音；作者段落选音仍需另一层模型。

第二轮数据、训练、推理、评分分别在`dataset-solo-negatives-v1`、`model-solo-negatives-v1`、`inference-solo-negatives-v1`、`evaluation-solo-negatives-v1`，都位于`test-data/physical-drums`。本轮没有将实验权重并入应用或发布Release。
