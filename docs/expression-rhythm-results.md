# 固定节奏骨架对照结果

2026-11-11。本轮使用冻结的《樱花草》候选、人工74 BPM / Offset 178ms /
四细分 / 提前22.5ms，对默认权重0与持续覆盖权重0.25分别跑完整、phase0、
phase1三种方案，共30组。完整方案作为同键数基线；phase0/phase1只对已有
piano scope应用`stride=2`，其他声部没有增加规则，但容量竞争仍会改变
最终其他声部的选择。

## 结果

完整方案重现原结果。10K默认为1496物件/382 LN；10K持续覆盖为1491/425。
半拍phase0为1435/440（默认）和1430/482（持续覆盖），phase1为1391/532
和1390/547。6–10K的完整、两相位结果均通过定轨、容量、落线及`.osu`回读，
主选择和补鼓求解均status=0、gap=0；主求解最长约7.42秒，时间上限仍15秒。

这些数字只证明策略按固定全曲拍格执行。phase1在10K默认中删去223个钢琴
起音，同时因容量重新取舍，鼓实际删4增201，贝斯删6增102，other删16增112；
这不是“钢琴少一半”这么简单，也没有证据说明被删起音都是伴奏。phase0的
10K默认钢琴保留541个起音，phase1只保留182个。LN比例上升主要来自起音
竞争后的选择，不能当作LN质量提升。

`scope_rows`按“段落＋声部＋乐器类别＋起音”计数；报告中的全曲声部变化按
“声部＋起音”去重，不能直接相加。`policy_allowed`仅表示拍格规则允许，
不代表最终入谱；`allowed_but_unselected`也可能来自其它容量或组选择原因。
连续省略串按候选行计算，可能跨自然休止；相邻保留起音间隔不是音频空白证明。
`sustain_ms`是各声部完整LN区间并集，不是有界奖励的时长。

## 结论与限制

固定拍格策略可以作为用户显式的研究选项，但不能自动判定主旋律、伴奏或
重复乐句，也不能直接打开默认。它会显著改变声部平衡，尤其在稀疏相位下
让钢琴、鼓、贝斯和other互相竞争。没有本轮新增原声窗口、试听或试打；
`musical_acceptance=false`。完整证据保存在ignored目录
`test-data/expression-rhythm-v1`，输入哈希和源码快照均在执行计划中。

下一步应转向真正的段落级编排和键型序列，而不是继续扩大固定半拍抽稀：
先识别声部角色与重复乐句，再对每段选择完整/半密度/旋律保留策略，最后让
10K LN定轨搜索评估具体放手、反键和放手后重按。当前训练先验只负责固定
起止和LN的合法轨道偏好，不能弥补错误的起音取舍。
