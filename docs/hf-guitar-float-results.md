# FL 吉他浮点声轨实测与独立审核（2026-11-10）

完整 60 份 GuitarSet 派生输入与 2 条真实全曲吉他声轨的证据已审完。浮点输入、重采样、窗口拼接、两套物理时钟、事件解码和候选音尾来源均与保存的产物相符。两级重采样与原始单级输入并非相同：60 例中有 2 例计分略降。此结果支持继续验证可选吉他采音链路；它没有证明人工制谱、LN 编排或最终可玩性已经合格。

原 ONNX 全窗口协议仍为 **false**。本轮没有改写此前结果，也没有重新训练、调整阈值或据标签挑选音尾。协议见 [hf-guitar-float-input-protocol.md](hf-guitar-float-input-protocol.md)。

## 样本、时钟与独立复核

固定队列保持原 60 份完整 mono-mic 录音，comp / solo 各 30，BN / Funk / Jazz / Rock / SS 各 12。输入转换为 `44.1kHz int16 / 32768 → 22.05kHz float32 → 16kHz float32`，不归一、限幅、裁静音、吸拍或往返 int16。全部 60 例的两级模型 PCM 均与原直接转 16k 的 PCM 不同；本队列两条转换路径的采样数量相同。共享采样的最大幅值差为 0.0214954615，各例差值 RMS 范围为 0.00000300267–0.0000547001。不能把这一新输入链写成“原输入完全一致”。

独立审核脚本不导入应用、Torch 或 ONNX Runtime，仅读取已保存的结果，用 NumPy / SciPy 重建波形、窗口和帧，用独立逐音高状态机重建事件，并用 Hopcroft–Karp 一对一匹配重算评分。62 条的独立重建事件起止与保存事件最大差为 **0 ms**。

原 44.1k 录音长度与应用 22.05k 浮点长度各自构造整数物理帧掩码；逐值核对了完整窗口、研究激活、应用激活、时间数组、完整 raw 事件和两套候选 trace。本批 62 条没有出现额外应用物理帧，两套事件完全相同。两套时钟仍分别保留，不能由本批无差异推断其他输入不会增加边界帧。

60 例共 300 个推理窗口、8914 个全曲 raw 事件（原单级为 8913）。模型阈值仍为 onset 0.3 / offset 0.3 / frame 0.1；10 秒窗、5 秒 hop、100fps，CPU 计算线程 2、跨算子线程 1。独立复核没有执行新的神经推理。

## 音尾与 LN 边界

默认模式保留所有 raw 起止点供检查，但 **0 个模型尾自动取得 LN 资格**。显式启用模型尾时，8914 个全曲事件中仅 4669 个具有模型观察到的尾假设：`frame_decay` 1668，`release_regression` 3001。其余 4245 个仍不允许晋级：`reattack` 4102、`input_boundary` 110、`frame_inactive` 33。

两种模式的每个候选与 trace 已核对原始事件、毫秒取整、音高、固定权重 1、声部及尾来源；所有 `authored_ln_verified` 都为 false。候选数量并非最终谱面数量，4669 也不是“应当写成 LN”的数量。重弹截断不等于真实放手，模型支持的尾仍需要声部表达方案、来源能量和编排流程继续筛选。
