# ManiaLab 0.1.0-alpha.3 — 对音与落线修复

下载 `ManiaLab-0.1.0-alpha.3-windows-x64.zip`，完整解压后运行 `ManiaLab.exe`。无需安装 Python 或 Docker。

- 修复上一版吸附仅覆盖部分音符的问题。短键起点和 LN 起止完整量化，生成与导出的实际 `.osu` 都逐个检查落线。
- 编辑器默认细分跟随所选三等分 / 四等分，不再始终写成四等分。
- 自动 BPM 接近 `.25 / .333 / .5 / .667 / .75` 时保留分数，其余取整数；210.00073 会变成 210。改变 BPM 后重新拟合 Offset，自动 Offset 使用整数毫秒。
- 增加「按当前 BPM 重新估计 Offset」和「粘贴参考 Timing」。例如粘贴两行 `BPM: 210`、`Offset: 91`，应用、试听确认、重新生成即可。
- 自动 Timing 不可靠时停止生成；旧候选和改 Timing 后未重新生成的候选不能导出。重新分析后显示新的 Timing。已有原生 mania 谱面严格重定轨保持原始时间及变速。
- 分析完即可下载「分析 JSON」，无需先生成谱面，便于反馈 BPM 候选和全曲偏移诊断。

**升级后请重新分析音频并生成整谱。** 音高缓存可复用；旧候选保留供查看。

63 项自动测试通过；页面回读导出文件验证端点落线。落线检查只允许整数毫秒存储的舍入误差，**不代表采音正确或手感合格**。用户《有点甜》的相同音源尚未取得，自动 Offset 118ms 与参考 91ms 的差异仍待真实复现，本次没有硬编码减 27ms。

此版本仍为实验版，未训练专用 10K / LN 模型。完整证据和边界见 `docs/validation.md`。
