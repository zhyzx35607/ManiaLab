# Nova鼓轨继续分离：尚不能替代采音

2026-11-09。使用[LarsNet作者源码](https://github.com/polimi-ispl/larsnet)、README链接的官方权重及[事前协议](larsnet-protocol.md)，完成《樱花草》全曲五类鼓分离。来源提交`17d631fd18e77ee2f1d23ee7b3fc0fb46ae629e2`；权重包SHA256为`dd785d77f66413c5acbd3a4cedac02951578c838496d059930c43f159647c907`。权重的CC BY-NC 4.0许可只用于本地研究，未随应用分发。

输入是原Nova鼓MP3重新解码的44.1kHz双声道float，长度12517344样本。五条轨全部保持该长度，没有峰值归一化或int16截断。采用上游默认非Wiener方法，仅逐块处理网络批次以降低内存；前两个块的整批/单块输出最大差异为0。CPU两个线程完成本次分离约126.4秒。运行使用PyTorch2.9.1+cpu，上游环境文件为2.1.2；严格参数加载与本次批次对照通过不等于所有环境行为都已经验收。

使用原应用起音检测器逐轨处理，没有对本曲调阈值。统一减去既定22.5ms作者提前量、40ms容差后的结果：

|范围/类别|匹配/作者事件|模型提出|F1|
|---|---:|---:|---:|
|全曲kick|353/360|510|0.8115|
|全曲snare|92/140|263|0.4566|
|全曲hi-hat对第4列|98/132|617|0.2617|
|后段kick|126/127|179|0.8235|
|后段snare|30/45|66|0.5405|
|后段hi-hat对第4列|58/75|181|0.4531|

第4列包含tom等，表中只用hi-hat分离轨进行明确受限的对照，不把作者第4列当成纯hi-hat真值。加上tom/镲片后召回更多，但新增事件也大幅增加；完整诊断并集留在报告，没有挑最高映射冒称音色准确率。Reference是作者取舍，额外事件可能是未选声音；还需要物理标注及试听来区分串音与合法额外起音。

## 分离证据辅助作者取舍：失败

随后按[独立事前协议](larsnet-selection-protocol.md)，保持原1387个候选，给原局部频谱分类器增加五条分离轨的45维局部能量特征。模型与阈值只由前段/中段拟合和选择；原float对照的所有区间分数和分组召回逐项重现。

|后段类别|原float分类F1|加入分离证据F1|后者匹配/参考|后者提出|
|---|---:|---:|---:|---:|
|kick|0.9555|0.9647|123/127|128|
|snare|0.9286|0.9070|39/45|41|
|第4列|0.3502|0|0/75|15|

第4列在中段已经只匹配3/16，后段全部漏选。不能为保住kick的小幅增益就整体启用，也不能调低后段阈值掩盖失效。模型名对应的分离轨并不保证音色纯净；分离结果与作者事件之间仍有分布差异，简单追加特征没有学到稳定取舍。
