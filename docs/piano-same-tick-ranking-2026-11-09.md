# 同刻错声部排序：误连减少，旋律保持仍退步

四轮训练已结束。把正确后继时刻内的已知错误声部加入排序后，同刻误连减少，但重叠输入的完整真后继组更少，交叉旋律控制还丢失了4条原本正确的连接。本轮不采用新权重，不接入应用，也不据此生成新安装包或重新推理《樱花草》。音乐验收仍未完成。

这次只改变辅助排序的负组范围：在原来其他时刻的负组之外，加入正确时刻内的已监督负边。所有和弦正目标仍参与比较，未知边仍不进入辅助损失；组均值分母随新增组改变，没有新加权系数。数据、原预训练起点、seed42、四轮、优化器、0.1倍辅助项、输入轮换、选轮和解码保持固定，见[运行前协议](piano-same-tick-ranking-protocol.md)。

训练仍是127份作品、511窗，验证是9份作品、36窗。clean、音尾延长1拍、延长2拍是同一作品的三种观测，不能算27首独立验证歌曲。按三种观测的逐曲raw宏F1等权平均、epoch0也参加选择，选中epoch4，分数0.775045；原BCE为0.770829，前一轮异tick排序为0.769282。训练计时628.281秒，每轮510次有效更新，其中500次含排序。分数上升没有消除以下退步。

## 验证与后续

全量722项通过，29项因应用环境无Torch跳过；研究环境实际通过新旧排序相关72项测试，覆盖这29项梯度检查。同刻错误分类另有9项测试已包含在全量内。未知边直接梯度为0、和弦每个正确目标参与、同刻已知负边产生梯度、没有同刻负边时与旧损失一致等均已检查。这些验证实现正确性，不证明成品音乐性。

独立复核已通过27组逐曲配对、五轮分数与选轮、损失分解、身份链、逐边双向转移及完整真后继组核验；六控制另从保存结果重建真值和解码。交叉控制新增漏连均为各小节的pitch 64→68，raw已判为负，不能归因于解码器。独立报告SHA256分别为`b51592cf7b4da75c8781cf6f7d57d98984934fccb26738c6a0a0f18aadce1895`和`1d2b562d5b65f164f1f451c5f115fac6da710108966079f640b8948dd80cc031`。

本轮只读train/validation，不读test源；历史曾为格式检查打开一份test源的记录仍保留。研究数据、逐事件缓存和权重留在本地`test-data`，公开JSON只保留汇总、逐作品计数与运行身份。

原音分析与这里的声部连接训练分开取证：[波形和频谱检查](piano-attack-evidence-2026-11-09.md)能定位可疑采音，[真实录音反例](piano-harmonic-coincidence-2026-11-09.md)已经说明不能仅凭泛音关系自动删音。本轮没有直接试听，没有改变音符起止或LN规则。
