# 相同钢琴采音的三权重连接对照

真实《樱花草》的三组推理和四段回放页面已完成，原始1557个候选的起音、音尾、音高、力度和ID均未改变。结果仍不足以进入自动LN：适配模型改变了很多局部连接，但没有真实声部标签证明这些变化正确。同一来源音仍可能指向多个不同起音位置，不能直接把这些边拼成稳定旋律。

此次输入表示与持续事件训练一致，使用固定4小节core与前后各1小节上下文，共22窗。每个事件只拥有一次输出，全部监督mask为false；全曲共有86113条归属明确的voice候选，其中同起音小节14332条，跨小节71781条。三权重的输入完全相同，分别是原预训练、clean适配epoch1、重叠适配epoch4。只比较raw heads，阈值固定0.5，没有官方后处理或全曲连通合并。

“多个起音组”按目标/来源的起音tick去重，同起音和弦不会因为多个音符被重复计数。表中数量不是错误率：只有原始模型预测，没有声部真值。尤其clean模型虽然分叉更少，但此前已在踏板控制丢失正确连接，不能按图更稀疏就选用它。重叠适配相对原模型新增382、去掉1623条同小节边；这些也不分别等于修正和损失。

已查看全部四张图：原物理音符区间、三组连接共用相同时间轴和音高范围。Core8中12/16/12条连接被片段边界裁剪，表格仍保留全部归属连接，未把它们当作可见完整线条。其余三段没有此类裁剪，所有片段均无完全在图外的归属连接。四段原音按精确样本范围导出16bit WAV，读回与预期PCM逐样本一致，gain均为1。当前没有直接试听本地音频的工具通道，因而没有人工听感验收结论。

图内可见高低音区、持续区间和重复起音的结构差异，但这不能证明每个候选真实存在，或连线属于同一旋律。短高音候选、混响拖尾等仍需声学证据；此前针对无持续激活候选的整类删除会损失真实起音，未启用。

输入量化仍沿用人工74 BPM、Offset178ms、22.5ms提前量与每拍四细分。图形位置使用原始采音时间，量化只用于诊断网络输入。这轮没有评估自动Timing，没有重新采音、训练或生成新LN，也没有发布安装包。

独立核验101份推理产物的哈希，并从22公共图和66预测NPZ重算全部汇总，结果一致。适配层与片段/显示边界共44项测试通过。原音、逐事件记录和研究权重只保留在忽略目录：推理为`test-data/piano-svsep/audio-events-v1`，回放为`test-data/sakura-benchmark/piano-event-review-v1/index.html`。公开JSON只包含汇总与身份。
