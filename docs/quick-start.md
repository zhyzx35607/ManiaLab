# 第一次用 ManiaLab

完整解压 Windows ZIP，双击 `ManiaLab.exe`。浏览器打开的是本机程序。保持控制台窗口开着，结束时关闭它即可。四／六声部模型和 CPU 运行时已经包含在完整包中。

## 先得到一份可以检查的谱

1. 导入歌曲，选择「深度：四声部分离后采音」，点击分析。需要单独检查吉他或钢琴时，可改选六声部；分离类别更多不保证更准，建议对同一段比较试听。第一次会实际运行模型；再次调整检测门槛时可复用缓存。
2. 先处理左侧 BPM / Offset。打开「对音实验室」，在歌曲开头、中间、结尾分别播放拍线提示。若已用其他工具对好，直接粘贴参考 Timing，再试听确认。
3. 选择目标键数，展开「这首歌怎样写」比较三个本地方案，查看分段理由后采用。第一次可从标有「建议先试」的方向开始，也可以直接手调。再点击生成，先听起音是否抓对，再检查 LN 的收尾。
4. 使用「下载 .osz」，把谱包拖入另一台电脑的 osu! 试打。保存分析 JSON 可以用于定位问题，它不包含音频文件。

还没有对好 Timing 时，提高 LN 比例或更换布局不能解决错位。自动 Timing 提示不稳定时，先检查提示的区间和精确 BPM 候选。

三个方案的区别是声音取舍与编排负担。「旋律与放手」保留较少物件、减少占轨和同手短键配合；「均衡 Hybrid」兼顾节奏与持续音；「密集多声部」保留更多层次，通常需要更多同手协调。它们不是固定星级，也不会因为歌曲属于流行或电子就强制套某一种风格。

本地建议按较强的检测音计算，采用后使用同一候选范围。原始采音一直保留；想自行选择弱音，可以清除段落建议。采用方案后仍可调密度、LN 比例和协调滑块，分段参数会跟随调整。改变 BPM 或键数后重新选择方案，避免旧的短 LN 阈值和占轨建议继续生效。当前分段是约 15 秒分析窗口，不能当作已经识别的完整乐句。

拍线检查下方可以直接点击可疑区间，自动定位并打开对音实验室，再点「试听当前拍线 A」。没有可疑区间时也会提供开头、中间、结尾三个位置；改动 BPM 或 Offset 后，旧区间诊断立即清除，需要重新检查。

## 怎样比较 BPM 和 Offset

`105` 与 `210` 是同一节奏的半速 / 倍速写法，但相同「拍内细分」对应的时间间隔不同。要表达更细的节奏，可以选更细网格；不需要把检测到的小数噪声保留下来。手动输入真实特殊小数也受支持。

Offset 需要和 BPM、细分、音源一起比较。相差整拍的两个 Offset 可以画出相同的重复拍线；数值更小不代表更准确。以完整歌曲的对齐为准，不能只校准第一声。

新项目的「制谱提前量」默认 **22.5ms**。这是与参考工具一致的显式初始约定；设为 0 使用原始音频时钟。输入参考 Offset 时直接输入它的结果，程序不会再对输入值减一次。更改提前量后需要重新生成，以保证全谱时间一致。

用户提供的那份《有点甜》中，参考工具自动 `209.998 BPM` 对应 `91ms`，固定 `210 BPM` 则对应 `93ms`；本版四声部固定 210 重新拟合也得到 93ms。它不适用于同名歌曲的任意音源版本。

## LN 设置究竟改变什么

| 设置 | 意义 | 调整后的主要变化 |
|---|---|---|
| LN 目标比例 | 长条数 ÷ 总物件数 | 55% 表示约一半物件为 LN，不表示一半播放时间都有长条 |
| 最短 LN | 小于此时长的检测音作为短键 | 默认 240ms；想保留较短 LN 时降低，不能借此补出检测不到的持续音 |
| 最大同时 LN | 同时保持按下的长条上限 | 降低后为其他短键留下更多轨道，实际 LN 比例也可能下降 |
| 跨音高人声长条 | 采用连续人声区间的倾向 | 增加时可跨过音高变化形成较长手势；需要回听呼吸、串音和收尾 |
| 放键间隔偏好 | 放键后紧接同轨起音的代价 | 用于布局取舍；严格重定轨不会为满足它而改变原谱时间 |
| 声部取舍 | 鼓、贝斯、人声、伴奏，以及六声部方案的吉他、钢琴候选权重 | 0 表示该声部不参与新谱；它不是试听音量滑块 |

程序会同时报告目标、实际和约束下的可达比例。目标 55%、实际 38% 可能是持续音证据不足，或占轨与密度限制所致。没有可靠持续依据时，调到 100% 也不会把所有空白补成长条。

LN 配合控制中，分手倾向减少一只手按着 LN 时再打短键，Hybrid 增加这类配合；放手协调倾向减少同手相近但不同步的释放；反键接续偏好把已有 LN 尾端与下一起音放到同轨，不会填满空白造长条。这些是偏好，不是难度保证。

选中音符后展开「修正选中的音符」，可调整起止、轨道、长短键，或增删物件；波形选点可作为新起止位置。保存后生成新候选，原候选仍可切回。严格保时模式只允许换轨。

## 找到问题后怎样比较

- **采音不对**：切到采音证据，分别试听鼓、贝斯、人声和伴奏；点音符看原始起止，再打开波形。降低门槛能找到更多弱音，也会带入更多混响和误检。
- **Timing 不对**：用对音实验室的 A/B 比较 Offset，分别听开头和结尾。只有结尾越来越偏时要重新检查 BPM，不能仅平移 Offset。
- **音对但表达不合适**：调整密度、声部和 LN 设置，保存候选对比。密度是每秒物件上限，不是星级；同样的物件数可以有不同手感。
- **LN 收尾或键型不顺**：选中长条后，点波形对音中的「查看 LN 尾端」，比较检测音尾与量化尾端。再打开谱面检查，定位短放键接续和同手 LN 密集位置。提示是试打线索，某些目标风格会有意使用这些键型。
- **已有喜欢的谱**：从参考谱取偏好，提取它的密度、LN 比例、长度和占轨规模；目标键数保留。参考只改变数量偏好，不会复制那首歌的音符。

最近 8 个候选会保留。切换候选后可以直接试听；改变 Timing 后要重新生成整谱，再导出。局部重写用于保持范围外物件，不能把不同 Timing 混在同一候选里。

## API 助手与原模型

API 助手是可选项：填写服务商的兼容接口地址、模型名、密钥和编排要求。它读取本地统计，提出全局或分段参数；不会听到歌曲，也不应被当作采音模型。没有 API 也能完成全部本地分析和生成。

Mapperatorinator 原模型是另一项可选对照，首次安装需要联网和额外磁盘空间。它与默认四声部路径不同，不需要为了使用 ManiaLab 而安装。

建议保留「使用当前 Timing」，先确认 BPM / Offset 和拍内细分。新生成的模型谱会按这条拍线量化，再进行 LN 定轨；原始模型输出保存在项目的 `engine-*` 目录。界面报告移动超过 30ms 的起音和不足一格而转为短键的 LN，请回听这些位置。导入现有谱面的严格重定轨仍保留原始起止。

## 更新和反馈

新版本解压到新文件夹即可。项目默认在 `%LOCALAPPDATA%\ManiaLab\projects`，不会存进程序 ZIP；另一台机器可复制整个项目文件夹。普通试打只需复制导出的 `.osz`。

反馈时最好保留版本号、键数、BPM / Offset、制谱提前量、问题秒数及分析 JSON。音源版本会影响对音，歌曲名称相同不足以复现。当前 alpha.5 仍需要人工试听与试打，完整落线只是必要条件。
