# 《有点甜》同文件 Timing 对比

日期：2026-11-07。此记录更新 alpha.3 发布时“尚未取得相同音源”的状态。这里只证明数值差异的来源和导出落线，不把参考工具输出当作音乐起点真值。

## 输入与复现

用户提供 `audio.mp3`，9,410,478 bytes，FFmpeg 解码时长 235.200590 秒。SHA256：

`08b6aff5db874fca7718c6bab0b7c97e01b59648531bfd0c53d5b1628346010d`

| 程序 / 条件 | BPM | Offset / ms |
| --- | ---: | ---: |
| ManiaLab alpha.2 原算法 | 210.00073 | 118.373 |
| ManiaLab alpha.3 | 210 | 117 |
| 用户的分析Timing，自动 BPM | 209.998 | 91 |
| 同一分析Timing，固定输入 210 BPM | 210 | 93 |
| 分析Timing测试副本，自动 BPM，22.5ms 常量改为 0 | 209.998 | 114 |
| 同一测试副本，固定输入 210 BPM | 210 | 115 |

用户反馈的 alpha.2 数值被逐位复现。alpha.3 的取整与量化没有消除自动 Offset 差异。固定 BPM 时需要重新拟合 Offset，不能直接把自动结果 209.998 / 91 只改成 210 / 91 并声称两者完全等价。

将同一 MP3 解码为 44.1kHz 单声道 PCM WAV，再送入原版分析Timing：自动返回 209.999 / 93，固定 210 BPM 返回 94。解码路径差异很小，不能解释主要的二十多毫秒差值。

## 已确认的固定补偿

用户提供的分析Timing.exe，版本 v0.32.4 alpha，SHA256：

`8ee122f8e6b3f7a87177a655e6dba0904c961f598c68e64075ac7a2e17bb9f1f`

静态检查发现输出 Offset 前在 VA `0x403f77` 执行减法，读取 VA `0x41a758` 的 double 常量 22.5（文件偏移 `0x18d58`）。输出为整数，因此替换后的显示差值可能为 22 或 23ms。

为验证因果关系，仅在被 Git 忽略的测试目录内制作副本，将该 double 改成 0，其他内容保持相同；原文件未修改。新旧文件长度一致，实际仅三个非零字节改变（文件偏移 `0x18d5d`、`0x18d5e`、`0x18d5f`）。两组真实歌曲输出见上表。此前已知物理起点 347ms 的 137 BPM 脉冲样本，也从 322ms 变为 344ms。

这确认 22.5ms 补偿解释了程序差值的大部分。它为什么存在、是否对应某个版本的播放器时间基准、是否符合当前用户的 osu! 播放环境，尚未证实。不能把去除补偿后的数值直接称为真值，也不能据此对 ManiaLab 所有音频统一减 22.5ms 或 27ms。

另外尝试了频段包络和谐波/打击声分离后的起音拟合。该歌曲的打击声拟合约为 111ms，但没有足够证据认定这一方法在各类歌曲上更准确，未将这些实验替换进正式算法。

## 真实全曲导出检查

实际运行整首音频的 Basic Pitch 模型，取得 4,120 个候选。使用当前默认 10K 编排参数，按固定 210 BPM / 93ms 完整量化后生成：

- 1,465 个物件，其中 310 个 LN，实际比例 21.2%。目标默认 55% 未达到；受持续音及占轨约束限制，不等于音乐表达已合格。
- 所有短键起点及 LN 起止共 1,775 个端点，回读真实 `.osu` 后离线数为 0，最大整数毫秒舍入误差 0.4286ms。
- 生成 117ms 对照版时，把 93ms 版本的红线、全部起点及尾端统一后移 24ms；逐物件确认数量、轨道、LN 长度和类型完全一致，只有整体 Timing 不同。
- 两个版本均通过结构和导出网格检查。它们用于试听和游戏内比较，不作为成熟谱面质量的展示。

音频、参考程序、修改后的测试副本、原始诊断数据和含音频的对照谱包均只保存在本地 `test-data/`，不提交到仓库、不放入公开 Release。对照谱包为 `YouDianTian-Timing-93-vs-117.osz`；另生成音乐第 50–70 秒的两份节拍器对照音频。

结论：alpha.3 修复的完整落线已在这首真实歌曲上通过；91 / 118ms 的数值差异主要来自参考工具明确执行的固定补偿。音频检测、游戏播放时间基准和人的对音判断仍需分别验证。本轮未据单首歌曲修改全局补偿，也未发布一个声称自动 Offset 已彻底修好的新程序。
