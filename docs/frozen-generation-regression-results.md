# 冻结多曲生成回归结果

2026-11-17。修复了跨段落 LN 容量漏检与源音组被整体省略的问题。10个已有开发片段、66组配置完成修改前后重放，全部通过结构、网格、输出容量和导出回读检查；这不是采音或音乐质量验收。

## 已实现的修复

结构化选择先生成各声部真正可选的和弦层，再用这些候选共同构成检查时刻和合排容量。最轻音组如果独自也无法满足未来约束，就按原起音拆成可独立取舍的组。已经被静音、去重、节奏遮罩或和弦层永久省略的候选不额外收紧容量。没有修改声部效用权重或研究默认值。

无结构历史分析的 LN 选择同时检查段落起点和终点；没有新起音也执行持条上限。已选起音保持不变，只选择能完整保留的 LN；不会裁短音尾来通过约束。纯段落边界的密度语义保持原样。

## Timing与证据限制

- 原有自动Timing仅3/10片段通过门槛。重复配置计数为默认9/26、分段12/40，修改前后相同；诊断生成显式确认冻结时钟，未绕过产品的自动门槛。
- 默认26例累计选中起音移动超过30ms为2,182次，完全不变；分段40例为5,078→5,080次。它们是跨配置重复计数，不能解释为独立声音数。没有改变Timing、起音校准或量化算法。
- 历史分析中选中LN的音尾来源字段全部缺失：默认1,363次，分段7,976→7,986次，均明确记作unknown。未出现已明确禁止的音尾类型，不代表这些未知音尾已被验证。
- 独立容量审计覆盖最终输出和段落边界。它不重建被省略的可选起音及其原音频段偏好；完整候选约束由生产求解器直接复验其矩阵，另有定向合成回归。不能将两者混称为完整独立容量证明。
