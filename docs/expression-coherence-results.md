# 相邻节奏组连贯取舍结果

2026-11-11。完成固定0.25权重的6–10K真实候选对照。它可以减少相邻组的
选中/落选切换，但有一部分通过省略整个短插奏实现。**暂不启用默认策略**，
也不把该指标作为音乐质量分数。应用仍使用PR15的选择结果。

## 实现与控制

研究入口为 `select_expression(..., coherence=.25)`；普通应用默认0，未增加
用户设置或自动推荐。联系仅作用于同段、同来源、同预测类别和同角色的相邻
音高组，没有连接音尾或覆盖原检测。具体规则在运行前写入
[协议](expression-coherence-protocol.md)，本轮没有按真实结果调权重。

13项控制验证：轻微评分交替时可以连续保留一个来源，明确的来源优势仍可
切换，跨段/长起音间隙/局部参数边界不联系，未选高分和弦不能抬高惩罚，
孤立独奏与原音尾保留；相关检查共151 passed。控制验证编排规则，不是音乐
偏好的独立标签。研究调用之外不改变返回的选音、决策或报告字段。

## 回到原声音轨

先保留原16–24、96–104、200–208秒三个窗口；它们的other选择没有变化。
96–104秒其他声轨有2个钢琴物件进入、2个鼓物件退出，不能说整段谱面不变。
为核查实际改变的other，另取**所有**含变化候选原起音的8秒分箱，没有排名
或挑选有利案例：8–16、184–192、208–216、216–224、256–264秒。

8张原波形/频谱/原检测/新旧谱面图均已实际查看，24份原声及起音/放手click
预览写出并回读。图中谱面使用真实播放时间，没有撤销22.5ms提前量。
所有彩色模型类别共享同一条Nova other波形，不是独立音轨。

- 8–16秒：原8.692和9.097秒的ethnic类让位，9.097、9.908、10.313秒的
  pizzicato类连选。图中存在连续的多次宽频起音，但这不能验证模型乐器名称。
- 184–192秒：185.043–186.664秒的pad类物件消失；原频谱仍有持续成分。
  不能把这个空白解释为真实静音，其他声轨的预算竞争必须一起考虑。
- 208–216秒：增加209.367–210.989和209.773–210.989秒的brass类LN，
  是已有候选进入，未从波形重新识别新音。
- 216–224秒：两个原pad类LN退出，一个218.286秒MIDI98短音进入。
  更少的组间切换没有保证保留原持续层，且不能凭混合频谱判定高音是独立音符。
- 256–264秒：原258.016–261.259秒pad类MIDI59，改为原候选中的
  258.016–259.637秒strings类MIDI62；较短持续来自另一候选，未剪断原LN。

没有直接听取本地音频的接口，因此这里是原声图像及文件核查，不是亲耳试听
或试打通过。click只表示首尾时机，不合成乐器音色或证明和声正确。

**结论与下一步：** 连贯惩罚能改变组间取舍，但不足以决定本段应表达哪个
声音；本版保留为可复现研究入口，不继续用减少切换数来选择权重。下一步需
区分声源证据、短插奏价值与段落角色，再决定哪些联系值得保留；不能把所有
同模型类别都当成已确认的连续声部，也不能以少采音换取表面稳定。
