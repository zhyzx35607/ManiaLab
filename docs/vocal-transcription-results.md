# 人声专用模型对照（2026-11-10）

决定：当前ROSVOT默认参数没有达到替换现有人声采音的条件。
40份vocadito全部完成，A1/A2分别评分；起音和完整音符区间总体均退步。
不能因为它是人声专用网络就把较差结果接入默认流程。

协议见`guitar-vocal-benchmark-protocol.md`，实际CPU适配见
`other-instrument-model-survey-2026-11-10.md`。完整原音频输入，原PCM不归一化，
没有歌词、节拍、谱面或标签输入，也没有按答案校准偏移。比较现应用的
Basic Pitch采音管线与官方默认阈值ROSVOT/RWBD/RMVPE组合。

标准指标为50ms起音、精确半音；完整区间另要求尾误差
≤max(50ms,参考音长20%)。以下micro均保留全部40例及窗口内全部预测：

| 标注 / 系统 | 参考 / 预测 | 起音匹配 | 起音F1 | 完整区间匹配 | 完整区间F1 |
|---|---:|---:|---:|---:|---:|
| A1 / 现应用 | 1854 / 3455 | 1269 | 47.81% | 725 | 27.31% |
| A1 / ROSVOT | 1854 / 1712 | 465 | 26.08% | 326 | 18.28% |
| A2 / 现应用 | 1580 / 3455 | 1132 | 44.97% | 629 | 24.99% |
| A2 / ROSVOT | 1580 / 1712 | 448 | 27.22% | 360 | 21.87% |

固定40ms起音/80ms尾容差也没有反转结论：A1起音44.34%→20.86%、完整
区间28.33%→15.87%；A2起音41.75%→21.93%、完整区间26.38%→18.96%。
单例起音F1分别只在A1的1/40、A2的3/40例提升。完整区间单例提升9/40、18/40，
但聚合后仍退步；不挑这些例子作为总体成绩。

第一份录音的逐音诊断可见提前、音高误差和重复切段：A1首音为约
0.662–0.952秒、pitch50，模型给0.549–0.912秒、pitch49；A1的
1.318–2.165秒pitch53被模型分成1.349–1.637和1.637–2.176两段。
这是已保存事件的比较，不是直接试听；不能用单例归纳所有失败原因，也
不能将标注视作毫无争议的歌唱起音真值。两位标注者之间本身存在分歧。

现应用在人声上的成绩也不理想，失败候选不意味着现有实现合格。
继续测试Tsumugi人声专用权重，并区分歌唱音符与可供制谱选用的词/乐句。
模型note/word边界不是玩家应该何时放LN的答案。
