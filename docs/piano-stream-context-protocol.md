# 固定权重的上下文敏感性检查

2026-11-09，在上下文对照首次推理前固定。本轮已完成的八轮适配和留出结果不重选；检查原模型原候选与已选定epoch5适配模型扩候选两种流程。

验证集16份谱的完整缓存（各前16个有音符小节）与按训练规则切成最多四个有音符小节、目标不超过500音符的窗口比较。原时长/整小节延音各一遍。延音增强先在完整缓存上冻结，再截取窗口，确保同一音符的起音、音高、时长、拍号相同；不让窗口外同音重弹的截断差异混入上下文对照。声部/和弦候选边的全局集合必须一致，局部索引映射回唯一原索引，不直接拼接局部组件编号。

记录谱表分类翻转、谱表分类头输出分数差（该头有Sigmoid，不误称原始logits）、相同候选边的声部/和弦原始logits差与0.5概率门槛翻转、后处理边差及同小节连通关系差。评价原谱同 `(staff, voice)` 的成对分组F1与逐曲宏平均，不用这些验证结果重选已锁定权重；不读取测试集数组或用测试分数调参。

《樱花草》冻结1557钢琴候选的整曲输出必须复现上一轮保存结果，再与四小节窗口比较。仍使用原已给定图时间和段落，不改采音、Timing或LN端点。统计谱表/组件分组变化，以及同一连续起音规则的长短表达翻转，只描述敏感性，不按LN数量选上下文。

上游GraphNorm没有传batch，四小节与完整图的归一化总体不同；观察关系边也因窗口重建变化。特别是原rest构图在没有未来起音、但仍有更晚音尾时，可能把当前音连接到窗口全部节点。逐关系记录完整图跨窗口边、完整图内部但局部缺失的边、局部新增边，以及rest中不指向音尾之后起音的数量。因此本实验测多项因素共同造成的输入上下文敏感性，不将结果全部归因于GraphNorm，更不据它宣称哪一种声音表达正确。若有明显差异，后续单独固定节点/边隔离归一化，再决定产品实现；本轮不改默认模型。
