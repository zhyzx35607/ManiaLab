# 音尾声学判断学习实验

2026-11-09。**真实弦乐对照仍有退步，不进入应用默认流程。** 本次只研究物理音符结束时刻，不把这些结束时刻直接当作作者 LN 放手。

同日计分修订：旧完整区间评分会排除音尾越过30秒的预测，可能漏算错误长音。现在将全部评分窗内起音保留在分母，18个输入的参考音尾均在原32.1秒上下文内可观察。重算使用保存的音符和决策，未重新推理、训练或校准；0.95门槛仍为原来的选择。旧报告保留，当前数值见[修订统计](acoustic-release-learning-v2.json)。

## 数据、任务与约束

从已核验的 URMP 原始录音和对齐 `Notes_*.txt` 中，固定选择公开比较划分以外最小四个 ID：3、4、5、6。3/4/5 的所有独奏与混音用于拟合，6 的所有独奏与混音用于校准；每个输入前 30 秒，追加 2.1 秒上下文。共 12 个输入、24 遍 YourMT3 推理，分别使用原窗口和半窗口相移。四首涉及长笛、单簧管、小号、萨克斯。

权重、候选匹配规则、28 个特征、拟合/校准/比较曲目、阈值列表和并列选择规则在拟合之前固定。原音频模型曾使用此数据集训练；音尾小模型的监督按作品隔离。此前已经检查过的作品 1/2 继续作为比较，不能称全新盲测。

每个候选有原音尾和另一个窗口预测的显式音尾。相同乐器和音高、起音差不超过 50ms、一对一匹配，不跨同音高重弹。候选两端都必须位于评估区间内，不能通过延长到区间外移除假阳性。起音、音高、乐器类别和物件数固定，不生成新的端点。

特征包括音高前六次谐波的能量、总能量、谐波占比、音尾前后变化、局部持续长度、端点来源、与窗口边缘的距离、附近模型结束事件和同时活动的音符。使用原物理时钟，不吸附拍线。标注只为拟合样本提供两个音尾的误差比较，不进入预测特征。

三个拟合作品共获得 177 个可明确区分的候选对：76 个替换后更好，101 个更差。按作品等权拟合 L2 logistic 模型。校准只在作品 6 上比较事先规定的阈值，先选完整音长 F1，再选改动更少、阈值更高者。最终阈值为 0.95；该数值是模型分数门槛，不等于 95% 实际正确率。

## 结果

在冻结原门槛的条件下，校准曲三个输入平均固定容差音长 F1 从 0.7237 到 0.7302，共改动 3 个音尾。原计分方式的历史值为0.7224到0.7290。拟合组只修改了小号混音的一处音尾，其余未改。校准收益不能当作泛化验收，固定80ms对短音也并非比标准50ms下限更严格。

|已有弦乐对照|音尾改动数|固定 40/80ms 音长 F1 前→后|
|---|---:|---:|
|Jupiter 小提琴|0|0.8333→0.8333|
|Jupiter 大提琴|0|0.6512→0.6512|
|Jupiter 混音|0|0.6825→0.6825|
|Sonata 小提琴1|0|0.9091→0.9091|
|Sonata 小提琴2|0|0.9062→0.9062|
|Sonata 混音|1|0.7771→0.7657|

比较组唯一采用的修改造成退步，没有足够证据启用。原来的采音漏检也完全保留；模型没有声称解决这些问题。

报告同时保留标准相对音长容差和固定容差，以及精确 program 匹配诊断。URMP 的粗萨克斯标签被预处理成 program 65，冻结转录词表可能归为 64；不把精确 subtype 的不一致直接解释成完全不认识萨克斯，也不使用这项诊断选择阈值。

完整统计与哈希见 [修订报告](acoustic-release-learning-v2.json)，[历史报告](acoustic-release-learning.json)保留原计分和校准选择。原始录音、逐音符标签、修改明细和权重保留在忽略目录。尚未满足音乐质量验收，也未发布 Release。
