# 持续音方案的有限覆盖奖励

2026-11-11，规则在真实全曲重放前固定。本阶段检验表达层的取舍，不重新
采音，不用谱面标签筛选，不把较长持续当作主旋律。

现选择器按起音奖励选择乐句；即使声部明确采用`sustain`方案，持续区间
仍只消耗持条/占轨容量，没有表达收益。因此实现可选研究参数
`sustain_coverage=.25`，默认0，先验证下述固定方案。

- 只奖励`sustain`方案中已有的pitch长音，且`release_reason`非空、未被
  `UNOBSERVED_RELEASES`排除。这只是现有尾音资格规则，不代表真实按键放开
  时刻已被独立确认。不奖励tap、瞬态、未知尾、合成phrase或support覆盖项，
  不改原首尾、力度或类别。
- 每个候选只在`[start, min(end, start+2拍))`提供奖励。每拍奖励
  `.25 × 既有_attack_value`，主声部沿用既有2倍系数；每候选最多相当于
  半个起音价值。这个截断只约束奖励，不剪裁真正LN。
- 同起始段落、同来源voice重叠的选中音取**最大**价值后积分；同和弦多层
  或模型类别拆分不会重复计时。不同来源独立，类别本身不加分。
- 用时间端点划分区间，最大值用既有阈值覆盖的二元辅助变量精确表达；
  只有包含该持续音的选中方案才能取得奖励，不能借落选高分音。
- 不连接相邻音尾，不奖励省略，不改变段落方案或节奏组边界；不启用上一
  阶段的coherence。密度、持条、轨道与放手间隔仍为原硬约束。

先用最小反例证明选择器能执行已有持续音偏好，控制更强起音仍可胜出、
未知尾无奖励、重叠不重复、两拍封顶及不同方案不受影响。再用冻结的
`chord-evidence-ties-v1`逐音复现默认路径，完整6–10K重放研究方案、定轨、
导出回读。固定人工时钟74 BPM/178ms/提前22.5ms/四细分不变。

报告每声部起音和LN变化、被移除/新增的已有候选、覆盖收益及求解间隙。
保留原16–24、96–104、200–208秒原声对照，并列出全部变化的8秒分箱；
另检查已定位的216–224秒，不能只展示长条变多的片段。明显新增损失、
高音误采和原音尾误差必须保留；覆盖值不是准确率或音乐验收。
先据真实变化决定是否接入，不在同一曲上搜索权重。音频、逐音数据和模型
继续保留ignored `test-data/`，不重读MAESTRO保留测试。
