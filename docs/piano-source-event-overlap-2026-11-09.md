# 重叠音输入训练：修复一个反例，仍未进入正式生成

固定四轮训练已完成，按事先声明的三种验证观测等权平均选epoch4。局部记谱后继宏F1平均由0.693105升至0.770829；原先clean适配完全失败的模拟踏板控制，本轮恢复为28个正确连接、15个误连接、0个漏连接。交叉旋律仍有漏连，谱表准确性也退步，因此不将这组研究权重接入应用，未发布新的安装包。

本轮从原上游权重重新开始。使用与clean实验相同的136份train/validation源，保留547个core窗口。增强只把观测结束延后1或2 quarter，遇全曲同音高下一次起音封顶且不缩短原持续；不能用增强后的结束改写后继真值。前三轮每个train窗口分别见过clean/plus1/plus2，第四轮重复第一轮分配；每轮510次有效更新，另有1个无监督窗口跳过。固定学习率、阈值、种子和选轮规则见 `piano-source-event-overlap-protocol.md`。
