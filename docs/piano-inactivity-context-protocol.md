# 钢琴低活动区间与表达分组

2026-11-11，实际表达重放和SMD标签检查前记录。PR #11已经合并，修复了
明确区间空隙的分组影响，但《樱花草》未知重弹尾使最长77834ms音组仍完整。
本轮检验源模型的完整活动输出能否补足这一上下文，不恢复未知尾的LN资格。

先核对了原Nova钢琴float PCM与应用缓存身份，并逐ID核对1557候选的起止
音高。旧分析89个`frame_decay`在当前解码为`frame_inactive`，与已完成的
音尾语义检查一致；不能把旧分析称为全部元数据都与当前解码相同。

原强候选区间有6个至少80ms的空隙。约43.982–44.402秒处仍有较强持续激活，
不能从没有事件推断休止；另5处存在不同长度的低活动帧。原声RMS下降仅作
背景测量，不据这些数值寻找阈值或改Offset。

## 固定规则

- 使用已保存钢琴网络100Hz、全部88音高的持续/起音输出。持续不超过0.1且
  起音不超过0.3，连续采样点覆盖至少80ms，才是候选低活动区间。阈值沿用
  既有解码门槛，80ms沿用既有表达时间尺度。末端止于最后采样点，不外推。
- 该区间还必须完全位于原候选覆盖空隙内；所有原候选，包括低强度候选和
  更早开始的持续音，都会阻止虚假的空隙。仅对旧起音规则已判为连续敲击
  的组进行细分；原先保留的持续音不得变为tap。
- 只试验钢琴来源，不能把整条伴奏的活动证据复制为多个独立乐器的休止。
  分组可以改变表达选择，但原起音、音高、原尾及未知尾标签全部不动。
- 新分组的依据单独记为模型低活动，不称为物理静音、松键或独立旋律身份。
  没有实际低活动证据时完全回退。手动持续/起音/不采等模式不受影响。

## 验证

1. 构造控制检查跨所有音高的持续/起音否决、低活动长度、完整采样端点、
   未知尾不升级、弱候选与早先持续音、默认结果和显式模式保持。
2. 原《樱花草》6–10K、11份SMD冻结激活全部完成表达重放后，再读取SMD
   已有按键/踏板持续标签，检查新增空隙内有无参考持续活动。已有曲目不是
   新盲测；标签只评价，不反向调门槛。
3. 《樱花草》固定13段、74 BPM、Offset178、四细分、22.5ms提前量。逐声部
   记录丢失/新增起音、持续表达、最终选择、定轨、导出。检查全部新断点原声
   波形、模型激活，制作原声及新旧起止click供试听；不能声称代理亲耳试听。
4. 工程通过不等于默认启用；若低活动区间与已知持续音冲突，记录并拒绝把
   这版提示当成可靠自动休止。仍需区分表达意图与物理音尾。

本轮复用激活，不运行神经模型，不读取用户Reference音符，不重新训练。
研究实现先放`scripts/`，没有应用自动入口；只有完整结果才决定后续接入。

## 首次完整运行后的覆盖补查

首次运行已完成：SMD11份没有新增表达分组，标签核查的有效新增样本为0，
不能据此证明空隙识别可靠。《樱花草》新增5个边界、10个持续表达提案，
最终每键数多5条钢琴LN，尚无物理休止真值。

因此追加检查同一SMD全部原始候选覆盖空隙内的低活动区间，包括原规则
已经分开的空隙，不要求必须改变表达。这是看到覆盖不足后的补充审计，
不称预注册盲测，不改原门槛、不重跑网络、不按结果选择歌曲。用原踏板及
按键区间分别报告重叠；延音参考与真实可闻尾仍不是同一概念。
