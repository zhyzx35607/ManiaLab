# 局部重写的乐句边界

2026-11-17。修复局部生成静默丢失内部起音、或重复表达乐句内部起音的问题。此改动校验生成范围，不改变整谱选音，
不自动补音或推断锁定旧物件的来源身份，也不代表人声识别、LN音乐性或手感已验收。

## 复现与处理

先生成1000ms、1500ms两个短键，再将本段人声改为1000–2100ms的连续乐句，
只重写`[1250,2500)`。整首预选用新乐句代表1500ms起音；但合并时新乐句起点在范围外，
实际锁定的仍是1000ms旧短键。旧实现成功保存，却静默删除了1500ms起音。

`regional.validate_phrase_scope`在合并之前检查该关系：被乐句省略的内部起音位于区域内，
代表乐句起点位于区域外时，拒绝并提示扩大范围包含乐句起点和内部起音或整谱重写。
同时覆盖`represented_by_phrase`与`phrase_not_selected`，不把容量竞争失败当成有代表。

反方向只重写`[1000,1500)`也会出错：旧实现生成1000–2125ms新乐句，同时锁定1500ms旧
内部短键；整谱相同设置只会保留乐句。检查因此也拒绝“本轮选中乐句起点在区内，明确被它
代表的内部ID仍在旧候选锁定集合”这种组合。锁定按旧物件实际起点计算，覆盖手动把内部音
移到区外以及重分析复用ID的情况；这些情况不能靠当前分析的时间坐标判断。

第二项不强制所有乐句支持音的时间都进入区域。旧内部音已删除或移入可重写范围时，不会
重复保留；提案乐句容量落选或量化塌缩时，也不会加入新乐句，因此不因锁定内部ID而拒绝。
不据重用ID宣称旧音同源：有冲突时要求扩大范围或整谱生成，避免混用无法核实的替代关系。

范围使用现有`chart_clock_notes`与`align_candidates`，遵循提前量、零点裁剪、拍格量化
及左闭右开区间。普通跨界持续音、没有内部覆盖的旧路径保持可用。对旧长音不做身份豁免：
编辑可能继承phrase/support，内部候选ID也可能重用；局部报告的表达签名属于本轮提案，
不能用来证明旧锁定音的声学来源。代价是部分原本相同的乐句也需要扩大重写范围。
