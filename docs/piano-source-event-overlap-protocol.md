# 重叠观测音尾的局部后继适配

2026-11-09，新增缓存准备与训练开始前固定。上一轮clean适配在已知的合成踏板控制中从TP27/FP40/FN1退步到TP0/FP20/FN28，因此此轮是在已见反例上设计的修正实验。六个旧控制是开发诊断，不能再称未见测试集。

复用136份train/validation源与547个clean窗口，不读取test。输入增加两种模拟音尾：每个持续事件原结束后延长1或2 quarter，使用原整数tick，不作半tick舍入。按全钢琴相同音高的下一次严格更晚起音封顶，不能缩短原持续；不读取part/staff/voice决定增强，不模拟真实踏板标签。起音、音高、ID与监督真值保持原样。

增强作用于完整事件集，几何关系重新计算后诱导窗口。窗口按观测区间重叠纳入新增carry，core监督仍以原起音唯一归属。后继关系只来自原书写持续事件，禁止把延长后的音尾用于决定标签。未知和被排除装饰音的屏蔽不变。缓存保存原结束与观测结束，核验共同候选监督不变，新增上下文不重复监督。

从同一固定上游权重重新开始，不从上一轮选中权重继续。固定4轮、seed42、AdamW lr1e-4、weight_decay5e-4、梯度裁剪1；局部连接正例权重5，谱表使用原mask内交叉熵，不训练和弦head的独立loss。每轮每个train core只更新一次，窗口原序号为i、轮次从1开始时，输入变体为(i+epoch-1)%3，即clean、plus1、plus2轮换；训练遍历顺序用seed42打乱。前三轮每个窗口分别见到全部三种观测，第四轮重复第一轮的分配。

验证对clean、plus1、plus2分别完整计算逐曲局部连接宏F1。按三种宏F1的等权均值选轮，epoch0参与，精确同分保留较早轮。不调阈值，固定logit>=0，保留所有轮次、逐曲结果与谱表变化。训练前检查全部图、mask并做一次丢弃的反向更新，正式训练前重置随机种子。记录代码、数据、协议和权重身份。

训练后重跑六个开发控制，披露交叉与踏板退步是否仍存在。三种验证输入只是固定记谱的模拟观测，不能替代真实音频尾音、声部或LN评估；不自动接入生成器，不发行研究权重。许可和原始资料继续留在本地忽略目录。后续实际采音验证需另行报告，不能以这一轮分数宣布达到用户《樱花草》的音乐标准。
