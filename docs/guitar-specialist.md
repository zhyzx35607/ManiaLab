# 吉他专用采音

这项可选功能用于已经分离出来的吉他轨，重点提取吉他的起音、音高和持续区间。
它使用公开的FL吉他权重，和贝斯、其他伴奏、钢琴的选项相互独立。
默认关闭；包含该模型的安装包使用本机CPU运行，无需另外安装Python或Torch。
dev.4完整构建加入该模型；dev.2及更早下载包不含此入口。
源码应用检查与便携验证分别记录在[应用结果](hf-guitar-application-results.md)，
发行包的实际身份和验证范围以同一Release附带的验证JSON为准。

## 使用

1. 选择六声部分离，或在“导入已有声轨”中提供与原曲同起点、同长度的吉他文件。
2. 勾选“吉他声轨使用专用采音（测试）”，重新分析。第一遍运行模型，后续相同
   输入和选项可用缓存；导入预览的音量处理不会改变模型读取的浮点声轨。
3. 先看、听原始采音，再确认BPM与Offset，并按段落选择表达方式。
4. 如需尝试持续音，再勾选“允许吉他模型音尾参与长条”并重新分析。

仅勾选专用采音时，吉他候选保留原始预测音尾供检查，但生成使用起音。
开启音尾选项后，有模型持续依据的尾端可以参与LN；由同音重弹截断、输入结束
或上下文不足产生的尾端仍保持未决，不能因LN比例高就强制拉成长条。
单音何时结束与一段音乐应该怎样写长条是两件事，还要结合段落、声部和密度。

四声部中的“其他伴奏”可能混有多种乐器，不能直接当成吉他送入该模型。
六声部分离也不保证吉他纯净，需逐声部检查串音、漏音和叠奏。

## 已知效果与范围

固定60份GuitarSet比较支持继续开发FL路径。原始输入的起音与音高micro F1
为89.36%，当前通用管线为73.17%；完整区间为68.81%与48.74%（59份可评）。
完整输入、实际计分窗口、训练重叠未知、两套容差、全部分层与退步项见
[完整模型对照](hf-guitar-specialists-results.md)。这些数据不代表流行歌曲分轨
或最终谱面的准确率，也不代表经过了新的声学训练。

实际软件采样链另按[浮点协议](hf-guitar-float-input-protocol.md)检查，
导入、缓存、取消和导出按[应用协议](hf-guitar-application-protocol.md)检查。
原ONNX全窗数值检查存在EOF后补零区域差异，实际消费帧通过，详见
[便携数值记录](hf-guitar-portable-protocol.md)。不以落线或无重叠代替音乐质量验收。

模型来源、固定版本及许可声明保存在`assets/guitar-model.json`与
`licenses/HFGuitar-NOTICE.txt`。
