# 泛音频率重合是否也包含真实起音

2026-11-09，在统计前固定。沿用《樱花草》四个高音诊断的同一关系定义：目标候选起音±30ms内有更低音高的已有候选，其第2–8泛音与目标相差≤35 cents。仅检查候选音高和起音的频率关系，不使用本次结果调整窗口、阶数或频差。它不等于波形中检出了该泛音，也不等于已判定两个候选的声音来源。

范围为已保存的11段SMD真实演奏，每段70秒输入、前60秒起音评价。读取原音尾语义候选及已有inactive实验的一对一起音匹配，不重新匹配或跑模型，不读取音尾真值。目标候选为全部5005个起音，分frame_inactive（47个）与其他候选，分别统计既有匹配/未匹配及是否存在上述关系。伙伴可以来自70秒输入中的任何较低候选，不按置信度或frame状态再过滤。

所有参数已由先前四例探索提出，且本批录音曾被检查，因此是开发诊断，不是盲测。匹配表示同音高且50ms容差下有独立MIDI起音，不自动等于每条预测具有完整正确区间；未匹配也不一定听觉不存在。若有匹配的真起音满足泛音重合，则说明该关系不能独立作为删音依据。没有生成过滤后的谱、没有改应用或LN；逐事件配对保留本地，公开仅汇总。
