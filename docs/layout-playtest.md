# 6K–10K 同音符定轨试打

将 `Layout-AB-6-10K.osz` 导入 osu!。每种键数有 `Layout A` 和 `Layout B` 两张谱。选自己能稳定游玩的键数，使用相同键位、滚速和模组，在 `scores.csv` 对应行按 `play_first`、`play_second` 的顺序各打一遍。

重点比较长按期间穿插短键的舒适度、松键后接下一音的可读性，以及同一乐句内左右手承担的负荷。需要复查时，用同一段落反序各打一次。

| 评分列 | 填写方式 |
| --- | --- |
| `preferred_A_B_equal_unsure` | 整体更喜欢 `A` 或 `B`，两份接近填 `equal`，判断不清填 `unsure`。 |
| `release_coordination` | 填写放手与接续更自然的一份，使用相同的四个选项。 |
| `hand_balance` | 填写同段内双手负荷更合适的一份，使用相同的四个选项。 |
| `time_ms`、`comment` | 写下有代表性的谱面时间（毫秒）、版本和具体手势，例如“B 的右手长按尾端紧接同轨短键”。 |

只记录实际打过的键数。保留评分表首列的谱包 SHA-256，完成后先保存评分表，再查看包外的解盲表。另一位玩家可以反转首轮顺序，并独立保存一份评分表。

填写前保留 `scores-template.csv`，只编辑 `scores.csv`。旧版盲测包若没有基线文件，先在评分前复制一份；新版构建会同时生成两份。评分回收、输入检查和解盲顺序见[真人评审回收与解盲顺序](human-review-integrity.md)。空白档位表示未试打，不要推断成评价。
