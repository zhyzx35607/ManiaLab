# 乐器采音选择

先用 Nova 等工具分离声轨并导入，或使用内置四／六声部分离。以下专用选项
处理对应声轨；声轨内若仍有串音或多种乐器，模型也可能误采或漏采。

| 声部 | dev.4完整构建中的选项 | 建议检查 |
|---|---|---|
| 鼓 | 现有瞬态与鼓音色路径 | kick、snare、hi-hat等起音是否漏采或重复；仍需完善复杂叠奏。 |
| 钢琴 | 可选钢琴专用采音 | 和弦层数、重弹和踏板拖尾；模型截断不能直接变成LN放手。 |
| 贝斯 | 可选Tsumugi贝斯模型 | 连续同音重弹、低音起点和持续区间。 |
| 弦乐、管乐等伴奏 | 可选Tsumugi其他伴奏模型 | 叠奏的漏采与声部归属；预测乐器标签不等于已分离的独立声轨。 |
| 吉他 | 新增可选FL吉他模型 | 拨弦起音、和弦、同音重弹；仅用于吉他轨，六声部或已导入声轨可用。 |
| 人声 | 现有通用采音与跨音高短语表达 | 呼吸缺口、滑音、和声；本轮比较未支持换成新的默认人声模型。 |

钢琴、贝斯／其他伴奏、吉他专用入口相互独立，均默认关闭。贝斯／其他伴奏
和吉他的模型尾还有各自的开启选项：默认先检查起音，明确允许后才让合资格
模型音尾参与长条；重弹截断、输入结束等未决音尾不能自动当作放手。
选项不代表每个持续音都必须写成LN，逐段声部方案、密度和轨道容量仍参与取舍。

导入声轨应与原曲同起点、同长度。首次分析运行模型，同一输入和设置可复用
缓存。先用独立声轨及起止提示检查，再确认BPM／Offset，按段落设定主声部与
持续音／连续起音／起音／不采，最后生成候选。完整包无需安装Python或Docker。

本轮查找和实际比较了STRAdi、FiloBass、FiloSax、Banquet、PESTO、Timbre-Trap
等模型；没有整体改善的候选保留研究记录，没有放进默认采音链。
吉他FL的固定录音比较有明显改善，因此增加可选入口。没有把分离模型输出、
预测乐器类别、模型置信度和音乐中应当突出的声部当成同一种信息。
