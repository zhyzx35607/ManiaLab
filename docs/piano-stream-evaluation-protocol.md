# 声部分组的补充评价口径

2026-11-09，在八轮适配仍在运行、留出测试尚未评价时固定。保留原适配协议的六项验证均值选轮次，不用本文件的补充分数重新选权重、阈值或表达方案。

原适配评价分别测声部连接、和弦连接与谱表分类。它们不能单独代表最终分组：一条错误连接可能通过传递关系把两条旋律合并。因此在模型选择锁定后，对同一批测试窗口补算连通块中的成对同声部关系。只在同一小节比较，标注类别是原乐谱的 `(staff, voice)`；预测类别是声部边与和弦边合并后的连通块。不跨小节追踪这些数字标签，不把排版声部称为听觉旋律真值。

原模型原候选、原模型放宽候选、适配模型放宽候选均评价原时长和整小节延音输入。报告成对 TP/FP/FN、合并 F1 与逐曲宏平均，保留逐曲结果。特别记录错合并（FP）和错拆分（FN），不只看最终 LN 数量。合并分数较容易受密集曲目影响，因此同时保留逐曲宏平均。

六个符号控制和冻结《樱花草》输入保持最初协议不变；原模型输出必须逐项复现此前保存的预测，再比较适配输出。音频候选始终保持原值，模型图内量化不能冒充音频对齐改善。实际选音和导出另按 `piano-stream-export-protocol.md` 检查。
