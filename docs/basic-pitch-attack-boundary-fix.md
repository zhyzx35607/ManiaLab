# 起音校准后的重弹和音尾

2026-11-10。原来独立校准每个起音时，同一个瞬态可能把相邻的同音高起音
挤到同一时刻；后一个起音提前后，由该起音截断的前一音尾也仍停在旧位置。

现在按声部、模型乐器标识、音高检查校准。如果校准使原本前后分开的两次
起音相撞或倒序，恢复这两个冲突校准的原时间，不删音；不同音高的和弦
仍可共用一次瞬态。只对 `same_pitch_reattack` 来源的尾部，传递下一起音
提前后的上界；不因下一起音延后而补长条，不改自然衰减或未知尾。

六项定向控制先复现两处失败，再验证修复。与通用音尾、音频处理控制合计
47 项通过，真实模型测试留给独占推理时段及远程 CI。快速/分轨分析 revision
更新为 8/13；已有激活可复用。

## 退步事件复核

独立重算逐字段复现全部 100 例、140 份标注和 560 个指标格。按 A1/A2 标准
完整区间都损失匹配的案例排序，固定检查前两例 `vocadito_5`、`vocadito_10`。
只改变冲突起音的反事实重放复现了两例全部匹配损失；只改变重弹尾、或只修复
窗口接缝，均未改变两例的匹配数。因此这些例的完整区间退步来自起音恢复，
不能将它误称为音尾收短的损失。

例如 `vocadito_10` 的同音高预测为 5803–5861ms 与 5861–5965ms，原后处理
把两次起音都校到 5821ms；A1 参考为 5804.989–5961.723ms。原第二片段因此
借用了更早的起音，同时保留较晚的尾，碰巧匹配整个参考音。恢复第二片段
5861ms 的起音后，起音误差从 16.011ms 变成 56.011ms，越过 50ms 容差；
尾误差仍为 3.277ms。这个结果揭示模型碎片与后处理冲突，不能证明两个片段
应无条件合并；缺少独立瞬态也不能证明真实重弹不存在。

证据在 `test-data/basicpitch-attack-boundary-review-v1/report.json`，SHA256
`6ad75e3788ea9c18d5ae3c4f551b6a1620a03d9d5a10c4e1065e91b5ac42db4c`。
分析未重跑神经网络、未调整阈值，未据匹配分数宣称完成听觉验收。

## 重复峰抑制消融：不采用

另用完整 100 例检查“同一瞬态、相邻同音高、frame 激活持续上升”能否判断
第二个峰是碎片。V1 抑制 91 峰后重解码；V2 进一步保持每个幸存音原有的
已校准起音，避免删除碎片时顺带改变起音定位。两版均保留原阈值、全部录音、
两套人声标注和两套评分口径，没有改动应用默认。

| 相对当前基线的匹配数变化 | V1 标准 / 固定 | V2 标准 / 固定 |

| 吉他完整区间 | +4 / +5 | 0 / −2 |

两版 micro F1 都提高，但部分来自减少预测分母。V1 把四个人声事件的幸存
第一峰重新吸附到较晚瞬态；V2 保住这些头，却直接删掉了另十个事件原先能
匹配参考的第二峰。共同瞬态和上升激活不足以判断哪个峰是真实起音，不能
按乐器或标注挑一个有利版本接入，也不继续围绕这批评分增加阈值。
