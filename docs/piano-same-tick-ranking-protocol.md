# 同刻已知负组：单变量排序实验

2026-11-09，模型运行前固定。前一轮排序仍只比较正确后继与其他起音时刻；标签审计发现新clean解码287条已监督误连中260条在正确时刻，其中215条同staff异voice。本轮仅把正确时刻内的已监督负边作为另一个负组纳入现有排序，不同时改未知边标签、图、模型结构、阈值或解码器。属于已见开发数据驱动的实验，不是盲测。

对每个源，P仍是全部已监督正后继边，它们的目标tick唯一。N_t现在含所有tick的已监督负边，包括P所在tick。每组取最大负logit，分别和所有P计算softplus差，再按正边、负tick组、源依次平均。增加一个组会自然改变该源的组均值分母，不额外为同刻组加权。一个源只有同刻负边时也合格；无P或无任何负组跳过。未知边仍不进入辅助损失，shared encoder的间接影响照常存在。全部和弦正例必须保留，不能选最容易的真边来代表和弦。

原数据不动：127份train/511窗、9份validation/36窗，三种观测为clean、音尾+1拍、音尾+2拍。独立覆盖审计给出train旧合格14212→15318（新增1106），validation981→1071（新增90）；有同刻负组的源为7249/445，含13243/732条同刻负边。每源全部监督归属同一个owner窗口，运行前重查。

原始BCE+staff CE+0.1×排序；原预训练起点、seed42、AdamW lr1e-4、weight_decay5e-4、梯度剪裁1、四轮、输入变体轮换及遍历顺序完全沿用上一轮。按三种观测逐曲raw宏F1的等权平均选择，epoch0参与、精确同分取较早轮。既比较原BCE对照，也必须与此前异tick排序做逐边配对；不能只报告对较弱基线的改善。

保留旧2218条验证正边，分别报告raw/解码TP、FP、FN、逐曲分数、正确连接损失/补回、完整和部分真后继组保持、未监督竞争造成的损失、staff结果。额外分开已知正确tick中的同staff异voice与异staff负例，避免总体指标遮住主要问题。保持原六个已见控制，检查crossing和pedal，不另挑新控制。

先在研究环境验证真实梯度：未知边直接梯度0、和弦每个P受监督、同刻负边产生梯度、无P/无负跳过、没有同刻负边时与旧loss一致、分组平均不按边数悄悄加权；完成一次丢弃更新，重置随机种子再正式训练。不读取test源，不改应用、不发布安装包。是否进入真实音频对照由实际错误及正确关系保持决定。波形/频谱诊断与本符号实验相互补充，但都不能单独算音乐验收。
