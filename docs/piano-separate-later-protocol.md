# 原排序与可证晚候选分开归一化

2026-11-09，在本轮运行前固定。上轮把新负组并入旧均值后，完整后继组、交叉旋律和更晚竞争均有退步。保存验证输出的解析诊断确认平均分母降低了旧组的绝对 logit 梯度权重；这不是训练参数梯度的测量，也没有证明退步原因。本轮只检验分开归一化，不同时加入困难样本筛选、同刻负例、推理解码改动或其他新标签。

从同一原始预训练权重重新训练，以原 `successor-ranking-v1` 为主要对照，失败的 `later-ranking-v1` 和原 BCE 作为辅助对照。不是从任一适配后的 selected 权重续训。原数据、完整正组 P、证明 sidecar、图、监督 mask、core/halo、评价去重方式和 2218 条验证正边不变。

定义 O 为旧规则的已监督异 tick 负组，A 为 `derived_later_mask` 单独标记的原未知可证更晚边，按 source 和 target tick 分组。R_O 完全使用原 helper 与原合格源数；R_A 使用 A 自己的负组与合格源数。每项内部依次平均全部 P 成员、负 tick 组和该项有负组的来源音。每个负 tick 仍取其成员最高 logit。总损失为 `BCE + staff CE + 0.1 R_O + 0.1 R_A`；某一项无组时只省略该项。

O 和 A 在同一 tick 时仍分别取各自的 max：这是两个独立辅助目标，不合并旧组。新源只进入 R_A 的源分母，不能改变 R_O。正边可同时受到两项直接梯度；旧负边只属于 R_O，新负边只属于 R_A，其余未知边没有直接辅助梯度。共享参数仍可间接改变全部预测。保留旧项不表示总梯度、裁剪后更新或优化轨迹保持不变。

系数固定为旧项 0.1、新项 0.1，不扫描。这检验的是加入独立辅助项的整体处理，不能将潜在改善归因于某一个分母，也不声称总辅助损失大小不变。旧训练的 seed42、4轮、AdamW lr1e-4 / weight_decay5e-4、裁剪1、voice正例权重5、输入轮换和训练顺序均保留。按 clean/+1拍/+2拍逐曲 raw 宏 F1 的等权平均选轮，epoch0参与，同分取早轮。validation sidecar 只用于身份、覆盖和离线诊断，不参与更新；不读取 test。

开跑前用实际 Torch 检查全部 P、空项、新源、同 tick 混合来源、非法 mask、未知边直接梯度及有限差分；特别验证固定 logits 时 R_O 的值与梯度与原实现一致。在真实 train 窗口做一次丢弃更新，再重置随机种子开始正式训练。记录两项各自的覆盖、均值和更新数，保留所有代码和数据身份快照。

结果按原监督 raw/decoded 指标、完整真组、多目标组、逐边丢真/补回、逐曲退步、同刻误连、可证更晚竞争、谱表分类以及六个既有控制评估。可证负例减少不能抵消交叉旋律和完整和弦损失。若没有稳定改善则不做新的真实音频推理、不启用应用、不发布安装包。即使有改善，也只能进入冻结《樱花草》候选上的连接结构对照，不能宣称自动采音、Timing、全局声部或 LN 已达标。

进入新音频连接对照的最低条件也在此预先固定：相对原排序，选轮用的 raw 宏均值提高；三种输入各自的 decoded 宏 F1、完整真组和多目标完整组均不下降；+1/+2拍被可证最高竞争组抢走的真边均不增加且至少一项减少；六控制的 voice/chord TP不降、FP不增，宽琶音 staff 层配对不退步。逐作品变化仍完整报告。满足这些条件只允许继续研究，不是采用或发布条件；不满足则保存反例，不换阈值或另选轮次来绕过。
