# 《樱花草》原钢琴轨与候选回放

按照用户“结合音频分析”的要求，已对三个固定12秒片段生成原声、候选音高/音长合成和左右声道对照，并查看全部三张波形、频谱与音符区间图。当前对话工具没有把本地音频送入代理听觉输入的接口，因此本记录没有“亲耳听过”或人工试听通过的结论。

输入为原Nova钢琴轨未经削波的float PCM，以及正式钢琴入口冻结的1557个候选。不读取人工Reference，不调整22.5ms制谱提前量，不使用人工BPM或量化。合成音是简易谐波音色，用来暴露检测器给出的音高、重弹和区间，不能代替真实钢琴表现。三个片段各有264600采样、22050 Hz；原声、合成及双声道长度逐文件回读一致，所有PCM峰值留有余量。

第二片段包含4个音长6–10ms、MIDI90以上的高音候选。它们列为需要进一步核查的对象；短、弱或高音本身不能证明误检，因此没有据此删除音符。同片段MIDI69有17次独立起音，其中15个音尾由同音重弹截断。这个输出表明检测器所称“持续区间”经常止于下一次起音，不能直接拿来当乐句结束或LN放手真值。

首版频谱/音符图固定33–98显示范围，视觉复核发现遮住了一个MIDI100候选。第二版只扩展纵轴至覆盖所有候选，原九个音频文件与首版SHA256逐个相同，源音符也逐字段一致。原始首版保留，公开统计以第二版为准。

图上可见各音区有连续的能量带与重弹瞬态，但频谱还包含谐波和分离残留，不能将每条亮线视作独立乐器音。进一步检查应区分：真实重弹是否遗漏、短候选是否只有谐波支持、踏板/混响尾是否被当成新声部，以及稳定的声部为何在表达层反复长短切换。不能靠提高LN比例掩盖这些问题。

本机离线页面为 `test-data/sakura-benchmark/piano-audio-review-v2/index.html`，同目录内有全部音频和图像。浏览器自动化初始化返回 `failed to write kernel assets: 系统找不到指定的路径。 (os error 3)`，因此尚未验证浏览器中的切换与播放；静态图已实际查看，音频已完成采样数和量化回读检查，但并未完成听觉验收。

独立代码与数值复核补充：硬裁剪片段的端点不保证为零，例如第三段合成音首采样约0.217、第二段末采样约0.395，播放开始或停止时可能产生裁剪瞬态，不能当成乐器新起音或放手。6ms候选受合成器5ms起音和20ms收尾包络压低，不能凭混合回放中听不见就删音。4096点STFT首帧中心距片段起点约92.88ms，也不提供毫秒级起音定位。这些是对照工具的局限，不改动冻结候选。
