# 低活动与参考延续冲突的原声核查

2026-11-11，声学测量之前记录。上一轮PR #12得到104个候选覆盖空隙内的
低活动区间，其中28个与按键参考、29个与踏板参考延续重叠。本轮读取原音，
区分参考保持、实际衰减与可能的持续漏检；不把任何一种计数当成直接试听。

## 固定范围

完整保留`test-data/piano-inactivity-audit-v1/all-smd-gaps.json`的104个区间，
文件SHA256 `80c0a9be2657c1333b8ee72f5ce7fd1d723df02a21c52058bb3af2d715b4f7b7`。
范围来自6份既有SMD录音，其他5份没有符合条件的区间。不能只挑29个冲突。
同时对《樱花草》上一轮6个固定候选空隙使用相同测量，单列结果，不混入
SMD参考计数。没有新的留出集、网络推理或训练。

先核对manifest的原音、参考及旧预测身份；原int16/float32 PCM不重采样、
不重对齐、不做响度归一化。参考音高只用于指定要查看的频带，不决定新的
分组或选择门槛。所有起止、候选和上一轮表达保持不变。

## 测量与限制

- 全带RMS、峰值、实际样本数；间隔前500ms、间隔本身、后500ms分别报告。
  不用它们建立可闻性门槛；背景噪声、键噪、混响也贡献能量。
- periodic Hann STFT，512/2048/8192窗，128样本hop。保存帧支持范围，
  只有完整窗落入统计区间才计数，短区间不能拿跨界的起音能量当持续声。
- 检查参考在间隔内仍活动的所有音高，以及原候选在间隔前500ms内活动的
  音高；基频及前6分音。频带沿用35 cents与半个FFT bin中较大者，排除DC。
  同时记录相邻半音共享bin；频带能量不是独立音色或独立音符的真值。
- 每个频带报告前/中/后功率和中/前dB比，不逐频带归一化。无完整窗为null，
  不能记为零。长窗帮助看低频，却不能证明短空隙的精确音尾。
- 原声回放保留样本、图显示波形/频谱/原模型活动/参考保持区间，标签与模型
  使用同一原声时钟。参考末端差几毫秒和持续数秒的情况分开描述，但不修改
  原参考，不事后扩大对齐容差。

## 核查与决定

全部110个区间都测量并保留。预定查看：每个有冲突的录音中重叠时长最大
的一例、相同录音中首个无冲突例（存在时），以及《樱花草》第一个被拒绝的
区间和第一个被接受的区间。不能以选择后的图形代表全部样本。

独立检查样本时钟、完整窗、零信号、跨窗泄漏、量级缩放与若干真实FFT。
代理不能亲耳试听；结论必须区分测到的衰减、无法分辨的频带与未确认可闻性。
无论结果如何，不将模型低活动重新标成物理松键，不据本批资料调门槛。
