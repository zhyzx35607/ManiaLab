## 固定修复候选

保留起音与力度头逐值不变，只对切换点“前窗仍活动、后窗不活动”的音高
考虑前窗持续证据。使用现有.3起音/.1持续门槛，不根据标签调门槛。

1. 前窗最后一次起音须位于它原本负责的区间，且早于后窗的音频输入起点。
   后窗在切换前不得识别到该音高的新起音。
2. 前窗从该起音到切换点连续活动；必须在剩余重叠范围内观测到frame下降，
   并保留offset解码所需的后4帧上下文。没有已观测下降或靠近输入边缘则不改。
3. 至下降后4帧的范围不得出现任一窗口的同音高重弹；有歧义则保留原输出。
4. frame采用前窗至首次下降的原始值，offset采用前窗至下降后4帧的原始值。
   不延长到参考音尾、不取各窗max、不生成新起音、不把窗口结束当松键。

这是依据已见开发失败设计的候选，不是独立盲测。先离线复算全部11份SMD
70秒输入，原60秒评分范围、按键/踏板两套参考与50ms/40ms起音规则不变。
完整原窗口先保存且与历史归属帧核对，再解码对照，最后读取逐音标签。
按所有变化候选报告改善与退步，起音数量不变不能当作音尾准确率改善。
《樱花草》另作真实Nova分轨对照，不把人工谱当物理持续真值。

不修改正在运行的采集脚本或生产runtime。实际结果支持且边界控制通过后
才决定是否接入；若候选延长了错误持续，不凭Liszt正例就默认启用。
