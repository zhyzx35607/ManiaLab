# 声部优先级与持续表达分开比较

2026-11-09，第一版连续起音对照完成后的新实验。第一版将新版伴奏输入的10K从698条LN改成44条；单修活动统计则升至726条，并把other主段变为0。这些数量不证明音乐好坏，但暴露了旧“仅主声部默认持续”的依赖，故不直接把第一版设为默认推荐。

本次在原固定输入、分段和Timing上，再比较独立表达方案：所有未静音、有候选的非鼓声部都可保持已观测持续音，不以primary/support身份决定LN资格；钢琴和吉他选择连续起音优先。主声部依然只影响取舍偏好，不影响声部物件的长短资格。LN倾向为0仍全部只表达起音，不强凑比例。

保留上一轮旧方案与中间结果；本轮对旧other和新other各跑10K，新other跑6–10K。统计原始候选、表达候选、最终取舍、完整节奏组遗漏、LN和对音偏差。不能根据单首歌的LN数量选择规则，也不以结果接近作者谱判定胜出。此为研究方案，应用先仅提供手动连续起音表达选项；默认自动推荐在多曲及听辨证据不足时保持原规则。
