# 实际音轨与候选音符对照

2026-11-09，用户要求结合音频分析能力。本轮为《樱花草》建立局部波形/频谱与音高回放对照，不声称模型或代理已经亲耳听过文件。当前工具没有直接将本地音频送入本对话模型的听觉输入接口。

固定三个已有研究片段：6.664–18.664、215.853–227.853、241.798–253.798秒。复用原Nova钢琴轨的未经削波float PCM与正式钢琴入口已冻结的1557个候选；不再使用早期1461音符输出，不读取人工Reference作为声学真值。原音频使用 `raw-pcm-audit-v1` 的哈希，候选使用 `piano-svsep/probe-v3/report.json` 的分析哈希。

输出原轨、按候选音高/起止合成的简易谐波声音，以及左原轨/右合成的双声道对照；同一片段所有音轨采样数一致。候选保留原毫秒时间，不减22.5ms、不量化、不移动起点。跨片段左边界的持续音保留原相位和衰减过程，不作为新起音合成。合成器只是检查节奏、粗略音高与音长的工具，不模拟真实钢琴音色，也不将模型音尾当作手指松键或LN放手。合成音RMS匹配原片段、再共同缩放避免削波；每个缩放系数记录。

各片段输出标准科学绘图库生成的波形、对数频率STFT、原始音符区间图。STFT为4096点Hann窗、128采样hop，频谱中谐波不等于独立演奏音；不能仅凭一条亮线增加音符。真实音轨、谱图及检测音符共同辅助诊断，不能据图宣称全面漏音/错音准确率。

本轮不按主观印象修改声学阈值、LN比例或既有结果，不用新统计替代音乐验收。输出到新的本地忽略目录 `test-data/sakura-benchmark/piano-audio-review-v1`；素材及逐事件内容不上传仓库，公开代码、协议和汇总。提供离线HTML对照页，人工试听尚未完成时明确标记。

首版图像核查发现固定33–98音高显示范围会遮住第二片段MIDI100的6ms候选。第二版仅将图的纵轴扩展到覆盖片段内全部候选，再输出 `piano-audio-review-v2`；原输入、声音渲染和音符不变，v1保留。此项修正不是删除短音或调整阈值。
