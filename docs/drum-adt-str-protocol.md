# 细分鼓音色候选：固定官方模型与原声对照

2026-11-10，在该候选第一次真实声学推理前固定。目标是检查更细鼓音色能否改善 Nova《樱花草》中 kick/snare/hi-hat/tom/ride 的混淆。先核对声音检测，再看作者取舍；不由Reference第4列定义所有真实hi-hat，也不以新类别多就宣称效果好。

## 固定候选

来源为作者仓库 `https://github.com/pier-maker92/ADT_STR`，提交 `77dbef225e7029478ebfb916f20c7a00274f0f12`。使用作者HF `Pierfrancesco/adt-str` revision `a33c5c6b191a4ca1e0f6dc22140947485eb36ce8` 的 `setting-tau-0.8`，权重SHA256 `f94d1773d929166e0a3f63d305975aa6667512f8a71d7706872e1f8b23ca930b`，大小289134056字节。选择依据是作者推荐的配置，不在本曲比较tau后择优。

实际配置以HF bundle为准：`adt_config.yaml` SHA256 `a565a66cbb39b03e83eb29babaf474ba83bd4500ae1025868c9f65f84d2d6a3f`、`config.json` SHA256 `645ff73607cf8cebc71da07ad0016740cf82043fa56a62be4783074c8550cee9`。greedy、batch8、max_length512（包含BOS）、2.56秒非重叠窗、24kHz、float32，CPU2 intra/1 inter线程，seed42。Git旧inference.yaml的max_length64不是本轮配置。严格加载全部权重并逐tensor比较，保持eval/frozen。Torch2.9.1/torchaudio2.9.1/transformers5.3.0的实际版本与所有依赖另存，不声称与作者2.8环境已逐bit等价。

## 输入与范围

1. 完整283.84秒Nova《樱花草》原浮点鼓轨，已有原声审计SHA256 `97762166e5fef541b0cb8c3a048b03e1cc75f5c1e20575ddda93982ae06ccc9d`，22.05kHz，6258672采样。保留超过1的峰值，不归一化、不限幅，不读作者谱/BPM/书签指导推理。
2. 已有物理鼓manifest中的全部23份MDB drum_only原录音，按原manifest顺序，使用完整音频；保存原audio/annotation哈希，推理阶段不读逐音标签。它们已被旧研究使用，也是作者报告数据范围，全部称为开发回归，不声称盲测。

SoundFile读float32、声道均值按官方_prepare_waveform、重采样使用官方torchaudio实现。保存实际24kHz PCM和每窗原token。最后一窗按官方补零；保留窗外/输入外预测并单列，不能为了好看在统计前丢掉。若资源或运行错误中断，只在输入、代码、模型身份相同下续未完成录音，保留失败日志。

## 解码审计

官方tokenizer时间为 `(token-4)/100`，10ms粒度。mel裁掉边缘帧后可见的帧中心不等于token时钟，不另加50ms偏移。模型输出35–60为26个自定义打击乐类别，不是标准GM音高；原映射与每个类别名均保存，不直接把这些数字写入GM MIDI。

原官方完整输出作为兼容对照保留。官方decoder按不同字典values做zip，畸形token可能跨事件错配，因此另按同一连续 time/pitch/velocity 三元组解析并保存来源token索引：time4–259对应局部[0,2.56)，pitch335–360对应custom35–60，velocity400–527对应0–127；遇到EOS停止，缺字段/越界/非三元组逐项记录，不猜测补齐。缺EOS、max_length耗尽、局部窗外时间另记；语法合法但全曲输入末端外的预测仍保留作误检风险。全静默串允许BOS,silence,EOS；EOS后的固定EOS填充可接受，其余尾随内容标记。

分别报告原官方事件和严格解析事件的差异，不能把纠正解析产生的数量变化全部归因于模型准确率。固定0.1秒的鼓offset是显示占位，完全不用于LN持续/放手。

## 评价与原声检查

MDB使用原class标签，固定合并映射：KD=custom35/36；SD=37/38/39/40；HH=42/43/44；TT=41/45/47；CY=46/48/49/51；OT=50/52–60。同时全报26类预测，SD包含side-stick/clap是粗类比较，不能冒称细音色真值。先验证原标注类别集合，未知类必须报告。逐类同类一对一最大匹配分别使用20、40、50ms，不按拍线量化、不拟合时间偏移；空类别不通过忽略预测获得好分。全报每曲、合并、额外/遗漏、边缘窗附近遗漏与所有畸形解码。

《樱花草》仅作作者选择诊断：列1主要kick、2/3同刻snare双押合为一次起音、列4主要hi-hat但含tom等。原时钟和既定22.5ms提前量各自报告40ms匹配，另列HH∪TT、HH∪TT∪CY诊断，绝不据最高分重命名列4。按已有0–162340、162340–188286、188286–283840ms区段及全曲报告，不做本曲训练或调参。

保存每个输入全部预测和token。原声图页固定显示Nova第4列最早未匹配、最早新增候选、MDB每类最早漏采/额外事件；含原幅度音频、波形、频谱与不同类别时间线。图形审查不记为亲耳试听。

本轮是独立候选调查，不自动替换应用。只有工程核验完整、物理类别尤其HH相对已有固定回归有可靠收益，且没有未解释的大量漏采、窗边缘丢音或token错配，才考虑后续同音轨的段落表达与便携运行验证。研究权重、音源、逐事件标签不随仓库或Release分发；公开汇总保留改善与退步。
