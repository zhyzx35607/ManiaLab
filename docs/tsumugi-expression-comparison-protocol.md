# 原 Nova 全曲的编排对照

在首个全曲导出前固定此补充说明，不修改正在运行的采音协议和输入。

每个 6–10K 键数同时导出三份：当前 Basic Pitch、Tsumugi 原始尾未决、
Tsumugi 显式允许来源可追查的模型尾。后两者起音、音高和原始区间一致，
只改变尾是否能参与 LN 编排。未知尾仍表达为短键。保持原钢琴、鼓、分段
边界、密度、音频时钟；人声权重按原曲配置为0，四轨采音仍全部保存。

上述15份是不同完整处理链的比较，原生权重语义不同：Basic Pitch strength
来自激活，Tsumugi为1的事件权重，不能视为100%置信度。编排器会按strength
过滤并分配容量。因此再导出三份10K消融：对双方被替换四轨都统一为1，
保持原始证据文件不变，并固定基线的逐段主次／表达模式。新模型类别继承
同声部策略；基线不存在的声部明确omit，不从新结果推测有利模式。

本次不重新运行跨声轨串音过滤，旧诊断标记为历史值。两方均做相同的局部
能量下限检查；Basic Pitch保留原有贝斯重复峰处理、音尾修整和瞬态校准，
Tsumugi不套用这些尚未为它验证的后处理。差异必须在报告中明确。

固定74 BPM、Offset178、制谱提前22.5ms是已有对照的手动时钟。强制落线
与导出合法不证明自动Timing正确，报告同时保留全部表达候选和最终保留音
超过30ms移动的数量。自动方案每版重新推荐，另报告各段主声部／模式。

共18份实际导出后回读，检查音符数量、键数、合法区间和网格。以上为工程
与编排对照，不设置“音符少了”“LN多了”即音乐验收通过的条件。
