# 全曲声音流与局部片段的表达对照

2026-11-10，在首次批量结果前固定。复用 `piano-svsep/probe-v3` 与 `adaptation-evaluation-v1` 的原模型、epoch5适配模型预测，不运行网络、重训或选权重，不读取保留测试数组。输入为六个既有符号控制，以及最终 Tsumugi 整曲分析中的1557个原钢琴候选；后者须与当时分流模型输入逐字段相同。

表达桥接独立保存候选身份哈希、音频观测边界、方法、预测文件哈希、每音分组及身份范围，不改 `instrument_id` 或原候选。全曲谱表分类仅作为一个分组假设，不是物理左右手或独立旋律真值；小节内组件标为局部片段，不能用整曲剩余时间证明这个组件的后续身份已被观察。未分配身份留空，不将所有未知音合并成新声部。

固定四种控制：整轨、全曲staff、直接把components当全曲身份的旧式诊断、staff与局部components共同约束。最后一种只在全部假设对长短决定一致且至少一份具备完整来源上下文时改变整轨决定；冲突、缺失和局部未知均保留原规则并记录原因。两份假设来自同一个网络，其一致不等于两份独立证据，也不构成正确率。片段末次起音不获得“观察到休止”的待遇；少于三次起音的片段单独无法增加持续表达。只对 `articulation` 生效，手动 sustain/onsets/phrase/omit、弱音门槛、未决尾和最短LN规则不变。

所有长条只能使用原始可用区间，不新增起音、补尾或剪尾；以全曲上下文先做长短选择，再按段落策略输出。六项固定控制保留所有分组错误和双向表达变化，尤其模拟踏板、宽琶音和交叉旋律。人工四音反例只证明接口行为，不能算模型成绩。

真实比较固定九份：当前整轨10K；两套模型各staff与共同约束10K；适配模型共同约束另导出6–9K。不按这首歌的LN数量选方法。使用已冻结13段、74BPM、offset178、四细分、22.5ms提前量；不称自动Timing正确。当前10K基线须逐对象复现 `balanced-expression-default-v1`。每份保存表达、侧车、取舍、最终音符、模型来源和导出，检查原输入不变、同轨冲突、实际起止/轨道回读、声源/音高不变和未知尾禁用。

报告表达前后新增/取消LN、保留起音、局部身份冲突、各声部取舍、鼓组丢失/恢复、超过30ms的起音移动、求解状态与间隙。软件检查和更多持续音不能替代连续乐句听辨；没有达标证据不接入自动模型或发布正式版本。
