# 逐音力度首轮真实推理结果

已运行作者固定Tsumugi velocity模型。它通过了本轮双音强弱排序控制，但不够
作为自动主次或删音的依据；继续保留在研究入口，未修改应用候选strength。
实验遵守[预先固定的协议](note-dynamics-protocol.md)。

## 输入与实现

四个现有原音片段共252个音符，按宽类别枚举全部可用GM假设，得到922个查询。
每个分别跑−12、−6、0、+6dB与全零输入，另跑12个双音控制，共32组音频条件。
没有用MIDI中转、重新采音、取整时间或裁去反例。运行约155秒（只表示本机此次
控制的耗时，不含准备，不用于承诺其他机器性能）。严格加载277项模型state，
无缺失/额外权重；实际配置为绝对能量输入、无stem-gain head。

输入文件、原音PCM、原采音数组及源码在运行前后核验不变。源码和模型版本、
每窗查询次数、全部logits、未取整期望velocity及程序音色假设均保留。
独立复核也从127类logits重算了全部32组期望值，最大浮点差约2.38e-5，
每个查询只计算一次；922个真实查询没有因float32转换改变8秒窗口归属。
模型主要读取起点附近的局部特征，offset仅参与时长metadata，不是对整条
持续音逐段测量响度。8秒窗附近起音的局部上下文也会受窗界限制。

## 结果

| 原片段 | 原音符／GM假设查询 | 随四档增益单调递增的查询 | 原音同类别内GM假设造成的最大力度差 |
|---|---:|---:|---:|
| bass | 42／58 | 58／58 | 10.73 |
| guitar | 102／204 | 191／204 | 9.50 |
| other | 69／621 | 621／621 | 10.13 |
| vocals | 39／39 | 39／39 | 0（只有一个代表假设，不能据此证明稳健） |

吉他的13个非单调查询来自7个原音符，最明显一次增加6dB后预测力度下降1.34。
不是把13个查询当成13份独立音乐样本。某些原音基线接近模型输出下限，
因此不将单调性通过率解释为真实力度准确率。

四对音高分别交换4:1强弱，program 0和40分别查询，16／16次将已知较强分量
排在前面，最小力度差15.78。等幅/近等RMS控制中，两个音仍相差约4.20–7.51；
不同音高的力度标尺并不等于可直接比较的波形响度。控制使用谐波合成信号，
不代表弦乐、管乐、吉他真实混音都已通过。

全零输入仍给出约28.87–29.38的velocity；吉他10个查询的静音输出还高于原音
输出。模型本来是“已有音符条件下的力度预测”，没有无音类别，因此这些数值
不能当音符存在概率。没有据此把小于29的真实音删掉或作新的静音阈值。

## 对编排的影响与下一步

本轮也核实《樱花草》13段全选other的主次问题：旧推荐依赖250ms占用格子，
第一段同分后选中other，后续8段由85%延续规则继续保留。即使补齐跨段音、
改为精确覆盖，other第2–12段覆盖也接近100%，所以单纯修占用算法仍无法
判断它是背景还是主旋律。未知尾不是这首歌other占用分数增加的原因。

力度模型可继续作为单音强弱的独立证据；段落主次还需要旋律轮廓、起音节奏、
重复乐句与真实混音的突出声音证据。共享一条other声轨的12种模型类别，不能
各自复制同一个声轨RMS并冒充独立乐器测量。当前未替换自动主声部策略，
未重新拉长LN，也未宣称解决音乐表达问题。

后续已按另一个事前固定协议完成两组真实乐器的五条件混合对照，发现来自其他
声部的干扰，见[真实弦乐与铜管结果](velocity-interference-results.md)。
