# 表达选择求解精度对照

2026-11-11。PR19 的10K持续覆盖方案目标值1656.653838，9K为1664.305500；
其他设置相同，10K轨道限制更宽松。先核验9K主求解方案在10K的可行性及
目标值，不能直接把两份最终谱的差异全部归因于持续覆盖偏好。

本次固定原候选、分组、0或0.25覆盖权重和人工时钟。完整重放6–10K，
主求解与剩余鼓点补充的相对间隙要求都改成0，原15秒/5秒时间上限不变；
这是数值对照，不搜索权重或改表达偏好。超时的可行解必须保留间隙与状态，
不能宣称精确最优，更不能将目标值当作音乐质量。

重建历史选择的二元变量：去掉后补鼓点，按原组层数映射到选择变量，正奖励
辅助变量取其合法阈值覆盖。重新核对所有约束、原目标值和音符ID，不依赖
旧report的“optimal”布尔字段。9K见证方案单独在10K矩阵中校验。

每次保存原/新主求解目标与间隙、补鼓耗时、完整物件与声部起音取舍，以及
定轨、容量、落线和导出回读。校验求解x的整数性与可行性，报告其取整后
选中索引、单位ID与矩阵以便独立复核（实际v1未保存原始float x）。
音符及音尾不得改变。无新增神经推理、Reference读取、自动Timing验收或
听觉验收。所有逐音产物保留ignored test-data，不覆盖PR19历史记录。

只有确认收益来自更充分求解、时间预算不增加且原默认行为的结构验证通过，
才考虑采用更严格停止条件。它仍不能解决整组落选或自动声部主次判断。
