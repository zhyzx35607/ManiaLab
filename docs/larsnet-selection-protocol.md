# 分离声轨作为作者取舍证据

2026-11-09，拟合前记录。冻结LarsNet全曲结果已生成，不改分离模型。直接逐轨采起音在后段第4列匹配58/75，但提出181个候选；snare只匹配30/45，不能整体替代。下一项检验分离声轨能否帮助原局部分类器表达作者取舍，而不是把每条分离轨的检测结果全部写入谱面。

完全固定原1387个起音、原float鼓轨局部频谱、22.5ms提前量、训练结束162340ms、校准结束188286ms以及线性正则0.01、阈值0.1–0.9步长0.05。增加五个冻结声轨在同样四个相对窗口（-45至-5、-5至25、25至70、70至140ms）的线性能量：20个相对形状、5个非负攻击增量、20个绝对log能量。每类独立逻辑回归，允许多个音色同时出现。无拍位、书签、绝对歌曲时间、输出密度或后段标签输入。

固定同输入float线性对照须逐项重现`drum-mixture-v1`的线性结果。中段只选阈值；不因为后段差而扩大搜索或换声轨映射。分别报告全部作者事件F1和独立/叠奏事件召回；学习的是作者选音和分配，不是完整物理音色真值。此前重复开发同曲和重复乐句的限制继续有效，不能凭改善启用为通用模型。
