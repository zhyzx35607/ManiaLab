# 多乐器扩展对照结果（2026-11-10）

35个固定输入全部完成：28个独奏声轨、7份对应混音。YourMT3在这批数据上的
总体误采明显减少，完整音符区间也更准确；但独奏起音召回下降，不能说所有
乐器都改善，更不能把音符指标当作LN键型验收。

协议为`instrument-extension-protocol.md`。原始录音0–40秒用于推理，0–30秒
内的全部起音评分。没有节拍吸附或时间补偿。起音容差50ms、精确半音；完整
区间额外要求尾误差不超过max(50ms,参考音长20%)。以下均为micro F1。

标准容差下，独奏起音27胜1负、完整区间26胜2负；混音两项都是7胜0负。
局部退步为31-3-hn起音、24-3-va与25-4-sax完整区间。萨克斯整体尾指标也
退步；圆号起音匹配75→51，不能用更少的误采掩盖漏音。

固定40ms起音/80ms尾容差下，独奏起音72.19%→87.29%、完整区间
55.97%→77.19%；混音起音55.64%→74.83%、完整区间34.40%→59.41%。
80ms对于短音比标准50ms宽，不能只选较好的一套指标报告。

33/35例有上游token解码诊断，总计onset-not-found364、segment-tie436。
这些不是执行失败计数，但也说明不能称解码零异常。全上下文端点审计4258条
与评分窗YourMT3预测3012条是不同分母。类别表按真实独奏来源分组，不证明
模型精细GM分类准确；萨克斯子类标注还有上游不确定性。

决定：继续比较新专用模型，暂不凭总体F1更换应用默认采音。低音乐器、萨克斯、
复杂混音音尾仍需改善。公开录音可能参与上游训练/验证，不称未知盲测。
