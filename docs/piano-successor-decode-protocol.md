# 单一后继起音组的有限解码对照

2026-11-09，运行前固定。由真实钢琴三模型连接图发现同一来源音指向多个起音位置，提出一个有限结构约束。此发现属于已见开发观察，不是盲测；本轮不训练、不搜索阈值、不选择新的权重。

先审计clean/+1/+2全部train/validation的1641缓存及跨窗ID：每个有已监督正例的源事件恰好对应一个后继起音tick组，组内可有1–4个目标。train为17810个正源/27362正边，validation为1328个正源/2218正边，0个多tick正例源。有监督候选但无正例的源分别1931/117，不能强制每音连接。原监督来自源事件最后书写片段的小节，存在476/18条跨起音小节的正边，不能用起音小节过滤候选。

固定解码：按目标core归属收集每份输入的全部唯一候选边，然后对每个源事件，在logit>=0的边中选最大logit所对应的目标起音tick。同分取较早tick；保留该tick组内所有原非负边，删除其他tick的原非负边。全负时不连。源ID、目标tick、logit是仅有输入；不得读取真值、监督mask、staff/voice、音尾或小节编号。未监督跨小节边参与同一竞争，mask只用于最后评分。不同窗口同源边先聚合再选，避免每窗各选一个后继。

固定比较原权重、clean适配epoch1、重叠适配epoch4。使用9份validation作品的clean/+1/+2输入，保存公共图与三套raw预测；新的raw汇总必须与已有对应验证结果核对。只运行这些validation文件，不读test或训练集标签做选边。逐作品和整体报告TP/FP/FN、Precision/Recall/F1及宏F1；明确报告去掉的真/假正边、净召回损失，以及监督正例被未监督不同tick高分边抢走的数量。减少分叉是规则定义的结果，不能作为独立效果成绩。

六组已有开发控制复用已保存raw预测，不重新生成；同样让全部未来候选竞争，最后只在原mask内评分。真实《樱花草》也复用audio-events-v1已保存预测，对全曲唯一owner边聚合选组；只报告同小节/跨小节结构变化，不使用作者Reference或成品作真值，也不生成LN。输入音符ID、物理起止、音高和数量保持不变。

这是局部后继解码基线，并不证明全曲旋律身份。错误最高分可能删掉正确连接，未监督跨小节输出可能抢走已知正确后继；无论整体F1如何，都记录这些损失。结果未完成音乐验证前不接入应用默认、不发布研究权重或新安装包。
