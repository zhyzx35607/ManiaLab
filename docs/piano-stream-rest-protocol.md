# 固定权重下的 rest 观察边修复对照

2026-11-09，在修复后的模型推理前固定。本实验承接 `context-v1`，不改写已完成的上下文实验或其协议。原实验发现《樱花草》四小节窗口出现 2244 条完整图中不存在的 rest 观察边，全部没有指向源音尾之后的起音；完整图没有这类边。窗口同时少了 45 条正常跨窗 rest，2244 不是两图 rest 总数的净差。该发现只确定构图错误及其出现位置，尚未证明它对音乐表达的影响或修复后一定改善。

上游固定为 commit `1462e7c28d7adaae033150883a7cb00238ee364a`。原模型 SHA256 为 `1f71ab8b6c7cd271e18adfba5ccbcd634a8530a44e46aabede27e15ce84dbe32`；适配模型仍使用已选定 epoch 5，SHA256 为 `1a1db7e3ed82f2a32f92941f677c2a0ac321d7e8a9c859ea83d2d1f7c07accdb`。固定比较原模型原候选、适配模型扩候选两个流程，不重新训练，不调整概率门槛，不根据结果选择检查点、窗口大小、上下文或 LN 策略。

## 修复范围

`hetero_graph_from_note_array` 的 rest 分支在某个音尾之后没有未来起音时，将全部差值设为无穷大，再把所有等于最小值的节点选为目标，因而连到所有节点。研究包装层只删除 rest 中 `onset[dst] <= onset[src] + duration[src]` 的边；等价的重建实现是未来起音集合为空时不连边。处理发生在官方 `predict` 添加反向边之前。保留上游源码和模型原文件，以便复现旧输出。

不修改 onset、consecutive、during、声部候选、和弦候选、输入特征、原音频候选和音符时间，也不通过裁短音尾避免错误。现有输入的时长均为正；因此 `max(end_times) >= max(onset)`，最大音尾没有更晚起音，原循环排除最大音尾本身不造成合法 rest 漏边。本轮不顺手改变该循环的其他行为。

## 固定输入与对照

使用 `dataset-v2` 的 16 份 validation 完整缓存；每份包含已冻结的前 16 个有音符小节。原时长 clean 和整小节延音 whole 各一遍。whole 必须先在完整缓存上增强，再按原上下文实验同一规则切窗，避免窗外同音重弹造成时长不同。比较完整缓存与最多四个有音符小节的窗口，窗口目标不超过 500 音符；单小节超出上限时保持完整小节并记录，不能为本实验改窗。

每套权重、每种时长输入、每种上下文均比较修复前后。先逐数组复现 `context-v1` 的原预测，再运行只修复 rest 的版本。旧上下文脚本快照、原模型、适配检查点、数据 manifest、每份缓存和新运行脚本均核对并记录身份。验证原始数据不变；不读取 test 数组，不用已有 test 分数调参。完整缓存结果仍是有限符号乐谱窗口，不称为完整曲目的音乐真值。

《樱花草》继续使用冻结的 1557 个钢琴候选，按原始候选重建并核对 ID、音高、图起音和图时长；使用既定 74 BPM、Offset 178 ms、四细分与 22.5 ms 制谱提前量，仅用于复现图时间。比较整曲图和原四小节窗口的修复前后，模型输入不得重新对音或调整量化。保留现有段落和连续起音表达规则，分别观察 staff 与 components 两种分组，不读取作者谱，也不按作者匹配率验收。

## 构图不变量

- 每条修复后的 rest 必须满足 `onset[dst] > end[src]`；没有未来起音的源节点 rest 出度为零。
- 源音尾恰好存在起音时，由 consecutive 表示，该源不应另有 rest。其余合法 rest 应指向所有位于最早未来起音的节点，不跳过更早的可用起音，也不只保留和弦中的一个音。
- 除删除错误 rest 外，其他观察边、两类候选边、节点顺序、全部特征和音符字段与未修复图逐项相同；反向关系由同一官方推理过程重新建立。
- 局部输出用稳定全局节点索引重映射，原始 logits 按候选边键比较。局部预测边重映射后重新计算连通块，不直接拼接组件编号；成对关系只在同一小节评价。
- 每个节点恰好进入一个窗口，并断言时间有序、每窗为连续音符切片且不拆同一起音。满足这些条件后，修复后的局部观察图应等于修复后完整图在该窗的诱导子图：各关系的 `window_only` 与 `full_internal_missing_in_windows` 均为零。跨窗观察边正常保留为完整图与窗口图的差异，不强行消除。
- 用不涉及模型权重的小型确定性例子检查：没有未来起音但有更晚音尾、多个音同时是最早未来起音、音尾恰好接起音、仅一个音或所有音尾相同。若原图没有错误 rest，修复图及其固定权重预测应逐数组不变。

## 记录与判断

每个 case 保存修复前后的错误 rest 数、被删除边数、四类观察边集合审计、预测输出及哈希。报告 staff 分类翻转和分类头分数差、相同候选边的 voice/chord logits 差与固定 0.5 概率门槛翻转、后处理边差、同小节连通关系差。staff 头带 Sigmoid，其输出称为分数，不称为原始 logits。

validation 对原谱 `(staff, voice)` 标签报告同小节成对 TP/FP/FN、汇总 F1、逐曲宏平均、staff 准确率，以及修复前后的逐曲改善/相同/退步。完整图与窗口图分开报告，clean 与 whole 分开报告，保留各曲结果；不得用总体提升掩盖单曲退步，也不能把符号谱表标签视为完整听觉声部真值。

《樱花草》报告 staff/components 分组变化、相同规则下 hold→tap 和 tap→hold 的数量及候选 ID，核对表达只在原始起音和已观测音尾之间选择，不新增起音、不提升未决音尾为 LN。这里记录的是表达输入，未经选音、定轨和导出；不能把它们称为最终谱面的 LN 成绩。完整图若没有错误 rest，应复现旧输出；即使窗口结果更接近完整图，也不能据此证明完整图的音乐判断正确。

修复会改变曾被旧权重见到的观察图分布，可能改善也可能退步。GraphNorm 的归一化范围、正常跨窗观察关系与后处理上下文依然存在差异，本轮不把修复效果全部归因于某一种因素。后续若隔离归一化或重新训练，应另行冻结方案，不混入本轮。

全部原音频、逐事件结果、生成表达与研究权重仍保留在忽略目录 `test-data`。本轮不启用应用默认流程、不发布新 Release。构图不变量通过、F1 提高或 LN 数量变化均不代表采音、可演奏性和歌曲表达已完成音乐验收。
