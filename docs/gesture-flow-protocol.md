# 全曲放手规划求解对照

2026-11-09，运行前记录。独立候选 v1 全曲求解在60秒内只返回5个LN、973个未确定事件，MIP gap为2.1088；同一模型校准片段能生成86个LN。这需要区分求解失败与模型识别不足，不能据此宣布采音或LN已经改善。

首先把相同端点概率、相同平方计数目标和占轨约束写成最小费用流。每个起音时刻用固定流量保证原始物件数；长条占用的一单位容量直到放手才返回。连续线性规划的网络矩阵应返回整数最优解，独立校验整数性、流守恒和毫秒占轨；未求到最优则报告失败，不接受任意临时解。小样本与原整数规划比较，另测同刻放手重按及无起音放手。

第一对照保留原平坦端点目标，明确关闭原有放手事件开启成本，以隔离求解器。第二对照另加总LN数量的平方误差，端点分布误差权重固定为0.25，解决总持条概率高但分散到多个端点时被投成短键的问题；仍不指定必须达到的LN比例。两种版本均不支持原全曲LN硬上限，不悄悄忽略该参数。

单曲偏置只使用既定校准范围，协调参数固定0。社区对照偏置0，固定原20个开发片段；不根据测试片段更改参数。报告严格起止、长LN、短LN、逐曲退步与求解状态。新候选v2排除无法保留0.1ms精度或不单调的累计红线时钟，记录谱ID和原因并重新准备数据。既有实验目录保持原样，所有权重仍禁用。
