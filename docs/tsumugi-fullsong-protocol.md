# Tsumugi 回到 Nova 全曲声轨的对照

2026-11-10。在全曲新推理开始前固定以下步骤。短录音指标不等于流行歌曲
分轨效果，也不等于成品 LN 验收。

1. 使用 `test-data/sakura-benchmark/raw-pcm-audit-v1/` 中的原浮点声轨，按已有
   PCM 审计核对文件哈希、样本数及与应用缓存逐样本相等。保持超过 1 的采样
   峰值，不限幅、不归一化、不使用试听用 int16 副本。
2. 固定声轨与模型对应：bass→bass_v2、guitar→guitar_v1_5、other→other_v1_5、
   vocals→vocal_harmony_v1_5。完整处理四轨，包括几乎静音的吉他轨；不能按
   结果只保留较好声轨。已知分轨类型只用于选权重，保留全部模型类别输出。
3. 不给模型作者谱、BPM、Offset、bookmarks 或乐器参考标签；从原音频 0 起
   整曲连续推理。保留作者内部窗口与全曲采样时钟，不按 60 秒外部分块后拼音。
4. 独立入口 `scripts/research_tsumugi_fullsong.py` 将输入上限扩到 20 分钟，
   复用短录音研究入口的权重校验、原始事件转换及被动构造观察器。其余模型
   参数、双声道处理、2/1 CPU 线程和完整权重加载相同。开始前用固定已有
   smoke 输入核对两入口的 notes、raw notes、窗口及构造记录逐字段相等。
5. 每轨保存全部模型事件及来源重放。构造裁切、强制封口和未知尾仍标未决。
   只有末端所有来源都给出未裁切、非观察边缘的显式模型尾时，才可作为可选
   持续音假说供编排；这个条件不证明它是正确放键点。回收的无尾起音保持短键。
6. 同时保留当前应用对这些原始声轨的缓存重解码结果，并区分原冻结结果与
   重弹修复后的版本。起音数、持续区间、类别变化、重弹和未决尾分别统计。
   作者 Reference 可能遗漏且无完整物理音高标签，不拿事件数量变化当准确率。
7. 若导出编排对照，固定原有生成时钟及其他声部，只替换这四轨候选，使用
   同样的密度和键数配置。人声权重继续按该对照歌曲原配置为 0；其采音单独
   保存。导出结构、落线和键数验证不替代对音与音乐表达验收。

全曲入口不修改仍在运行的短录音研究文件，也不使已冻结比较失去可重放性。
目前只是本地研究接入，尚未加入便携发行包。
