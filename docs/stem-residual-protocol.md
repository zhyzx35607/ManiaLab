# 冻结节奏模型的声学残差对照

2026-11-09，运行前记录。首轮多曲声学适配在已完成的验证谱上明显退步，且节奏对照本身也有遗忘社区先验的情况。此项诊断保持全部已准备样本、声轨特征和分组不变，只训练第一层新增60维声学输入的权重；原78维权重、所有偏置和后续层逐值冻结。这样不能通过改写旧节奏网络来获得训练收益。

24轮，学习率0.001，新权重均方正则0.0001；AdamW权重衰减设0，防止即使旧权重梯度为零仍发生衰减。每次导出核对原权重逐值不变。新增验证候选epoch 0，即完全未适配状态；如果训练没有改善验证损失，允许选择原模型而不是被迫启用训练后的某一轮。该轮次选择修正也作为后续所有初始化适配的默认行为，旧实验结果保留。

模型和验证轮次冻结后才做原有片段实际生成。原社区模型是直接对照；先前同预算节奏适配结果额外保留，它不是本轮冻结参数约束完全相同的对照。不根据测试结果调超参数或增加轮数。输出仍是研究，未获得整体音乐验收不得启用。
