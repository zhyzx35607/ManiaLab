# 人声乐句结束证据修复（2026-11-10）

人声连续活动可以跨越多个音高，形成可选的乐句 LN。此前构造乐句时复制了
第一个短音的结束原因；短音的同音重奏或帧激活下降并不证明整句结束。

现在乐句按自身的活动区间记录来源：自然活动结束为 `vocal_activity_decay`，
仍活跃却已到输入末尾为 `input_boundary`，因最长乐句限制在能量谷切开为
`forced_segment_boundary`。后两者保留原候选，不自动承担乐句 LN。

段落表达还在替换、覆盖内部起音之前检查乐句是否为有音高的声音、是否达到
当前最短 LN 长度。例：用户最低长度 1000ms，而候选乐句只有 800ms，仍保留
各个原起音，不会先吞掉内部音，再把整句压成一个单点。

独立复核包含 32 组来源控制、5 类未知尾原因的两条表达路径、最短长度不足
与恰好相等、非音高候选控制。冻结《樱花草》人声重建 1126 个原候选和 97 个
乐句；97 个乐句均是自然活动结束。修复仅改变这些乐句的来源标签，区间与
输出起音不变，不能据此声称本曲乱音得到改善。

这不是唱词音节、音尾真值或制谱手感验收。旧项目已保存的乐句来源不会自动
推断或迁移；需要重新分析，届时可复用声部分离与模型激活缓存重建乐句。
