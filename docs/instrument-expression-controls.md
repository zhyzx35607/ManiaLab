# 按段调整不同乐器类别的表达

源码开发分支增加可选的乐器类别表达：同一条“其余伴奏”中，弦乐类别可以
保留持续音，吉他类别可以只写起音，也可只关闭其中一个类别。设置仅作用
于当前段落，不改变检测候选、音高、原始起止或该声部的主次角色。

这需要采音结果实际携带模型类别。没有类别的候选仍使用原声部方案，
不会根据声轨名称补造标签。当前默认Basic Pitch没有这种类别信息，
YourMT3仍是研究入口；此功能尚未进入新的便携Release。

Tsumugi 研究候选现在也可显示弦乐、合成器铺底、贝斯等中文类别名称，
原始模型身份仍保存，不把版本哈希当作用户需要选择的名称。名称依旧只解释
模型分类，不表示已经分离出可单独试听的乐器；默认分析引擎没有因此改变。

## 使用

在“先规划音乐 · 段落与声部表达”中打开一段，再展开相应声部下的
“按模型类别细分”。只列出这一段检测到的非空类别。

- **继承声部方案**：默认值，维持原来该声部的表达。
- **持续音用LN，短音用短键**：仅已有、达到长度条件且音尾可用的区间能成为LN。
- **连续起音优先**：使用整曲同声轨、同类别的起音上下文；分段不会制造假的组尾。
- **只表示起音**或**本段不采**：分别将本类别表达为短键，或从本段候选中省略。
- 人声类别还可选择已有连续乐句证据；没有支持的乐句不会凭空补长。

保存声部方案后，重新生成候选才会生效。类别选项可以单独开启一个在
本段声部方案中被关闭的类别；全局声部权重为0时仍全部静音。
主声部选择仍针对原声轨，类别不会额外获得主声部权重或重复起音奖励。
改回“继承”后立即恢复上层方案，下个段落不受影响。

名称只解释模型标签。例如“弦乐合奏 · 类别48”不证明该音确实来自弦乐，
也没有增加一条可独立试听的分离声轨。同program的两把琴仍无法分别处理。
错误起音、错误音尾和错误类别仍需回听；这个控制不等于自动判断音乐主次。
