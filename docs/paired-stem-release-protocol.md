# 多曲声轨与放手学习

2026-11-09，准备前记录。前一批社区节奏模型在20个片段上仍未匹配两秒长LN，单曲适配仅匹配《樱花草》后段1/6；新增单曲声学特征并未稳定改善整体质量。下一项实验使用实际多曲声轨，学习声学变化与作者表达之间的关系。

使用现有75份配对库存，其中72份有可核验的四声部缓存，62份全曲、10份裁剪。原音频哈希必须匹配；裁剪必须带原音频身份、起止时刻，不能把裁剪零点当作全曲零点。读取原幅度 `.npy`，不用试听时按声部峰值归一化的 `.wav`。四声部来自公开Hybrid Demucs，不能冒称Nova六声部，也不将能量变化冒称完整音高转录。

继续采用当前7898谱社区数据的歌曲连通分组，覆写旧音频实验的train/validation名称，且报告26份差异。该素材曾参与旧工程研究，因此这是开发比较，不称全新盲测。社区预训练、声轨拟合、验证和测试使用一致分组。只读拟合及验证数组选轮次。

输入人工起音、数量、Timing和LN比例，去掉成品列与尾部；因此这仍是有条件的表达任务，不是自动采音验收。声轨特征采用20ms窗口中的固定PCM能量、起音变化、低高频比例，以及候选区间内的持续程度、放手前后变化；不读取音符标签、书签、绿线或全曲峰值。

每谱最多128组起音，歌曲组/键数加权；区间上下文必须在已知音频范围内，裁剪额外留原审计的3秒边界。从社区节奏模型初始化新增输入为零，24轮按验证损失选轮次。生成对照固定偏置0、平坦与分层流规划（端点权重0.25），不给测试曲单独调阈值。报告逐曲严格起止、长LN及退步；新权重禁用。
