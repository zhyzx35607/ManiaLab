# OaF 鼓模型：完整回归完成，不能替换现有采音

2026-11-10。完成《樱花草》原 Nova 鼓轨和全部23份已有MDB录音。
新模型在部分录音上减少hi-hat误报，但作者分轨的军鼓与第4列差异仍大；
不替换默认采音，没有发行新模型或Release。

## 复现与真实性

按[事前协议](oaf-drums-protocol.md)，使用官方Magenta
`model.ckpt-569400`。加载固定官方函数建立CPU推理图，78个模型变量在
推理前后均逐值等于checkpoint。完整保留8023条预测和88维逐帧概率；
独立实现从概率复解全部事件逐字段一致。没有训练、阈值搜索或拍线吸附。

官方meta是TPU训练图，不能直接当CPU推理图。TF Slim旧Keras导入失败后，
使用其自带fused batch norm推理分支和Tensor类型兼容别名。
第一次正式运行因旧resampy缺少pkg_resources退出，未产生真实音频模型输出；
固定隔离环境setuptools80.9.0后重新运行，失败目录也保留。

实际hop为512、采样率44100，注释中的441没有作用。保留官方全曲峰值
归一化、32767截断PCM16往返、历史kaiser_best重采样、mel前端和整曲
双向LSTM，不切窗。6份合成/原声DSP对照中，librosa0.7.2源码与0.10.2
显式参数逐值一致；这不是对所有输入或历史TF环境的等价证明。
帧数沿用官方浮点表达式裁剪，未改为整除。

## 物理数据的分类口径纠正

首次6类评分仅保留为诊断：MDB把side stick和tambourine记作other，OaF
分别并入snare和HH；OaF又把ride bell与cowbell合组。原other的0/70匹配
不能直接解释为70个物理漏音。

在结果后补充固定subclass兼容评价，不改变预测。逐行核对数量、父类及
时间；Rockabilly允许最多0.5微秒文本舍入差，保留原class时钟。
China15个和Splash10个缺乏明确模型类别支持，单列25个不可评价参考，
unknown之间不算匹配。此补充不是事前已固定的原评价。
