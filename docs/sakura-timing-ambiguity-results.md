# 《樱花草》半速/倍速与 Offset 静态诊断

2026-11-16。规则、输入哈希和复现命令见[协议](sakura-timing-ambiguity-protocol.md)。
本阶段只复用了冻结 JSON 中的候选，并将固定网格与已有 `timing_attacks` 比较；
没有重估 BPM/Offset、读取音频或 Reference、运行模型或更改应用默认行为。

## 结果

冻结输入为 283.84 秒、1,365 条鼓轨 `timing_attacks`。应用原先选择 148 BPM、
Offset 204ms、四分细分，得分 0.7100、细分覆盖 0.8629、中位误差 10.51ms，
但 `stable=false`。

|候选 BPM|Offset|得分|细分覆盖|拍点覆盖|半拍覆盖|可疑 12 秒窗|
|---:|---:|---:|---:|---:|---:|---:|
|74|204ms|0.6397|0.8536|0.4669|0.7165|5/24|
|148|204ms|0.7100|0.8629|0.7165|0.8536|4/24|
|296|2ms|0.7047|0.8022|0.8547|0.8620|5/24|

拍点、半拍和细分覆盖都使用固定 25ms 上限（短网格另按 `20%` 缩小）的加权起音
距离；这是时间网格指标，不是拍感分类。相邻候选的半拍/拍点覆盖接近：74 的半拍
覆盖与 148 的拍点覆盖同为 0.7165；148 的半拍与 296 的拍点分别为 0.8536 与
0.8547。这说明同一组起音支持嵌套网格，不能单靠这些起音决定哪一层是强拍。

74 与 148 的 Offset 相同；148 与 296 的 Offset 在按 296 拍长折返后仅差约 0.70ms。
鼓轨/混音在同一 BPM 的折返相位差为：148 BPM 约 2ms，296 BPM 约 1ms。未发现这些
数值中存在明显的全曲相位冲突，但它们不能验证绝对物理 Offset。

148 BPM 的 4 个可疑窗口位于 0–36 秒与 192–204 秒；局部相位误差范围约
-14.25 至 +4.22ms。74 BPM 多出 96–108 秒窗口；296 BPM 多出 276–288 秒窗口，
并且 192–204 秒覆盖更低（0.344）。现有数值更突出局部覆盖不足，而非大幅相位
漂移。混音来源的全曲覆盖较低（对应最佳 296 BPM 候选 0.5678），其 24 个窗口有
22 个标记可疑；它与鼓轨是相关来源，不应当作独立投票。

因此保留 148 BPM 仅作为当前候选排名第一的估计，不据 0.0053 的细小得分差判断
拍感或质量。自动 Timing 仍不稳定，原确认门槛继续生效。
