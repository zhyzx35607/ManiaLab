# 物理鼓起音训练：独立于作者选音

2026-11-09，模型训练之前记录。此前所有《樱花草》Reference分类实验都混合了物理音色与作者取舍，不能以未写note当作声音不存在。本项改用有逐音色起音标注的数据训练三个可同时输出的物理类别：kick、snare、hi-hat。tom/镲片等不偷偷并入hi-hat；其余类别在本轮是背景，后续需要单独扩充。

数据来自作者发布：

- IDMT-SMT-Drums，Zenodo 7544164，官方MD5 `d2664b4c2aaa34b90ba2f57b389c5663`已核验。说明页面称104个混合片段，实际官方V2压缩包有95个MIX WAV与95个XML，二者完整配对，不虚报104。使用XML物理起音，不使用孤立训练音文件。
- MDB Drums，`CarlSouthall/MDBDrums`固定`b29e2d63c3a023506f4bf353c5b2e8a558eed135`，23条鼓混音和class标签。其余声部不进入本轮训练。

两者权利信息、音频、标注与产物均留在本地研究目录，不打包分发。它们并不是新的人工谱面，训练数据不含《樱花草》及其Reference。

准备数据时发现`RealDrum01_13#MIX.xml`内部写了不存在的`RealDrum02_00#MIX.wav`。继续核对同名SVL：SD/HH数量相同且时刻相符，但KD在XML里8个、SVL里7个。因此这一个身份和标注不一致的条目在训练前隔离，实际使用94个IDMT与23个MDB片段，并记录排除原因；未看模型分数选数据。

另有10个官方起音位于样本零之前0.068–0.204ms。保留原负时间作为事件级真值，并在最近帧生成目标时落到帧零；不删去这些事件或整首测试曲。只允许[-1ms,音频末端)这一已审计边界，manifest列出所有近零事件。首次准备遇到该问题时终止，未训练，失败目录保留；修正后使用新数据目录。

固定划分：IDMT以整套音色来源分组，RealDrum01、TechnoDrum01、WaveDrum01拟合，TechnoDrum02校准，WaveDrum02测试。MDB采用官方MIREX2017测试11曲不变；原训练集按名称排序后，Disco、Rockabilly、Zeppelin这三曲作校准，另外9曲拟合。名称与音频/标签哈希固定到manifest，检查跨划分无重复音频。IDMT各套可能共享节奏型，因此只能称未见音色来源，不称完全独立作曲；MDB可能与已有预训练模型数据重叠，这里仅证明本次从零训练的数据隔离。

前端：22050Hz单声道，2048点STFT，220样本hop（按真实hop记录时钟，不假设100fps），80个三角mel频带，功率`log1p(power*1e5)`。每频带均值/标准差仅来自拟合音频。小型时间卷积网络从零训练，多标签3类输出；256帧训练中心加32帧前后上下文，边缘补训练均值；不用拍位、节拍和谱面时间先验。

网络固定为80→64通道、宽5的输入卷积，再接宽3、膨胀率1/2/4/8的四个64通道残差卷积，SiLU激活，最后1×1输出三个logit；无批归一化或时间全局归一化。有效时间半径17帧。训练前以256/2048中心分块检查输出相符，避免分块边界改变检测；代码、协议及模型身份写入实验目录。

固定seed42，Adam学习率0.0003，30轮，批16，正例BCE权重10；起音标签最近帧1、两邻帧0.25，其他0，重复标注保留事件级评价。只以校准集BCE选epoch（含epoch0），不查看测试或《樱花草》选模型。选定后按校准起音F1选各类阈值0.1–0.9、步长0.05，峰间隔30ms。报告物理起音20ms与40ms容差、逐曲/逐类及微平均，测试仅最后一次评估。

另用未改动的应用起音候选作为不区分类别的召回对照；全类候选上限不能当分类准确率。固定模型完成后再对《樱花草》原float鼓轨推理，仅对作者选择作受限参考，禁止用它重新选阈值。独立物理标注准确度、作者取舍及成品LN验收是三件事，本次不能替代后两者。
