# ManiaLab 0.1.0-alpha.4 · 四声部采音、LN 与 6–10K 编排

下载 `ManiaLab-0.1.0-alpha.4-windows-x64.zip`，**完整解压**后双击 `ManiaLab.exe`。完整包包含 CPU 运行时、四声部模型、节拍 / 音高模型及 FFmpeg，不需要安装 Python、Docker 或 CUDA。`SHA256SUMS.txt` 用于核对下载文件；普通使用只需要 ZIP。

这次重点处理“先采好音，再写谱”：

- **四声部深度采音**：真实分离鼓、贝斯、人声和伴奏，再检测起音与持续区间。可逐声部试听，检查串音和音尾；连续人声支持跨音高长条。
- **Timing 与完整落线**：整理数值噪声，固定 BPM 重新拟合整数 Offset；保留真实特殊小数候选。短键和 LN 起止完整量化，实际导出文件逐端点检查。页面支持 3/4/6/8/12/16 拍内细分。
- **可见的时间约定**：新项目「制谱提前量」默认 22.5ms，可设 0 使用原始音频时钟。粘贴参考 Timing 后直接使用输入 Offset。旧项目保留原有时间行为，不静默挪动。
- **LN 数量与占轨**：可调目标比例、最短长度、同时 LN 数、人声持续段和声部取舍。全曲选择起音，再在持续证据与轨道约束下选择 LN；显示实际和可达比例。
- **连续定轨**：多排搜索考虑 LN 占轨、释放及双手负担。小型轨道偏好模型在 6K/7K/10K 启用，可关闭；8K/9K 保留普通搜索。严格重定轨保持原谱起止、数量、音效和变速。
- **检查工具**：同一 PCM 内的 Offset A/B、起音 / 放键提示、毫秒波形、直接定位 LN 尾端、参考 `.osu` 偏好导入和局部重写。计算期间相关参数锁定，避免修改被完成结果覆盖。

《有点甜》的同一份用户音源，固定 210 BPM 的四声部重新拟合为 **93ms**，与参考工具固定 210 的结果一致。10K 对照谱的 1,947 个导出端点全部落线；这证明该项时间行为得到修正，不能据此保证任意音源自动对准或音乐表达合格。含用户音频的对照包未放入公开 Release。

升级后建议重新进行深度分析并生成整谱。项目自动保存在 `%LOCALAPPDATA%\ManiaLab\projects`，更新程序文件不会删除它们。先读随包的 `docs/quick-start.md`，重点在歌曲开头、中间和结尾试听，再导入 osu! 试打。

本版经过自动测试、真实配对歌曲统计、Edge 页面操作，以及干净 Windows 环境的实际 EXE 离线验证。详细成功、失败和来源记录在 `docs/validation.md`、`docs/audio-audit.md` 和 `docs/ln-audit.md`。

**仍是实验版**：自动 Timing 不稳定的歌需要手动校准；尚不自动生成多段变速红线。LN 检测与人工谱师的收尾取舍仍有明显差距，也未完成玩家盲评或端到端 10K/LN 大模型训练。目前不能宣称全面超过 Mapperatorinator。可选 API 助手读取统计提出编排参数，不上传音频，也不能代替采音模型。
