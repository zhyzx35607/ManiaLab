# Transkun 真实钢琴与 Nova 声轨对照

2026-11-10，在本轮真实音乐推理前固定。独立声源控制仍在运行，已发现新模型减少部分重复预测、也新增漏采，因而不满足原协议的直接替换条件。本协议不修改或追认该门槛；补充真实音乐对照，是为了判断这些取舍是否发生在实际演奏和用户的分离声轨中。无论结果好坏均完成同一范围，不训练、不融合两模型、不改变应用。

## 范围与输入

- 使用既有 SMD manifest 全部11首，SHA256 `f1e7bcffc17e9aa5399aa2e923939748e3c9cc2a29e8e1b0a766e2fbc20e3c6b`。每首输入前70秒、评分前60秒起音，沿用原录音和 MIDI 按键/踏板延音标签。这些是已用于开发的历史回归资料，不是盲测。
- 与保存的 Kong `specialist-v2` 完整结果比较，report SHA256 `ab23fa8f30d79e6dcb2a167eeaaada3c47ed3bfdfba55c16e99448125d39cda6`。不重复推理后挑一次较好的结果。
- 最后运行用户 Nova《樱花草》完整283.84秒钢琴轨：`raw-pcm-audit-v1/piano.wav` SHA256 `8eb46bbdf283028e5f5d4c13169741e734cc57f0bfd2fe3f19dd590f38ad2722`。比较便携 Kong 的1557个原候选，report SHA256 `4354670c70f39a0420f99a33f1bc9b8c1715d043a19aed363cdd3dd88fb21a30`。
- SMD 的22050Hz int16除以32768，Nova 的22050Hz float32保持原幅度；都先按原 Kong 输入路径 `resample_poly(320,441)` 得到16kHz float32，再以 `resample_poly(441,160)` 给 Transkun。这样不会让新模型额外获得原模型没有收到的高频带宽。保存两个实际PCM数组及hash。不归一化、不按标签移动音频、不输入谱面或Timing。

模型、完整配置、16秒窗/实际hop、分窗记录与官方解码均沿用[控制协议](piano-transkun-controls-protocol.md)和同一冻结runtime。先完成91例控制和一次包装器验证，再顺序运行12份音乐；同一时刻仅跑一个声学推理进程。

## 评分和解释

SMD沿用原同音高一对一最大匹配：50ms起音，以及40ms对照。完整区间的普通音尾容差为max(50ms, 参考长度×20%)；40ms起音对照使用固定80ms音尾容差，故并非对所有短音都更严格。分别保存原按键结束、踏板延音结束的区间结果；两模型音尾训练语义不同，这两套区间比较只说明与各参照的距离，不是LN放手验收。评分窗内所有预测进入分母，音尾越界不能据此删除。完整预测、负音高踏板控制、输入区间外输出均另存。

报告逐曲和合并的precision/recall/F1，以及对应同一个参考起音的新漏与找回数；不只报告总数之差。按固定音区21–47、48–83、84–108汇总起音匹配，用于检查控制中观察到的高音退步。按键与踏板标签的起音/音高必须逐项相同。

Nova没有完整物理音高和放音真值，不能凭预测数量给准确率。额外记录两模型在同音高±50ms的一对一一致性，并与Reference第5/6列的起音组作差异诊断：沿用30ms非链式分组、40ms匹配，同时报告原时钟和预先固定的22.5ms制谱提前量，不搜索最佳偏移、不吸附已知拍线。人工谱的省略不标成模型假音，不能为贴近1038个短键而自动删音。

这些结果用于决定下一次可验证的声学改动。即使汇总分提高，也要保留逐曲退步、控制中的新漏音，并检查原声波形/频谱与事件差异；没有稳定音乐收益就不启用、不发行。本轮未执行直接听感验收，公开研究汇总不含原音、逐音标签或模型权重。
