# 通用采音的音尾来源（2026-11-10）

修复了Basic Pitch候选没有记录终止原因的问题。输入音频结束时仍在持续，
或结尾不足五个低激活帧时，原来会被当作可用于自动LN的音尾。
现在保留这个起音和原始检测区间，但不根据缺失的结尾上下文自动生成LN。

这影响快速分析，以及分轨后使用通用模型的贝斯、吉他、人声、钢琴和其他伴奏。
钢琴专用模型和YourMT3研究模型各自已有的解码来源不受本次修复影响。

## 来源含义

|release_reason|实际观察|自动LN资格|
|---|---|---|
|`frame_decay`|扫描到连续五个低于阈值的模型帧|保留原有资格；不是物理松键真值|
|`same_pitch_reattack`|到达下一个已接受的同音高起音|保留原有资格；不是检测到独立停音|
|`input_boundary`|输入耗尽，尚未观察到上述任一终止依据|保留起音，自动表达为短键|

以循环实际停止分支判定，不从最后一个毫秒数反推原因。最后一个时间单元
自然可能略超出音频时长；这不等于模型有每音时长上限。若传入的缓存中
已经有时间戳位于声明音源之外，则拒绝该不匹配输入，不能借用音源结束
之后才出现的衰减作为有效证据。

波形近静音收尾、起音校准、声部标记和候选序列化保留来源字段。
波形收短不会把未知结尾自动升级为已观察到的物理放音。现有全局LN选择
和按段表达均使用同一未知结尾保护。没有改变阈值、起音、音尾算法或
自然模型衰减的LN资格，也没有新增强凑比例的规则。

本轮只让已有音尾证据可追溯，并挡住确定缺少结尾上下文的自动LN。
真实起音误差、谐波误检、段落主次与音乐放手选择仍需分别验证。

## 验证与缓存

固定激活控制覆盖自然衰减、重弹、末尾仍活动、末尾不足五低帧、音源短于
缓存、末帧单元略超时长，以及波形收短/起音校准后的来源继承。
六种声部通过全局和分段两条表达路径核验未知结尾保护；实际深度分析
从五轨激活缓存重建来源，无需模型重新运行。真实模型合成音测试也核验来源。
