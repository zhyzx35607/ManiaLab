# LN建议与音尾资格保持一致（2026-11-10）

已修复推荐层和生成层使用不同音尾依据的问题：生成器不允许明确未观察到
结束的区间自动变LN，但此前编排建议仍用这些长区间计算持续比例、共同放手、
反键接续等机会。现在两层都排除已明确标记的未知结尾。

推荐计算保留其起音、音高、类别、密度及声部，只在临时建议视图中将这类
区间视为短键。原始analysis与实际生成输入不变；未知音尾长度本身不再决定
LN建议。若没有任何达到最低长度的有效持续区间，LN倾向为0，分段文案为短键。
已有有效长音与未知尾候选的可靠起音仍能形成“长按中的短键”。

另统一了键型机会的最短持续阈值：高BPM时不再把低于100ms的音同时称为
短键和长按。没有改采音阈值、主声部角色、声部权重、音符起止或布局算法。
