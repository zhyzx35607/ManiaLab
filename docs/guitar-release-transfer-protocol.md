# 吉他未知尾的跨模型证据检查

这是一项在看到第一批 GAPS 输出后提出的开发实验：部分起音较好，很多数值尾却是
同音重弹截断。它不是盲测，也不在这批标签上搜索阈值。先固定本规则，等待两模型
全部 120 份原推理完成后才执行，不改变正在运行的转录协议。

每份吉他录音使用相同原始输入的 HF 候选和已冻结 Basic Pitch 候选。HF 的全部
起音、音高、事件数和强度逐项不动。只尝试给明确标为未观测结束的
`reattack/duration_limit/input_boundary/frame_inactive` 提供另一模型的尾证据。

固定规则：相同 MIDI 音高、非鼓、起音距离不超过 50 ms；两侧都只能有唯一匹配。
匹配图包含所有原始候选，不能先删掉未知尾来制造唯一性。同音齐奏或快速重弹
造成歧义时不转移。供体必须是 `frame_decay` 且没有明确的 `release_observed=false`，
其结束必须晚于接收者起音、早于真实音频终点。同音重弹封口、补零终点、未知尾
均不能提供证据。不选择最接近参考答案的音尾，不平均端点，也不把结束强制吸拍。

推理仍在运行时的符号审查补充了一条约束：起音唯一不代表同一根弦持续到供体音尾。
若供体尾跨越后续另一个 HF 同音高起音，整次转移拒绝，并保存被跨越的候选索引，
不将尾截到新起音冒充停音。此规则来自 1.0/1.2 秒两起音的构造反例，在真实录音
转移实验执行前确定；没有据实际收益改规则。它可能放弃真实的跨弦同音延续，属于
保守限制，也不证明被接受的匹配就来自同一根弦。

成功时只替换尾并保存双方原始索引、起止与原因；这仍是另一个模型的衰减假设，
不是物理松手真值。原神经输出不覆盖。无法满足条件的全部事件原样保留在评分分母，
不会因为尾不可信而删掉音符。Basic Pitch 的 `same_pitch_reattack` 在既有应用中有
独立的音乐边界策略，但它不作为本次“独立停音证据”的供体。

分别对 GAPS、FL 完整 60 例执行同一规则，两者均与自己的原始结果比较。起音指标
必须完全不变；完整区间继续保留相同 59 例可评子集、不可评原因和全队列分母。
不因某个组合更好而逐曲换模型。记录转移数、失败原因、实际区间收益与退步；
只有明确收益后才考虑真实分轨与表达层测试，不自动进入应用或变成 LN。

入口 `scripts/research_guitar_release_transfer.py`，输出全部逐音与逐项证据。
六个符号控制覆盖同音齐奏、快速重弹、跨越后续同音、供体歧义、人工封口、真实输入边界，
以及起音/强度/原输入不变。完整实验不新增神经推理。
