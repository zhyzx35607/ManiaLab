# 扩充语料与重新训练协议

执行日期：2026-11-08。以下条件在扩充快照训练前记录，用于约束筛选、验证和交付，不是预注册的独立科学实验。

- 发现来源为 Sayobot 的公开查询：所有语言，mania，6–10K，Ranked / Loved。遍历分页到末页；镜像返回的全站 `results` 不当查询命中数。覆盖镜像查询不等于覆盖全部 osu! 谱面。
- 下载优先用 Sayobot 自身前端提供的 mini 谱包地址，通过 HTTP Range 取 ZIP 目录和谱面压缩区间。记录压缩包 ETag、传输字节数、原谱 SHA256。CRC 与成员大小都核查，不提取音频和图片。
- 已取得官网逐谱状态与 MD5 时，用校验码确认身份，允许文件内部 BeatmapID 陈旧。只有镜像元数据时明确记录 `mirror_beatmapset`，不伪称逐难度官方认证。
- Loved 候选必须补查逐难度官网状态；页面不可用时不进入核心快照。撤回、未获选或消失的难度保留排除记录，覆盖旧版缓存。Ranked / Approved 仍有仅镜像谱包状态的记录，报告分别列出。
- 失效或版本陈旧的镜像项，仅在已有官网逐难度状态与校验码时允许官网补取；下载来源与官网核验来源分别记录。一次谱包下载失败不会对包内每个难度重新发起同样的镜像请求。
- 从旧语料发现查询遗漏的已知 Loved 包时，先逐难度查官网，再用 `--include-set` 补入并记录。续跑保留这个补充清单。此次补充 7 包不计作原查询命中；旧数据的 Loved 标签也需要核验，不能只审查新增下载。
- 原生格式、键数、结构冲突、物件数和手布局先检查。按键数去重完全相同的布局；同一 ID 以较新来源覆盖旧版，排除记录也覆盖旧版。
- 普通表达参考与 `layout_only` 分开。标注转换 / Inverse 的有效谱可供固定时间轨道学习，不作为乐器持续时长或默认 LN 长度校准。
- 对采音建议的统计按歌曲组等权。LN ≥50%、15–50%、<15% 分开统计；阈值是本项目的描述性分桶，不是社区官方类型定义。
- 轨道网络固定 101 特征、64/32 隐藏层、pairwise softplus、镜像增强和随机种子 20261107。每曲每键数约 5000 对上限，多个难度共享配额，采样覆盖全曲。
- 按歌曲名、音频哈希和谱包建立连通分组后划分，禁止同组跨训练/验证/测试。元数据异名仍可能漏合并；作者并未完整隔离，结果不能称作跨作者泛化。
- 批次按键数以及 LN 上下文 / 普通短键均衡。验证以键数和两类上下文的平均损失选轮次，测试只报告。
- 各键数启用需至少 8 个训练歌曲组、3 个验证歌曲组、3 个有 LN 上下文的验证组，且整体和 LN 上下文验证准确率均 ≥60%。不因测试成绩选择轮次或降低门槛。
- 指标是人工排相对合法替代排的打分准确率，不是生成谱好评率。每键数、LN / 短键分别报告，保留退步。
- 发布前另外检查真实歌曲建议、原始采音不变、6–10K 落线与导出、浏览器状态、便携 EXE 离线启动和退出。原谱与音源不随模型或 Release 分发。

对当前用户需求的最低交付是可执行的编排建议、扩充后可审计的数据与受控训练、实际 Windows 程序以及准确的限制说明。没有玩家盲评或独立音频真值时，不声称已经学会所有谱面表达、完美采音或全面超越上游模型。
