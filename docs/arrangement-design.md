# 根据声音证据提出编排方案

从音频分析开始，先提出旋律与放手、均衡 Hybrid、密集多声部三个方向，再让用户选择并调整。方案解释哪些检测音支持它、局部密度上限及 LN 目标，绝不把建议值标成 osu! 星级。

语料的作用是提供键数与风格分布，以及固定时间下的轨道偏好。新曲的起音和 LN 尾端必须来自新曲检测。Ranked / Loved 的作者选择是参考，不是所有声音的完整转录标签。

## 当前实际执行的流程

1. 保留原始起音、持续区间、检测强度、声部和有连续证据的人声乐句。
2. 按目标键数读取独立的语料统计。同一首歌的多个难度先在曲内汇总，歌曲组之间等权。短键、Hybrid 和 LN 为主的谱分别统计。
3. 依据本曲强度达到 0.35 的候选，提出全局和局部方案。采用方案后实际生成使用同一候选范围；原始采音不删除，清除方案可手动取舍弱音。当前分段使用约 15 秒分析窗口，不声称已经识别主歌、副歌或完整乐句。
4. 用户采用后，方案真正进入起音取舍、LN 选择和轨道搜索。之后调全局密度、LN 比例和协调滑块，也会相应调整局部建议。空白窗口不会被补出 LN 配额。
5. 在已确认拍线下选择音符并量化，使用 LN 容量与未来起音约束求解，再做连续轨道搜索。导出后重新解析文件，核验数量、起止、轨道与落线。
6. BPM、键数或采音证据改变时，旧本地方案失效，要求重新选择或清除计划。采用方案不会覆盖用户已确认的 Offset 和制谱提前量。

“旋律与放手”使用较低的语料密度分位，并参考 LN 为主的样本，避免被高速短键谱的平均密度推高。其低负担目标仍只是编排方向；低密度不保证释放容易，高密度也不保证音乐丰富。

## 可以考虑的表达情况

下表是设计词汇和条件，不表示每项都已有独立学习模型。当前自动机会识别与局部定轨能覆盖其中一部分；跨乐段动机记忆、乐器主次识别和真正乐句级难度规划仍待验证。

| 声音或结构条件 | 可考虑的表达 | 必须检查的依据 |
|---|---|---|
| 同时起音、同时收尾的持续层 | LN 和弦 | 各层都持续，不能仅因和声相同就拉等长 |
| 分次进入、共同结束 | 递进入手、共同放手 | 只在检测尾端本来接近并量化到同尾时采用 |
| 同时开始、分次结束 | 阶梯释放 | 双手的放手顺序与间隔是否可读 |
| 起点、终点都错开 | LN 协调 | 同手相邻释放与按键是否过密 |
| 一条持续音内有另一声部短音 | 长按中的短键 / Hybrid | 短音确实存在；同手与分手是可选负担 |
| 多条持续层很少短音 | 进入与放手的层次 | 不靠新增短键填满空白 |
| 人声换音高但声音连续 | 跨音高人声长条候选 | 持续覆盖、呼吸缺口、重新发音与串音 |
| 人声停顿，伴奏仍延续 | 由伴奏承接持续层 | 不能把人声 LN 无依据地跨过停顿 |
| 同一音高重新发音 | 分开起音、重新进入 LN | 不被连续音高平滑成一根长条 |
| 同一声部节奏稳定重复 | 保持可辨认的布局动机 | 当前检测只能提示，跨乐段复现尚未完整实现 |
| 连续上行或下行 | 与旋律方向一致的轨道移动 | 同时和弦的多个音高不算连续旋律 |
| LN 结束后短正间隔再起 LN | 反键接续候选 | 空隙真实存在，不能填长间隙伪造 Inverse |
| LN 尾端附近有新短音 | 放手后短键、或分手接短键 | 放与按是两个动作，避免把同步事件重复计罚 |
| 短音之后进入持续层 | Shield 或分轨进入 | 保留短音起点与新 LN 的真实起止 |
| 相同持续层由不同声部交接 | 换手或轨道接续 | 不能仅因相邻时间就认作同一乐句 |
| 长音与快速装饰音并存 | 保留主持续层，选择装饰音 | 低密度方案需要舍弃部分装饰，仍保留主重音 |
| 密集琶音或多个同时音高 | 多声部、和弦或轮替 | 音高检测的谐波、跨声部分离重复要先排查 |
| 鼓密但旋律稀疏 | 节奏与 LN 的分层 | 鼓的衰减尾巴不能直接当可听的持续旋律 |
| 原曲稀疏、停顿多 | 留白、少量起音及清晰释放 | 不以曲风或“高难”目标要求程序凭空添音 |
| 段落逐渐增加声部 | 分段增加密度或同手配合 | 先有新增声音；当前窗口统计不是渐强语义识别 |
| 段落突然变薄 | 降低占轨、突出收尾 | 不能沿用前段的密度配额填空 |
| 乐句结束、余响仍在 | 按可辨结束组织放手 | 分离残留和混响容易把尾端拖长，需要试听 |
| 很短但清晰的持续音 | 短 LN | 用 BPM 和实际长度判断，不使用全曲固定 240ms 一刀切 |
| 长时间同时按住多轨 | 控制占轨与可用手指 | 物件数少也可能很难，需要释放与手指负担共同评估 |
| 变速、三连音、切分 | 在对应节奏网格检查起止 | 当前新谱仅单段 BPM；变速原谱只能严格保时重定轨 |
| 用户想强化反键或高难 | 增大对应偏好并对照候选 | 参数只控制现有声音的表达，不证明可玩性或音乐质量 |

## 从参考谱学到什么、没学到什么

小型轨道网络对“人工当前排”和“同历史下合法的替代排”打分。新增训练按键数与 LN 上下文均衡采样，加入不同放手顺序的合法候选，同曲多个难度共享限额，避免一个谱包支配学习。

标明 Inverse / 转换的谱可以进入 `layout_only` 参考组，贡献固定时间下的轨道几何；它们不进入默认持续长度校准。7+1 / IIDX 与 4+6K 属于不同手布局，仍不作为普通 8K 与 5+5 的 10K 训练样本。

没有配套音频、准确时间对齐和持续音标注，仅增加 `.osu` 数量无法教会模型听懂乐器音尾。本轮扩充解决的是风格覆盖、布局偏好和建议依据；采音、音乐性与玩家体验另行验证。
