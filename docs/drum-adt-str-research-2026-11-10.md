# 细分鼓采音：已经核验的失败与下一步

本轮补全原float音频和解码证据后，已停止未完成的MDB扩展回归，未启用应用或发布新模型。官方细分鼓模型在Nova《樱花草》上发生重复输出和未正常结束，不能直接用于生成器。模型耗时长并不代表声学分析可靠。

## 完成范围

固定候选、输入、分窗、时钟与评价在真实推理前写入[协议](drum-adt-str-protocol.md)。使用原始float鼓轨，保留超过1的幅度；69,000,824个参数、132个state tensor严格加载且逐项核验。官方模型逐窗真实运行，原token、官方解码、连续完整三元组解码及24kHz输入分别保存。音源和checkpoint不随公开仓库分发。

完成完整283.84秒《樱花草》及MDB的80sRock、Beatles；BebopJazz仅完成32个窗口，其他20份MDB未运行，不能将两份成绩冒充全量结果。三个完整输入已由独立实现复算DSP，PCM逐bit一致；原始token到严格事件、官方兼容事件均逐字段一致。独立检查没有再次执行模型。停止时未执行原runner末尾的全模型state核验，只有初始严格加载证明与已经落盘产物，不能冒称完整冻结推理验收。

## 《樱花草》的实际失败

111个窗口中15个没有EOS。完整连续三元组共有3417个事件，其中同刻同custom类别多余2076个；精确四字段重复为2067个。官方解码在`np.unique`之前产生3419个事件，之后仅剩1352个。去重隐藏了重复问题，没有恢复后续被循环耗尽的时间覆盖。

官方比严格解码多出的两个事件来自窗口100：缺少力度后，官方用默认力度100，再把不同索引的时间和pitch相配。它们不是模型输出的两个完整音符。本项目分别保留这两条路径，禁止把解析修正说成声学模型进步。

最早没有结束的窗口从10.24秒开始。同类重复在合法三元组阶段就出现；最终在token297本应输出力度处连续输出pitch353。该窗口98个合法事件仅10个精确唯一事件，最后可解析起音为12.35秒。15个未结束窗口在最后可解析时间后的空白合计约23.439秒，原PCM均非零。这说明输出停滞，不能直接据非零声波推算漏了多少鼓击。

《樱花草》是作者选择对照，不是所有真实鼓击标签。原时钟、40ms同类一对一匹配：

## 目前两份MDB的有限结果

80sRock和Beatles共30个窗口均正常结束，两个解码路径事件一致。40ms物理标签合并：kick110/110匹配、10额外；snare66/80匹配、1额外；tom18/30匹配、2额外。两首没有物理hi-hat参考却提出2个hi-hat，不能用这两首论证HH识别改善。其他类别及20/50ms结果一并保存，但本候选不继续全量评价。

## 原声检查与限制

已生成16个固定最早遗漏、额外和循环片段，保留原采样率、原幅度音频、波形、频谱与三条事件时间线。主线程实际看过《樱花草》首个未结束窗口、第4列首个hi-hat差异，以及Beatles首个军鼓遗漏图。

10.24秒附近可直接看到单个起音位置反复输出多次。123.826秒附近模型保留部分接近参考的起音，但将其归到其他打击乐；单靠波形和频谱尚不能把每个音色判定为hi-hat。Beatles的近邻军鼓起音也出现只采一次的情况。上述是图形和标签对照，未完成亲耳试听或可玩谱音乐验收。

边缘遗漏统计基于所选最大匹配；等价最优配对可能改变具体遗漏归属，不能把其差值直接当成确定分窗漏音。官方鼓尾固定0.1秒只是格式占位，完全不用于LN持续或放手。

## 重复路线纠偏

核对项目既有[ADT_STR研究记录](adt-str-research.md)后，发现此前已用相同源码、相同权重做过完整int16输入实验，以及同tick同custom去重的[事件语法对照](adt-str-grammar-protocol.md)。旧语法实验第4/5块已达到512上限且未EOS；原float单块也已经不能解除原模型循环。交接摘要遗漏了这一历史，导致本轮重新准备了相同方案。

本轮新增的原float全曲、两份MDB、独立解析与原声图仍有诊断价值；继续重复同类语法神经试验不值得。刚写出的新采样器、runner、协议和测试已在首次神经推理之前撤回公开改动，归档至本地`withdrawn-duplicate-grammar-v1`，保留源码哈希和未运行状态。不能将撤回候选的符号测试通过说成新模型收益。

同时核实并终止本轮唯一原模型进程24724；工具会话24886返回exit code 1。完整与部分产物未删，`inference-v1/termination.json`记录停止时间、全部哈希、已完成曲目和部分窗口。此决定明确偏离事前23份MDB计划，不创建假的完整`report.json`、不宣称全量完成。后续方向是扩展可靠物理音色训练来源，并把“没有起音”和“起音被归入另一类”分开诊断。

第4列新诊断中，132个作者事件在原时钟±40ms内有126个存在任意鼓类候选，其中28个有HH、98个只有非HH，6个没有任何类；固定22.5ms提前口径为127、27、100、5。三段原时钟任意类覆盖分别39/41、15/16、72/75。123.826秒对应custom57 Guiro、预测123.83秒，不能只据模型名称把它当成已确认的刮瓜或把作者改成错误。64个参考的最小误差配对有多解，60个涉及不同语义候选；因此高起音覆盖也没有证明音色已经正确。该诊断仍不改变类别映射或做本曲训练。

应用默认、Release与训练权重尚未改变。
