# 将上下文差异拆成观察边与归一化

2026-11-09，首次因素对照推理前固定。`rest-v1` 已完成：修图后《樱花草》适配组件仍有141次整曲/四小节长短表达翻转；不能把剩余问题归因于某个尚未隔离的因素。本轮不重训、不选模型、不改LN规则，不读取test数组。

冻结输入、两套权重、16份validation的clean/whole和《樱花草》与rest-v1相同，先复现修复后的完整图预测。所有图都先删除已确认的非未来rest边。每个案例保持全部节点、节点顺序、候选边、特征、时间和后处理入口，比较四种组合：

|组合|观察关系|GraphNorm统计分组|
|---|---|---|
|full_global|完整图正常边|全部节点|
|cut_global|移除跨四小节窗口边|全部节点|
|full_window|完整图正常边|按四小节窗口|
|cut_window|移除跨四小节窗口边|按四小节窗口|

仅过滤onset/consecutive/during/rest观察边，候选边全部在小节内，必须断言它们从不跨窗。正常反向边仍由官方predict创建。GraphNorm通过临时forward前钩子传入固定窗口batch，使用原权重、公式和eps；其他层不变，推理结束移除钩子。检查所有GraphNorm模块调用、输入节点数量、参数原样和窗口覆盖。不修改冻结上游源码。

验证full_global逐数组复现rest-v1的完整图；cut_window的三个原始输出头按候选边对齐，与rest-v1真正逐窗推理比较。浮点一致性门槛预先固定为`atol=1e-4, rtol=1e-5`，另报最大/平均绝对差、staff分类翻转、概率门槛翻转、最终预测边与同小节组件关系差。不能仅凭浮点近似一致就宣称最终分组一致：同分匹配或临界概率可能导致后处理变化。若仍有明显残差，报告残差，不宣称两因素已经完全解释全部上下文差异。

保存四组合预测和文件SHA，报告逐曲和汇总同声部pair F1及staff准确率；同一观察边下比较归一化、同一归一化下比较观察边，并记录两者交互。结果用于定位机制，不按最高分选择默认推理组合。

《樱花草》仍复用原1557钢琴候选、原段落和相同连续起音表达；按staff/components记录每个组合对基线的双向长短变化及cut_window对真正逐窗的残差。没有修改音频采音、Timing、音尾证据、选音或定轨，不称成谱质量通过。所有音符级结果保留忽略目录，公开只保留统计与身份。
