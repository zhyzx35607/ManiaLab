# 起音规划的声学证据增量

2026-11-09。在节奏模型的同曲和跨曲成绩已被查看后提出，不声称全新盲测。

已观察到的限制：社区预训练再做单曲适配后，全曲可以生成两秒以上 LN，但同曲后段六条这类人工 LN 仍然零匹配。只知道起音节奏和粗声部数量不足以决定持续表达。

本次保留同一批检测起音、终点候选和训练区间，增加冻结 YourMT3 的局部观测与 Nova 声轨能量：起始音高数量、持续时长分布、乐器 family 分布、强制分块截断标记、区间内同音高覆盖及重弹、候选尾部附近显式／强制音尾、前后 RMS 变化。物理音尾只是特征，不直接生成或限制 LN 终点；覆盖多个重弹也不被当作“证明连续持音”。

不读作者 Reference 的音尾或成品声部标签。RMS 使用固定 PCM 标度，不用全曲峰值／分位数归一化。物理时长特征最多观察八拍，候选上下文仍需完全位于各数据划分内。

从社区节奏模型初始化；旧特征保留原标准化，新特征只用拟合区间估计尺度，第一层新增权重初始化为零。80 轮，按既有校准区间损失选轮次，再按原先固定列表校准偏置和放手代价。比较无限制及使用原 LN 条件作数量上限的两种输出，同时报告两秒以上完整 LN 的匹配，不能只看新增长条数量。

这是已看过的同曲开发诊断。社区语料本轮没有逐曲音频，不能把它称为已训练的通用多声部声学规划器。
