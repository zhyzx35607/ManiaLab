# Mapper音频表示与放手规划

2026-11-09，研究权重未接入应用，未达到整体交付标准。

采用固定Mapper mania编码器的真实音频路径：16.376秒窗口、8.192秒步长、保留中心区。卷积前端脉冲核验时间间隔为16ms，但注意力混合完整窗口，不能称每个向量都是独立音符。输入仅为核验过的原混音准备WAV，没有作者音符、Timing或书签进入编码器。

共72份配对谱，训练/验证/测试为{'validation': 8, 'train': 57, 'test': 7}。32维PCA只用训练歌曲拟合；同样本纯节奏对照的标签、权重、起音与78维节奏前缀逐项一致。独立歌曲组与缓存身份核验通过。

放手模型仍接收人工起音/物件数、Timing和整曲LN条件。这是表达实验，不能当作自动采音通过；也没有学习成品LN的乐器归属。两种模型均从社区模型初始化，24轮按验证损失选轮次，允许epoch 0。

|版本|选择轮次|验证损失|
|---|---:|---:|
|mapper-release-model-v1|2|0.96556|
|mapper-release-rhythm-model-v1|3|0.99254|

实际生成固定中央最多16秒、24拍前后文，分层流规划、偏置0。所有决定先落盘再评分；超过音频缓存的候选明确拒绝，不作边缘夹取。逐曲排除及原因见机器报告。

|划分|片段数|音频表示F1|同样本节奏|社区原模型|改善/相同/退步|
|---|---:|---:|---:|---:|---:|
|validation|8|0.2420|0.2365|0.2320|3/2/3|
|test|7|0.2366|0.2841|0.2578|2/3/2|

|划分|音频表示严格F1|节奏严格F1|音频表示≥2秒匹配/参考|预测≥2秒|
|---|---:|---:|---:|---:|
|validation|0.2420|0.2365|2/7|3|
|test|0.2366|0.2841|1/1|1|

结论：不启用。验证平均值略增，但测试相对同样本节奏模型和社区模型均退步，长LN没有新增匹配。两秒长LN在测试片段中仅1条，证据不足。小模型记住音频表示也不等于学会音乐表达。

这是开发对照。平均F1或训练损失不能代替逐声部试听、全曲持续表达、自动Timing及6–10K手感验收。原音频、谱面、逐事件数据和权重仅在test-data中；公开机器报告保留逐曲统计及身份哈希。
