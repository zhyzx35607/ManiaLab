# 贝斯完整对照（2026-11-10）

IDMT-SMT-Bass-Single-Track 的全部 17 录音已按固定协议跑完：当前应用的
Basic Pitch 加后处理，与 Tsumugi `bass_v2` 比较。普通贝斯起音、误采和
完整区间总体改善，但无明确音高的敲击、滑音、弯音和部分打弦仍有问题。
这批结果不能直接证明 Nova 分离残留上的准确率，也不能替代 LN 编排验收。

模型使用完整原音频，评分从 0 到 min(20秒,音频时长−2秒) 的全部起音。
全录音共 948 个参考音，评分窗为 818；不能混用分母。已知是贝斯只用于
选定专用权重，未把逐音技巧标签、音高或节拍给模型，未按类别删预测。

另一口径仍完整保留，80ms对短音不一定更严格。

17 例两项 F1 都提高，但不是每个音都改善。标准起音匹配在 `001`、`006`、
`014`、`017` 分别减少2、1、3、1；`017` 完整区间匹配减少5。
固定口径起音匹配 `001`、`006`、`017` 减少1、1、3，区间 `006`、`017`
减少1、5。按音符数更少得出的 F1 改善不能掩盖这些损失。

以下是先全局匹配、再按参考技巧归类的标准起音召回；不单独重匹配各技巧，
也不为未匹配预测猜测技巧来制造子组 F1。

独立最大匹配复算了全部204个指标格和逐技巧汇总。标准起音的净增加54来自
补回80个参考、同时丢失26个原匹配；固定口径净增加112来自补回144、丢失32。
`017` 标准完整区间的净减少5是丢失13、补回8，其中11处损失来自尾部，
10处为泛音。九个泛音预测尾比标注长约399–1221ms；这些仍是模型尾假说，
不能为追回分数直接截成标签长度。`013`、`016` 不考察音高的标准起音匹配
另减少6、2，不能只检查有音高口径的四个退步例。
