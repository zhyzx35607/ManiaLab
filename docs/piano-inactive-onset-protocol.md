# 无持续激活候选的起音探索

2026-11-09，在本轮匹配和消融执行前固定。前一轮迟到 frame 诊断中，16 个评分窗内音尾改动有 12 个找不到同音高、50ms 内的参考起音，这一已见结果参与了本轮构思。本轮是探索性开发分析，不是盲测，不能用于宣称独立泛化收益。

只使用已冻结的 11 份 SMD 演奏：从 70 秒已保存事件中选取 `0 <= onset < 60`，参考使用同样窗口的按键 MIDI 起音。只比较起音与音高，不比较参考结束，不使用音尾调整后的事件，不运行声学网络或解码。输入来自 `piano-release-semantics-v1` 的原始候选，保留事件索引、起音、音高、力度和全部物理区间。

固定同音高、起音误差不超过 50ms，使用已有 `evaluate_piano_acoustics.pairs(strict=False, offsets=False)` 一对一匹配，最大化匹配数并保持已有起音误差择配方法。不搜索阈值、不按曲调参，不用输出选择新的运行方案。`frame_inactive` 仅指起音后首次低 frame 之前没有成立持续激活的旧解码标记，不先验等于错误起音。

首先在全候选的一对一匹配中，分别统计 `frame_inactive` 和其他候选的数量、匹配数、未匹配数及匹配比例；保留逐曲结果。然后只排除 `release_reason == 'frame_inactive'` 的候选，重新执行同一匹配，报告整体及逐曲 precision、recall、F1，以及宏平均。所有其他候选逐字段原样保留。

“真起音损失”分开报告：移除候选中原本匹配的数量；两方案净匹配数差；参考身份从已匹配变为未匹配的数量及反向变化；剩余候选从未匹配变为匹配的数量。因为一对一匹配可能重新分配，不把“移除的旧匹配候选数”直接等同于净召回损失。具体配对只保存本地研究产物，不进入应用。

《樱花草》只读取同一已冻结原始事件的原因分类与数量，不读取 Reference 或任何参考音尾，不匹配、不计分。全部结果保存在忽略目录 `test-data/piano-inactive-onsets-v1`，保留规则、脚本、匹配代码、输入身份和产物哈希。本轮不更改应用、不发行权重、不把探索结果自动变成删除规则。
