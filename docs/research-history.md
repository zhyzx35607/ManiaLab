# 历史开发与研究导航

以下条目保留原阶段结论。组件曾在历史包中提供，不代表当前 Release 仍包含；当前范围见[乐器采音选择](instrument-choices.md)。研究结果与默认应用行为分开记录。

**开发测试版 `0.1.0-alpha.6-dev.2`**：在段落与声部表达流程上，加入已有声轨导入、可选钢琴专用采音、和弦减层保留起音，以及手动“连续起音优先”表达；重建音频程序并校验源码与包内模型身份。下载入口为 [开发测试包](https://github.com/zhyzx35607/ManiaLab/releases/tag/v0.1.0-alpha.6-dev.2)。这是对照测试版本，自动对音、复杂鼓音与LN音乐表达仍未完成验收，研究中的YourMT3伴奏模型和未通过对照的训练权重没有启用。常规alpha.5仍保留，原段落流程说明见 [采音与段落表达修订](music-first-revision.md)。

**dev.3 新增[可选贝斯与其他伴奏采音](instrument-worker.md)**：Tsumugi 专用CPU组件随完整包提供，默认关闭；适用于四／六声部分离或已导入的贝斯、其他伴奏轨。另一个开关允许有来源记录的模型预测音尾参与LN，默认只用起音。吉他、人声继续原引擎。已经完成两权重、两种音尾模式的真实便携前向和缓存核对；全曲18份编排结果及仍存在的主次、量化问题见[全曲对照](tsumugi-fullsong-results.md)。自动音色重分组尚未启用，见[真实结果](instrument-refinement-results.md)。这仍是开发测试版，不能视为音乐质量已验收。

**起音来源修复**：曲中窗口开始前就在持续的声音，不再无条件写成新按键；歌曲开头已发声的区间单独保留。完整156份输入重放说明，直接删掉所有无起音标志的事件会伤到真实开头音，因此采用明确的输入边界策略，保留原始预测与排除原因。结果和仍存在的漏采见[完整复核](tsumugi-onset-provenance.md)。dev.3保留原草稿，相关修复并入dev.4。

**源码研究进展**：已用真实 Mapperatorinator 音频／事件序列完成两轮 6–10K LoRA 实验，修正跨窗 LN 状态、训练／推理条件和模型轨道被覆盖的问题，增加混音／六声部同步试听对照。自由生成尚无稳定收益，10K Hybrid 对照出现 LN 退步，因此未启用研究权重；详见 [音频事件微调记录](mapper-audio-research.md)。

**已有声轨导入**：可直接选择 Nova 等工具导出的鼓、钢琴等声轨，保留原曲时钟，逐乐器采音、分段和试听。支持部分声部，检查长度、缓存身份及失败时旧结果保留；见 [已有声轨使用说明](provided-stems.md)。作者《樱花草》的声部与成品对照、实际训练失败及不足见 [专项研究记录](sakura-source-research.md)。此功能从dev.2测试包开始提供。

**LN 规划研究**：增加无新起音处的独立放手、全曲占轨求解和异常红线校验，重新训练7898份有效谱的条件表达模型；长LN和声部归属仍未过关，权重继续禁用。实际生成、逐曲退步和限制见 [放手规划对照](release-planning-research.md)。

**可选钢琴采音**：dev.2测试包内置默认关闭的钢琴专用入口，只作用于独立钢琴声轨；使用便携 ONNX 运行时，记录音尾依据，阻止把模型截断自动当作 LN 放手。真实钢琴演奏、《樱花草》和运行一致性对照见 [专项记录](piano-acoustic-research.md)。分离输入同时改为浮点音频并修复两级缓存失效，见 [输入审计](raw-pcm-input-audit.md)。这些改动不代表完整制谱已验收。

**声部表达修正**：允许复音和弦以较少层数保留起音，修复超容量时整组被省略的问题，并调整主声部偏好与对音证据的关系。已在同一份六声轨输入上完成6–10K全曲导出检查；详细结果与尚未解决的问题见[起音组与表达层数](chord-expression-research.md)。

**伴奏转录对照**：在原Nova浮点伴奏轨上运行专用转录，完成6–10K全曲选音、定轨及导出比较；补齐强制截断/未决音尾不能自动形成LN的保护，并修正真实弦乐评测漏算跨界长音的问题。钢琴主次和LN表达仍需验证，新伴奏模型尚未进入应用；见[实际编排记录](accompaniment-transcription-research.md)。

**其他乐器采音**：已实际运行 Tsumugi 的贝斯、吉他、人声及其他乐器权重；[完整 100 份吉他／人声结果](tsumugi-guitar-vocal-results.md)显示吉他误采减少但漏音增加，人声两套标注结果一升一降。[候选模型及状态](other-instrument-model-survey-2026-11-10.md)、[35 份弦管乐比较](instrument-extension-results.md)、[ROSVOT 人声退步结果](vocal-transcription-results.md)均保留。开发代码另修正了[起音校准挤在一起和重弹拖尾](basic-pitch-attack-boundary-fix.md)，但完整音符区间仍未整体改善，没有据此发布完成版。

**新增专用模型实测**：已下载并比较小提琴STRAdi、贝斯FiloBass、萨克斯FiloSax及PESTO音高辅助；固定录音的结果未支持替换现有方案，见[模型状态与实测依据](specialist-instrument-models-2026-11-10.md)。源码另修复[钢琴重弹截尾误当LN放手](piano-reattack-boundary.md)，保留起音并公开整曲表达的副作用；这项改动尚未进入旧下载包。

**吉他专用模型对照**：两份新权重×60份完整录音和独立复算已完成。FL模型起音F1为89.36%、完整区间68.81%，高于现有管线73.17%／48.74%；区间仅59份可评，训练重叠未认证，见[完整结果及退步项](hf-guitar-specialists-results.md)。dev.4加入默认关闭的[吉他专用入口](guitar-specialist.md)，已完成实际浮点声轨和源码HTTP整链对照；模型预测音尾须另行开启。采音指标不代表最终LN质量。

**弦管乐专用对照**：[Tsumugi 完整 35 输入三方结果](tsumugi-urmp-results.md)显示起音和完整区间整体改善，混音漏采减少；中提琴等局部起音仍不如 YourMT3。继续用原 Nova 全曲声轨检查实际编排，并准备[音色分组模型](instrument-refinement-protocol.md)对照；音符指标不等于 LN 音乐验收。

**可选连续起音表达**：逐段声部方案可选择“连续起音优先，组尾可延长”，处理钢琴等敲击序列的相互拖尾。自动推荐保持原行为；新主次/长短建议的两轮全曲结果包含鼓取舍退步，详见[表达对照](articulated-expression-research.md)。

**钢琴内部声部研究**：已完成重叠音尾的符号分组适配、77份留出乐谱评价和13项6–10K导出；持续声部识别部分改善，但正常音长、跨小节连续性和上下文稳定性仍不足，未启用应用默认。详见[实际训练与导出](piano-stream-research-2026-11-09.md)及[分段构图修复对照](piano-stream-context-research-2026-11-09.md)。

**持续音数据与声部训练**：已用独立持续事件表示重建136份train/validation源，并完成重叠音尾增强训练；踏板控制有所恢复，交叉旋律与谱表分类仍有退步，研究权重未启用。见[延音线审计](piano-bar-identity-research-2026-11-09.md)和[重叠训练结果](piano-source-event-overlap-2026-11-09.md)。相同1557个《樱花草》钢琴候选的[三权重连接对照](piano-audio-events-2026-11-09.md)已生成原音回放与局部图，尚不能证明稳定旋律或LN质量。另已修复[切段导致组尾误判](piano-articulation-context-2026-11-09.md)。

**后继起音组对照**：在原音符不变的前提下，限制每个来源音只选一组后续起音。重叠模型的模拟踏板误连减少，但复杂验证输入丢失了正确连接，仍未启用；见[解码结果与退步项](piano-successor-decode-2026-11-09.md)。

**后继排序训练**：完成四轮辅助排序训练与逐连接配对核验；重叠输入的解码指标局部提高，但正常输入、交叉旋律和踏板控制仍有退步，新权重没有接入应用。详见[训练结果与未采用原因](piano-successor-ranking-2026-11-09.md)。

**同刻错声部训练**：增加同一时刻已知错声部的排序监督，完成四轮和双基线对照；同刻误连减少，但交叉旋律漏连及重叠和弦完整性退步，继续不启用。详见[本轮改善与退步](piano-same-tick-ranking-2026-11-09.md)。

**更晚候选竞争训练**：仅为有可靠较早后继的同part未知候选增加辅助排序，完成四轮与逐边核验；raw指标局部提高，但完整真组和交叉旋律退步，更晚候选竞争也未改善，研究权重继续禁用。见[训练结果及上下文诊断](piano-later-ranking-2026-11-09.md)和[证明范围与覆盖](piano-later-negative-coverage-2026-11-09.md)。

**排序权重诊断**：保存预测的独立重算确认新负组压低原目标的绝对 logit 梯度权重，但不能认定训练退步原因；见[公式、配对统计和限制](piano-ranking-weight-diagnostic-2026-11-09.md)。

**独立辅助项对照**：保留原目标权重、单独训练可证更晚负组后，模拟踏板部分改善，但交叉旋律、部分完整和弦及错误后继竞争仍未通过预定条件；继续不启用。见[四轮结果及不采用原因](piano-separate-later-ranking-2026-11-09.md)。

**原音与标签核查**：补充[极短高音的波形、频谱和激活对照](piano-attack-evidence-2026-11-09.md)，区分潜在泛音混淆与已观测音尾；另定位[同刻错声部连接及监督覆盖缺口](piano-successor-label-audit-2026-11-09.md)。这些诊断尚未成为自动删音或新LN规则。

**原声频带对照**：完成47个固定候选的原声、三窗频谱及模型激活检查，发现能量增长和共享分音同样覆盖真实叠奏，不能据此自动删音；修正测量中的窗口边界误差并保留不可测状态。见[实际结果与限制](piano-band-evidence-2026-11-10.md)。

**独立声源对照**：83组真实单音叠加与8组同幅度补充定位到弱高音叠奏漏采和延音重复预测；提高总增益没有减少漏采，额外预测增多。已保存波形、频谱与全部检测结果，尚未得到可启用的修复。见[结果与下一步方向](piano-isolated-controls-2026-11-10.md)。

**钢琴模型对照**：Transkun 在11段实录中均提高起音F1，但91份声源控制新增17个漏采，实录也有20个新增遗漏；完整 Nova 钢琴轨仍存在叠加音分歧，未替换应用模型。按键音尾、踏板延音及原声检查见[完整结果与限制](piano-transkun-research-2026-11-10.md)。

**分窗丢音修复研究**：把已识别起音与音尾完整性分开保存，完整重放103份输入后找回两处实录丢音，未增加已知多采；Nova另保留两个音尾未决提案。去重仍有边界局限，未直接启用，见[修复结果](piano-onset-preservation-2026-11-10.md)。

**真实声学适配**：已完成两轮钢琴起音层训练和独立复算。验证仅减少1个额外起音，51个漏音未改善；原声与逐事件检查还发现移除假起音后，前一音尾反而延长约0.85秒。研究权重未启用，见[完整结果与音尾交换](piano-onset-head-research-2026-11-10.md)。

**起音与持续状态联合训练**：两轮双头适配仍未减少漏采，且新增音尾退步；逐参考保护门槛拒绝新权重，保留原模型。完整重放、真实梯度、原声图和逐音对照见[结果及未采用原因](piano-joint-head-research-2026-11-10.md)。

**细分鼓音色研究**：原float全曲复现ADT_STR的重复和未结束问题，已核验PCM与解码并保存原声图。核对历史后撤回重复语法方案，停止未完成的MDB扩展回归；第4列多数差异涉及音色归类，不能只看hi-hat匹配数。见[结果与路线纠偏](drum-adt-str-research-2026-11-10.md)。

**OaF鼓模型对照**：已完成作者分轨与23份真实鼓录音，另核验历史前处理和音色分类口径。部分误报减少，同时有明显漏音；《樱花草》第4列表现退步，不替换默认采音。见[完整结果](oaf-drums-research.md)。

**多乐器身份修复**：修复研究伴奏候选丢失乐器标签，导致跨乐器去重、长短表达及旋律建议互相干扰的问题。完成原全曲6–10K回归；容量竞争仍会挤掉其他声部，标签也不等于真实音色，见[实际变化与限制](instrument-identity-research.md)。未默认启用YourMT3。

**按类别设置段落表达**：已有模型类别的候选可逐段分别选择持续音、连续起音、起音或不采，默认继承原声部方案；支持保存、项目重开和实际生成。默认采音未因此获得音色识别能力，见[使用与验证范围](instrument-expression-controls.md)。
