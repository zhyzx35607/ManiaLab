# 真实乐器混合的力度干扰对照

在前一轮结果之后、此次推理之前固定本协议。使用已有URMP冻结0–40秒输入：
12-1-vn/12-3-vc（小提琴/大提琴），31-1-tpt/31-3-hn（小号/圆号）。
保留原音、原单轨转录查询和所有类别内GM假设，既有错采、未知尾都不删除。
来源声部是实验中已知的分轨信息，不声称模型从混音识别出了这个身份。

每组固定五个音频条件：A+B、A衰减12dB+B、A+B衰减12dB、仅A、仅B。
混合只做原PCM浮点线性相加，不归一化、不裁幅、不重采音。输出仍查询A/B
全部音符，哪怕该音轨在当前条件被完全关闭。记录峰值及超过1的样本数。
使用与首轮相同固定velocity模型、显式program假设、8秒窗、CPU2/1线程。

报告每个来源查询的自身衰减响应、另一来源衰减时的变化，以及关闭自身后
的输出。保存全部logits与原索引，不选择最佳program，不靠听感挑时间窗口。
这些指标揭示混合干扰，不是主旋律识别率；关闭自身后有非零velocity也不能
直接当误报，因为模型没有音符存在分类。原查询本身可能错采，不能将任何
非单调响应都解释为真实音符力度错误。

同音高重叠、谐波关系和其他音高的干扰需要分开分析。参考标注只允许做独立
评分，不送入此次模型、不纠正原查询。任何进一步改善都保留旧结果作对照。
