# ManiaLab 0.1.0-alpha.6-dev.21

Windows x64 开发测试版，发布范围为 `core` profile。版本号、源码 tag、包内版本和
验证报告必须一致；本说明只描述 dev.21，不改写历史 Release。

## 本版更新

- 成功重分析会清除按旧段落范围生成的外部编排计划；重分析失败时，旧分析与计划继续保留。
- 候选音符编辑在量化后若起点、终点与轨道均未变化，会拒绝该操作，避免无意义地创建候选并消耗历史容量。
- 编辑请求按候选的持久唯一 ID 校验；旧候选被淘汰后，即使新候选复用了相同时间戳和列表位置，延迟请求也不会改到新谱面。仍开着旧版页面时需刷新后再编辑。
- 候选切换只恢复与当前分析身份一致的段落表达方案；边界已变更时清除过期草稿，避免下次生成使用旧方案。
- 解码预览 WAV 完整写出后才替换目标。Windows 遇到短暂读句柄占用会有限重试；持续锁定时保留旧预览并返回错误，若没有旧预览，后续仍可重新解码。此修复不会主动修复旧版留下的损坏文件。
- Core 发布构建实际使用的 `requirements-lock.txt` 会计入 portable manifest 的源码指纹；锁文件身份帮助核对构建输入，不代表依赖许可或Standard/Extended构建已验证。
- Release collector 拒绝所有 profile 的 ZIP 在 `_internal/models` 下携带未声明模型文件，防止 Core 包借自洽清单引入未来权重。
- 明确公开 Windows Release 仅支持 Core profile；本地 Standard/Extended 构建不代表已验证或支持。

这些变更修复计划来源、候选编辑、段落方案和预览文件边界，不改变采音或编谱算法，不证明音符准确率、Timing、
LN 音尾或音乐质量有所提升。

## 发布范围

- 仅发布 Core profile；包内固定 Basic Pitch 模型及其运行时。
- 本包不含 Demucs 四/六声部分离 checkpoint、Beat This 节拍模型、钢琴专用 ONNX、吉他
  FL、Tsumugi 贝斯/伴奏或其它非 Core checkpoint。
- Standard 与 Extended profile 未由本版发布流程验证，不属于本次公开支持范围。
- 用户音频、参考谱、下载语料、本地研究权重和逐曲研究产物不进入源码提交或便携包。

Demucs checkpoint 的单独再分发授权仍未核实；dev.21 Core 包不分发这些 checkpoint。

## 验证边界

发布必须由精确 tag 的 Windows workflow 完成测试、Core 便携 EXE、离线 Unicode 路径、媒体
播放与切换、关停及验证证据收集；还需独立核对最终 ZIP 的 CRC、重复条目、包内版本与
manifest、SHA256SUMS 和机器验证报告。只有这些检查通过后才发布对应资产。

合成测试与便携验证不构成真实歌曲采音、Timing、osu! 实际试打或玩家盲评。对音清楚、声部
和段落表达、6–10K/LN 实际手感的长期音乐质量目标仍未完成验收。
