# ManiaLab 0.1.0-alpha.6-dev.23

Windows x64 开发测试版，发布范围为 `core` profile。版本号、源码 tag、包内版本和
验证报告必须一致；本说明仅描述 dev.23，不改写历史 Release。

## 本版更新

- 图表快照事务回滚恢复或提交后备份清理失败时，任务会报告仍需人工处理的恢复路径；已提交的项目状态继续保持已提交结果。
- 段落书签导入与 OSU/OSZ 导出使用与音符相同的半毫秒舍入规则，避免正负半毫秒边界在往返中偏移。
- 候选切换请求绑定 `candidate_id`；请求中的候选已过期、被裁剪或与索引不匹配时会被拒绝，不会误选列表中的另一个候选。
- 声轨输入快照清理失败会在任务结果和关停诊断中报告残留路径，同时保留原有操作或取消错误。
- 过期的手动段落表达草稿不能再保存为空方案；候选历史保留，重新建议后可继续编辑。
- JSON/OSU/OSZ 导出链接和图表试听请求绑定当前显示的候选 ID，防止旧页面操作到另一候选。

这些改动不改变采音、Timing 拟合或编谱算法，也不代表音符准确率、LN 音尾或音乐质量有所提升。PR #252 的 recent 项目加载竞态修复尚未纳入此发布候选，待其完整浏览器套件与 Windows CI 验证后再决定是否纳入。

## 发布范围

- 仅发布 Core profile；包内固定 Basic Pitch 模型及其运行时。
- 本包不含 Demucs 四/六声部分离 checkpoint、Beat This 节拍模型、钢琴专用 ONNX、吉他 FL、Tsumugi 贝斯/伴奏或其它非 Core checkpoint。
- Standard 与 Extended profile 未由本版发布流程验证，不属于本次公开支持范围。
- 用户音频、参考谱、下载语料、本地研究权重和逐曲研究产物不进入源码提交或便携包。

Demucs checkpoint 的单独再分发授权仍未核实；dev.23 Core 包不分发这些 checkpoint。

## 验证边界

本版须由精确 tag 的 Windows workflow 完成测试、Core 便携 EXE、离线 Unicode 路径、媒体播放与切换、关停及验证证据收集。发布前还须独立核对最终 ZIP 的 CRC、重复条目、包内版本与 manifest、SHA256SUMS 和机器验证报告。以上验证通过前，不发布对应资产。

合成测试与便携验证不构成真实歌曲采音、Timing、osu! 实际试打或玩家盲评。对音清楚、声部和段落表达、6–10K/LN 实际手感的长期音乐质量目标仍未完成验收。
