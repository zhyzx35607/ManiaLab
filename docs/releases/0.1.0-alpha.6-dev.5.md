# ManiaLab 0.1.0-alpha.6-dev.5

Windows x64 开发测试版，基于合并后的 GitHub `main`。这是阶段性功能包，不代表长期音乐质量目标已经达成。

## 新增

- 导入参考谱中的 Kiai 状态切换，并转换为可编辑的段落边界提示。Kiai 和书签都不被当作主歌／副歌识别。
- 在表达设置中逐段启用“连续人声乐句”，并调整该段候选选择比例。该比例是候选选择上限，不是全谱 LN 配额或音频人声置信度。

## 修复与打包

- 失败的文件导入会清理本次刚创建的未完成项目，不影响已有项目。
- Windows 便携构建、PyInstaller 工作目录、ZIP 和校验文件均按唯一构建 ID 隔离；不会覆盖既有 dev.4 包或其通用校验文件。

## 范围与限制

- 人声候选尚未完成对照 Nova 人声音轨的逐段核验；候选不等于已确认的人声身份，采音指标也不等于 LN 音乐性。
- 结构提示不自动判定段落功能；Timing、真实声部清晰度、起音与 LN 表达仍需听音和 osu! 试打。
- 研究权重保持默认关闭。测试和便携程序验证只证明代码与打包流程，不证明整谱质量超过 Mapperatorinator。

## 发布验证

Release 附带与本 ZIP 文件名对应的 `*-SHA256SUMS.txt`。Windows CI 的完整测试、离线便携 EXE 和关停验证通过后，才发布本版本。
