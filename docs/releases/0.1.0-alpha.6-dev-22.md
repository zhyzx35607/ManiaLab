# ManiaLab 0.1.0-alpha.6-dev.22

Windows x64 开发测试版，发布范围为 `core` profile。版本号、源码 tag、包内版本和
验证报告必须一致；本说明只描述 dev.22，不改写历史 Release。

## 本版更新

- 分析任务取消后，如果私有音频快照无法删除，任务会报告清理失败和可恢复路径；普通取消仍返回取消状态，且不会提交旧任务的项目状态。
- 图表工作区快照写入或替换失败时，即使临时文件清理也失败，错误仍保留原始失败原因并附恢复路径；快照发布后的清理失败同样报告路径。

合成回归另外覆盖段落边界变化后切回旧候选、区域重写、候选编辑、来源证据与 JSON/OSU/OSZ 导出的往返一致性。这些变更改进资源故障的可见性与恢复信息，不改变采音、Timing 或编谱算法，也不表示音符准确率、LN音尾或音乐质量有所提升。

## 发布范围

- 仅发布 Core profile；包内固定 Basic Pitch 模型及其运行时。
- 本包不含 Demucs 四/六声部分离 checkpoint、Beat This 节拍模型、钢琴专用 ONNX、吉他
  FL、Tsumugi 贝斯/伴奏或其它非 Core checkpoint。
- Standard 与 Extended profile 未由本版发布流程验证，不属于本次公开支持范围。
- 用户音频、参考谱、下载语料、本地研究权重和逐曲研究产物不进入源码提交或便携包。

Demucs checkpoint 的单独再分发授权仍未核实；dev.22 Core 包不分发这些 checkpoint。

## 验证边界

本版须由精确 tag 的 Windows workflow 完成测试、Core 便携 EXE、离线 Unicode 路径、媒体
播放与切换、关停及验证证据收集；发布前还须独立核对最终 ZIP 的 CRC、重复条目、包内版本与
manifest、SHA256SUMS 和机器验证报告。以上验证通过前，不发布对应资产。

合成测试与便携验证不构成真实歌曲采音、Timing、osu! 实际试打或玩家盲评。对音清楚、声部
和段落表达、6–10K/LN 实际手感的长期音乐质量目标仍未完成验收。
