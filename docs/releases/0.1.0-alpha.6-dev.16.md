# ManiaLab 0.1.0-alpha.6-dev.16

Windows x64 开发测试版。dev.16 将便携包源码快照更新到包含 PR #84 的当前
`main`；该 PR 增加了冻结输入上的表达取舍静态审计脚本与研究文档。

## 本版范围

- `scripts/summarize_expression_tradeoffs.py` 是源码仓库中的独立研究 CLI，只读冻结的
  《樱花草》分析与选择 JSON，不运行模型、选择器或音频处理，不读取 Reference。
- 本次只同步版本、下载入口与发布说明；不改变应用运行逻辑、默认采音行为、模型或安装包内的推理路径。
- 用户音频、参考谱、下载语料、本地研究权重、逐曲标签及其他本地研究产物不进入源码提交或便携包。
- 固定模型随 Windows 包提供；来源、许可与已知限制见 `THIRD_PARTY_NOTICES.md`。
  Demucs 预训练 checkpoint 的单独再分发授权尚未核实。

## 限制

- 本版不代表采音准确率、Timing 或音乐质量提升。
- 人工原声听审、候选标签复核及 osu! 试打仍待完成。静态候选审计不判断声源身份、
  可闻性或音乐价值，也不估算可以无冲突增加的 LN。
- 发布附件中的机器验证报告记录 Windows 构建、软件和便携运行检查；其合成音频夹具
  不构成真实歌曲的音乐验收。

## 验证

发布 tag 与该版源码版本一致。完整本地测试、Windows tag CI、包内 EXE/模型身份、
ZIP 完整性、资产 digest 及精确 source commit 见本版附件
`ManiaLab-0.1.0-alpha.6-dev.16-validation.json` 和项目进度记录。
