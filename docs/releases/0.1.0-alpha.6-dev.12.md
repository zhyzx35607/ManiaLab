# ManiaLab 0.1.0-alpha.6-dev.12

Windows x64 开发测试版。dev.12 用于让 Windows 便携包源码快照重新对齐
包含 PR #71、#72、#73、#74 及本版本准备变更的当前 `main`。

## 本版内容

- 源码包含《樱花草》冻结候选差异听审包构建器、标签导入校验及覆盖汇总工具。
  它们是本地研究辅助 CLI，不属于 Windows 应用运行时功能。
- 听审音频、参考谱、模型权重、逐曲标签及其他研究产物保留在本机 ignored 目录，
  不进入源码提交或 Windows 便携包。
- 不改变应用运行逻辑、默认采音行为或模型权重；本次重打包用于使发布源码快照与
  当前 `main` 一致。

## 功能范围与限制

- 本版发布不代表采音准确率、Timing 或音乐质量提升。人工原声听审、标签复核及
  osu! 试打仍待完成；自动检查与候选定位不代替声音判断。
- Demucs 代码的 MIT 许可不覆盖预训练 checkpoint；随包模型的单独再分发授权尚未核实。
  详情见 `THIRD_PARTY_NOTICES.md`。
