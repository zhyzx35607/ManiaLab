# ManiaLab 0.1.0-alpha.6-dev.14

Windows x64 开发测试版。dev.14 重新打包对齐合入 PR #79、#80 后的当前
`main`。相对 dev.13，源码快照增加发布验证记录和冻结输入上的起音保留账本
研究 CLI、测试与文档；不改变应用运行逻辑、默认采音行为或模型。

## 本版范围

- 起音保留账本只读冻结的《樱花草》10K JSON，用于汇总候选进入定轨与被省略的情况。
  它不是应用功能，不运行模型或音频处理，也不计算准确率、置信度或音乐质量。
- 用户音频、参考谱、模型权重、逐曲标签及其他研究产物保留在本机 ignored
  目录，不进入源码提交或 Windows 便携包。
- 此次重新打包用于让版本标签和 Windows 便携包源码快照对应本次发布的主线提交。

## 限制

- 本版不代表采音准确率、Timing 或音乐质量提升。人工原声听审、标签复核及
  osu! 试打仍待完成；自动检查与候选定位不代替声音判断。
- Demucs 代码的 MIT 许可不覆盖预训练 checkpoint；随包模型的单独再分发授权尚未核实。
  详情见 `THIRD_PARTY_NOTICES.md`。

`compileall -q manialab scripts tests`、版本导入和 `git diff --check` 通过。
PR 的 Windows `verify`、合并后的 Windows tag CI、便携包独立校验和 GitHub
Pre-release 尚待完成。只有这些步骤通过后，才把 ZIP 称为已验证发布包。
