# ManiaLab 0.1.0-alpha.6-dev.20

Windows x64 开发测试版，发布范围为 `core` profile。版本号、源码 tag、包内版本和
验证报告必须一致；本说明只描述 dev.20，不改写历史 Release。

## 本版更新

- 候选编辑事件保存在项目级哈希链中，避免每个候选重复保存相同编辑历史；载入与保存时
  校验链结构和事件摘要，并将旧版内嵌编辑记录迁移到新存储格式。
- 结构化生成使用经过候选来源过滤的候选与乐句证据；旧项目中过时的乐句支撑 ID 会在
  生成和导出时按当前候选协调。
- Windows 项目状态文件遇到短暂读取锁引起的 `PermissionError` 时有限重试原子替换；
  超出重试窗口的持续错误仍正常报告。

这些变更修复工程可靠性与来源追溯，不改变采音或编谱算法，不证明音符准确率、Timing、
LN 音尾或音乐质量有所提升。

## 发布范围

- 仅发布 Core profile；包内固定 Basic Pitch 模型及其运行时。
- 本包不含 Demucs 四/六声部分离 checkpoint、Beat This 节拍模型、钢琴专用 ONNX、吉他
  FL、Tsumugi 贝斯/伴奏或其它非 Core checkpoint。
- Standard 与 Extended profile 未由本版发布流程验证，不属于本次公开支持范围。
- 用户音频、参考谱、下载语料、本地研究权重和逐曲研究产物不进入源码提交或便携包。

Demucs checkpoint 的单独再分发授权仍未核实；dev.20 Core 包不分发这些 checkpoint。

## 验证边界

发布必须由精确 tag 的 Windows workflow 完成测试、Core 便携 EXE、离线 Unicode 路径、媒体
播放与切换、关停及验证证据收集；还需独立核对最终 ZIP 的 CRC、重复条目、包内版本与
manifest、SHA256SUMS 和机器验证报告。只有这些检查通过后才发布对应资产。

合成测试与便携验证不构成真实歌曲采音、Timing、osu! 实际试打或玩家盲评。对音清楚、声部
和段落表达、6–10K/LN 实际手感的长期音乐质量目标仍未完成验收。
