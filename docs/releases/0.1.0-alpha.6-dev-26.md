# ManiaLab 0.1.0-alpha.6-dev.26

Windows x64 Extended profile 公开试用预发布，包含完整 Extended 能力，供用户下载体验。此版保留 dev.25 的四种一键制谱预设与完整声部模型支持。

## 变更

- 精简主要分析界面，批量入口与高级采音、Timing 设置分区收起，常用的导入、分析、预设、生成操作更容易找到。
- 新增批量分析：一次选择 2–5 首音频，逐首导入为独立项目，最多同时处理 2 首；单曲失败与取消不会丢掉其它歌曲的结果。
- 批次界面显示每首状态并可打开项目；导入阶段可取消，任务轮询短暂失败会自动重试。任务 ID 已失效或连续连接失败时停止监控、解锁界面，并说明结果仍可到独立项目中检查。
- 保留均衡起步、纯起音（不写 LN）、偏持续音和节奏清晰四种一键预设。
- Extended 模型、worker 和 CPU 运行时范围以随包 `release-manifest.json` 为准；Mapperatorinator 权重仍由用户按需联网下载。

- 批量后端定向组合：`28 passed`；前端 JavaScript 语法检查与 `git diff --check` 通过。

## Extended 包验证

本版 Extended 便携包需要在精确 dev.26 源码上重新构建，并验证随包 manifest、ZIP 结构和该 EXE 的能力。此节只记录绑定到本版实际 Extended EXE 的便携检查；Core Windows workflow 的结果不代替 Extended 验证。资产清单、构建步骤和该 EXE 的结果会在打包完成后补记。

真实吉他、Tsumugi bass/other 音频专项需要冻结测试输入；这些 `test-data` 已按用户要求清理，本版不声称真实音频专项通过，也不复用旧版 EXE 或报告。合成烟测仅证明组件可加载、执行和身份匹配，不证明真实歌曲采音质量、Timing 或游戏手感。真实歌曲、osu! 试打及 6–10K/LN 手感仍由用户下载后实际体验。
