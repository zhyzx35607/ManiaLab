# ManiaLab 0.1.0-alpha.6-dev.26

Windows x64 Extended profile 公开试用预发布说明。已于 2026-11-24 从精确 tag 构建、验证并发布；真实歌曲质量和玩家手感仍需独立验收。

精确 tag：`v0.1.0-alpha.6-dev.26`（commit `70a52a40a16d254b9c1092c6607fd7c1f07c85ab`）。组装 ZIP 为 `1,310,888,430` bytes，SHA-256 `53a940c3918d9e6bd45ff0959367b4f34042614bc4a4b8196a13942e1a25e4d2`。GitHub Release 将 ZIP 切成 12 个分片；附件中的 `.cmd/.ps1` 负责并行下载、重组、校验并在成功后删除分片。

## 变更

- 精简主要分析界面：批量入口与高级采音、Timing 设置收进折叠面板，让常用导入、分析、预设和生成操作更容易找到。
- 新增批量分析：一次选择 2–10 首音频，逐首导入为独立项目，最多同时处理 2 首；单曲失败与取消不会丢掉其它歌曲的结果。批次界面显示每首状态并可打开项目；导入阶段支持取消，任务轮询可从短暂请求失败中恢复。
- 新增“主声部：鼓、钢琴、人声、其他伴奏”方案。此方案使用六源 HTDemucs，输出四个指定声部；原有完整六声部模式仍可输出鼓、贝斯、人声、钢琴、吉他和其他伴奏。
- 增加纯键型预设，采用显式左右手/手指布局：6K `3+3`、7K `3+1+3`、8K `3+2+3`（可选 `4+4`）、9K `4+1+4`、10K `5+5`。本版只增加键型选择与定轨映射，不修改 LN 生成逻辑。
- 保留均衡起步、纯起音（不写 LN）、偏持续音和节奏清晰四种一键预设。
- 最大密度提升至 50 物件/秒。
- Extended 模型、worker 和 CPU 运行时范围以随包 `release-manifest.json` 为准；Mapperatorinator 权重仍由用户按需联网下载。

## 源码验证

本地完整 Python/API 回归通过：`D:\project\ManiaLab\.venv\Scripts\python.exe -m pytest -q`，结果为 **3659 passed, 164 skipped, 1 warning**（420.25 秒）。唯一 warning 是短 STFT 边界测试中 SciPy 对 768 点输入缩短 `nperseg` 的提示。Edge Playwright 全套 `npm run test:ui` 为 **81 passed**（3.1 分钟），包括最多十首批量导入、并行数上限为 2，以及切换 8K 键型后阻止导出旧候选的浏览器回归。配置、推荐、LN、候选编辑、导入路由与上游路由定向组为 **129 passed**；`node --check` 和 `git diff --check` 通过。PR #260 Windows run `45354141337` 已通过 Python/API、合成浏览器和 Core 便携检查；它不代替 Extended 包验证。

## 已完成的 Extended 包验证

- 精确 tag Python/API 回归为 `3659 passed, 164 skipped, 1 warning`；Edge Playwright 为 `81 passed`。Windows CI 同一 tag 通过源码/API 与合成浏览器检查，workflow 便携 profile 固定为 Core。
- 本版 Extended EXE 完成 20 项便携检查，覆盖启动、模型/能力清单、合成音频分析、预设生成、four-piano profile、六声部分析导出、重启、取消和错误恢复。退出后音频 worker 与 Tsumugi worker 均停止。
- ZIP 包含 7,624 个条目；CRC 检查通过。12 个分片重组后的 ZIP 与已验证本地文件大小、SHA-256 完全相同；下载/组装脚本通过本地分片端到端验证。
- 由于冻结输入已清理，本版没有重跑真实吉他音频探针或 Tsumugi EXE 级真实音频接口检查；完整聚合验证报告未生成。随包的验证附件区分已运行检查与未运行专项检查，不复用旧 EXE 报告。

当前下载脚本一次并行启动 12 个 `curl.exe`，页面显示分片完成数而非字节进度；中断的 `.download` 分片不会续传。若用户网络无法稳定访问 GitHub Release CDN，这种下载方式尤其难排查。后续发布应优先提供轻量 Core 和可选模型包；如继续分片，下载器需要字节级进度、有限并发、续传和磁盘空间预检。

本地 ZIP 展开后约 `2,714,858,795` bytes（2.53 GiB）。压缩文件体积中约 `85.3%` 属于随包 assets；其中大模型与独立 worker 重复携带的 CPU runtime 是优先审计项。是否共享运行时需验证启动、隔离和许可边界，不能直接删除。

六声部真实歌曲问题当前没有可复现样例，不能据本版声称已修复。合成烟测仅证明组件可加载、执行和身份匹配，不证明真实歌曲采音质量、Timing 或游戏手感。真实歌曲、osu! 试打及 6–10K/LN 手感仍待用户实际验收。
