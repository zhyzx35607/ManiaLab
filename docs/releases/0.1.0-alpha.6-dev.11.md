# ManiaLab 0.1.0-alpha.6-dev.11

Windows x64 开发测试版。dev.11 用于让版本标签和 Windows 便携包源码快照与合并
PR #67、#68、#69 后的 `main` 对齐。

## 本版内容

- 增加训练集表达音频听审导出标签校验与覆盖摘要工具；它验证冻结听审包和人工导出，
  不推断音符准确率、乐器身份或音乐质量。
- 本地听审音频、模型、用户数据和研究权重不进入 Windows 便携包。
- 不改变应用运行逻辑、默认采音行为或模型权重。

## 功能范围与限制

- 本版发布不代表采音准确率或音乐质量提升。起音、Timing、声部清晰度和 LN 表达仍需
  结合原声听检与 osu! 试打；CI 通过不代表音乐验收完成。
- Demucs 代码的 MIT 许可不覆盖预训练 checkpoint；随包模型的单独再分发授权尚未核实。
  详情见 `THIRD_PARTY_NOTICES.md`。
