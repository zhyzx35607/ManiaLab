# ManiaLab 0.1.0-alpha.6-dev.8

Windows x64 开发测试版。dev.8 从包含 PR #52 的 `main` 构建，目的是让发布 tag 与当时的主线源码一致。应用运行逻辑与 dev.7 相同；没有启用研究权重或加入新的采音行为。

## 本版内容

- 延续 dev.7 的便携包构建修复与现有功能范围。
- 主线包含本地连续人声乐句候选复核工具和协议；这套研究工具不属于运行时采音或自动谱面生成能力。
- 不修改用户数据、音频、模型权重或历史研究产物。

## 功能范围与限制

- Kiai 和书签是可编辑的段落边界提示，不识别主歌／副歌；连续人声乐句 LN 是逐段候选选择，不是人声身份识别或全谱 LN 配额。
- Nova 人声候选尚未完成逐段人工听审。起音、Timing、声部清晰度和 LN 表达仍需原声听检与 osu! 试打；CI 通过不代表音乐质量验收。
- Demucs 代码的 MIT 许可不覆盖预训练 checkpoint；随包模型的单独再分发授权尚未核实。详情见 `THIRD_PARTY_NOTICES.md`。

## 发布验证

仅在 dev.8 tag 的 Windows CI 完整通过并生成对应 ZIP、SHA-256 校验文件和便携验证报告后发布。CI 或产物未完成时，本版仍是待发布候选。
