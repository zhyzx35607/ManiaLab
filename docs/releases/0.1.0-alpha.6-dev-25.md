# ManiaLab 0.1.0-alpha.6-dev.25

Windows x64 Extended profile 公开试用预发布，提供完整 Extended 功能集供用户下载体验。此版不改写 dev.23 Core 或 dev.24 Release。

## 变更

- 增加均衡起步、纯起音（不写 LN）、偏持续音和节奏清晰四种一键预设。
- 纯起音预设同时关闭普通 LN 和跨音高乐句 LN。生成时全局 LN 比例为0会覆盖已有手动 phrase/sustain 表达及分段 LN 偏好；明确选择 `omit` 的声部仍保持省略。
- 主界面优先显示预设与生成操作；采音/LN、键型/手感和 LN 设计细节默认收起。
- Extended 模型、worker 和 CPU 运行时范围沿用 dev.24，完整能力以 ZIP 内 `release-manifest.json` 为准；Mapperatorinator 权重仍由用户按需联网下载。

## 验证范围

GitHub Windows workflow 仍按 `core` profile 运行。dev.25 Extended ZIP 从精确版本 tag 单独构建，并以随包 manifest、版本/源码身份、ZIP 结构和实际便携 EXE 检查作为该包的依据。Release 随附的版本专属验证摘要仅列出本次实际运行并绑定到该 Extended EXE 的检查。

真实吉他、Tsumugi bass 和 other 音频专项验证需要仓库本地冻结输入；这些 `test-data` 已按用户要求清理，本版不声称这些专项通过。合成烟测只能证明组件加载、执行和身份匹配，不证明真实歌曲采音质量。真实歌曲 Timing、osu! 试打及 6–10K/LN 手感仍由用户实际体验验收。
