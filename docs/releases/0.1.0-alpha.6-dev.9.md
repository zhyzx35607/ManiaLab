# ManiaLab 0.1.0-alpha.6-dev.9

Windows x64 开发测试版。dev.9 将发布源码快照重新对齐到包含 PR #55 的当前 `main`。应用运行逻辑与 dev.8 相同；没有启用研究权重或加入新的采音行为。

## 本版内容

- 源码主线新增本地人声候选人工标签的校验与覆盖汇总入口。该研究工具留在源码中，不属于 Windows 便携应用的运行时功能。
- 不修改用户数据、音频、模型权重或历史研究产物。

## 功能范围与限制

- Kiai 和书签是可编辑的段落边界提示，不识别主歌／副歌；连续人声乐句 LN 是逐段候选选择，不是人声身份识别或全谱 LN 配额。
- Nova 人声候选尚未完成逐段人工听审。起音、Timing、声部清晰度和 LN 表达仍需原声听检与 osu! 试打；CI 通过不代表音乐质量验收。
- Demucs 代码的 MIT 许可不覆盖预训练 checkpoint；随包模型的单独再分发授权尚未核实。详情见 `THIRD_PARTY_NOTICES.md`。

## 发布验证

发布 tag 必须精确指向当时的 `main` 提交，并通过 Windows tag CI。只有生成并复核对应 ZIP、SHA-256 校验文件和便携验证报告后，本版才算发布。
