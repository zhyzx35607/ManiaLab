# ManiaLab 0.1.0-alpha.6-dev.24

Windows x64 Extended profile 公开试用预发布，供用户评估完整功能集。此版不改写 dev.23 Core Release。

## 包内能力

- 四声部 Hybrid Demucs、六声部 HTDemucs 与 Beat This! 节拍模型。
- 钢琴回归 ONNX、吉他 FL ONNX，以及 Tsumugi bass/other 专用模型和独立 CPU worker。
- Basic Pitch、FFmpeg、CPU 推理运行时、Mapperatorinator 安装器与固定源码包；Mapperatorinator 权重由用户按需联网下载。
- 便携包完整能力以包内 `release-manifest.json` 为准。专用模型按各自选项启用；默认状态不会自动使用所有专用模型。

## 验证范围

发布前将从精确 dev.24 tag 源码构建 Extended ZIP，并检查包内版本/profile、源码与模型身份、ZIP 条目/CRC、便携 EXE 离线启动、4/6 声部分离、导出/重启、专用模型运行和关停。吉他、钢琴、bass、other 专用路径烟测仅使用确定性合成音频；这证明所选组件能加载、执行并报告预期模型身份，不证明真实音频转录质量。

仓库当前 GitHub Windows workflow 仍固定构建 Core；它不会生成本版 Extended ZIP，Core tag run 不应被解释为 Extended 包的 CI 验收。Release 附带的验证 JSON 记录对应 Extended 包的本地构建和实际便携 EXE 检查。

真实歌曲采音、Timing、osu! 试打、6–10K/LN 手感和玩家盲评仍未完成验收。用户音频、参考谱、下载语料和逐曲研究产物不进入源码或 Release。
