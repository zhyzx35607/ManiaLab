# ManiaLab 0.1.0-alpha.6-dev.15

Windows x64 开发测试版。dev.15 对齐当前 `main`，并更正打包范围说明：
Windows 便携包包含应用运行所需、经过哈希校验的固定模型；用户音频、参考谱、
下载语料、本地研究权重、逐曲标签及其他研究产物不进入源码提交或便携包。

## 本版范围

- 起音保留账本是冻结输入上的独立研究 CLI，不属于应用功能；它不运行模型或音频处理，
  也不计算准确率、置信度或音乐质量。
- 此次改动为版本和文档范围更正，不改变应用运行逻辑、默认采音行为或模型。
- 固定模型的来源、许可与已知限制见 `THIRD_PARTY_NOTICES.md`。Demucs 预训练
  checkpoint 的单独再分发授权尚未核实。

## 限制

- 本版不代表采音准确率、Timing 或音乐质量提升。人工原声听审、标签复核及
  osu! 试打仍待完成；自动检查与候选定位不代替声音判断。
- dev.14 tag 未发布；该 tag 和它的 CI 工件保留作历史记录，详见
  [dev.14 记录](0.1.0-alpha.6-dev.14.md)。
