# ManiaLab 0.1.0-alpha.6-dev.17

Windows x64 开发测试版。此版本将源码快照重新对齐发布时的 `main`，包括
PR #87 的序列先验研究评估优化及 PR #89 的 checkpoint 许可说明修订。

## 本版范围

- PR #87 批量编码 LN 互动窗口并优化分组验证运行时间；仅影响独立研究评估入口，
  不接入默认制谱。它不代表 LN 键型、采音准确率或音乐质量改善。
- 除版本、README 下载入口、文档索引和发布说明外，不改变应用运行逻辑、
  默认采音行为或推理模型。
- Windows 包继续包含 `beat-this-final0.ckpt`、`hdemucs_high_trained.pt` 和
  `htdemucs_6s.th`。Demucs checkpoint 的单独再分发授权仍未核实；来源、上游讨论、
  许可边界及已知风险见 `THIRD_PARTY_NOTICES.md`。本说明不构成授权或商业使用许可声明。
- 用户音频、参考谱、下载语料、本地研究权重、逐曲标签及其他本地研究产物不进入
  源码提交或便携包。

## 限制

- 本版没有真实歌曲的人工听审、Timing 验收或 osu! 试打；用户目前没有耳机。
- Windows CI 的合成音频只验证软件和便携运行，不构成音乐质量验收。
- 采音、声部和段落清晰度、6–10K/LN 表达仍是未完成的长期目标。

## 验证

发布 tag 必须与该版源码版本一致。测试、Windows tag CI、模型身份、ZIP 完整性、
资产 digest 与精确 source commit 以本版机器验证报告及 `docs/PROGRESS.md` 为准。
