# ManiaLab 0.1.0-alpha.6-dev.18

Windows x64 开发测试版。本版源码快照重新对齐 PR #92、#93、#94 合并后的
`main`。该版本只同步发布元数据，不增加模型或用户数据。

## 本版范围

- PR #92 修正分段 LN 倾向、最短 LN 和声部权重沿实际生成路径生效的问题，并将
  Basic Pitch ONNX 算子线程限制为 2、跨算子线程保持 1。
- PR #93 通过真实项目生成 API 和 `.osu` 导出回读覆盖分段表达设置；其夹具为合成分析，
  验证应用路径，不证明真实歌曲的采音或音乐质量。
- PR #94 记录一份冻结分析上的三种 10K 推荐生成诊断。诊断产物留在本机忽略目录，
  不进入源码或便携包；手动诊断拍线和吸附结果不代表 Timing 已验收。
- Windows 包继续包含 `beat-this-final0.ckpt`、`hdemucs_high_trained.pt` 和
  `htdemucs_6s.th`。Demucs checkpoint 的单独再分发授权仍未核实；来源、上游讨论、
  许可边界及已知风险见 `THIRD_PARTY_NOTICES.md`。本说明不构成授权或商业使用许可声明。
- 用户音频、参考谱、下载语料、本地研究权重、逐曲标签及其他本地研究产物不进入
  源码提交或便携包。

## 限制

- 本版没有完成 Timing、真实歌曲音乐质量或 osu! 实际试打验收。
- Windows CI 的合成音频只验证软件和便携运行，不构成采音准确率或音乐质量验收。
- 采音、声部和段落清晰度、6–10K/LN 表达仍是未完成的长期目标。

`compileall -q manialab scripts tests`、全部静态 JS `node --check`、版本导入和
`git diff --check`通过。Windows tag CI、便携包独立复核及 GitHub Pre-release 待完成。
