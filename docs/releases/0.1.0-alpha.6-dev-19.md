# ManiaLab 0.1.0-alpha.6-dev.19

Windows x64 开发测试版，发布范围为 `core` profile。版本号、源码 tag、包内版本和
验证报告必须一致；本说明只描述 dev.19，不改写历史 dev.18 Release。

## 本版更新

- 整曲、声部和钢琴激活缓存遇到损坏的 ZIP/CRC 数据时按缓存未命中恢复，避免缓存损坏
  阻断分析。
- 整曲与声部缓存写入唯一暂存文件，写入成功且未取消后再原子替换；取消或写入失败会
  清理暂存文件并保留原缓存。
- 声部激活缓存继续使用格式 v4，保留模型身份与推理版本字段，兼容此前有效的 v4 缓存；
  更早且缺少这些身份字段的缓存会安全未命中。

这些改动属于缓存可靠性，不改变采音或编谱算法，也不证明音符准确率、Timing 或音乐质量
有所提升。

## 发布范围

- 仅发布 Core profile；包内固定 Basic Pitch 模型及其运行时。
- 本包不含 Demucs 四/六声部分离 checkpoint、Beat This 节拍模型、钢琴专用 ONNX、吉他
  FL、Tsumugi 贝斯/伴奏或其它非 Core checkpoint。
- Standard 与 Extended profile 未由本版发布流程验证，不属于本次公开支持范围。
- 用户音频、参考谱、下载语料、本地研究权重和逐曲研究产物不进入源码提交或便携包。

Demucs checkpoint 的单独再分发授权仍未核实；dev.19 Core 包不分发这些 checkpoint。

## 验证边界

发布前要求精确 tag 的 Windows workflow 完成测试、Core 便携 EXE、离线 Unicode 路径、媒体
播放与切换、关停及验证证据收集；还需独立核对最终 ZIP 的 CRC、重复条目、包内版本与
manifest、SHA256SUMS 和机器验证报告。对应运行标识和资产摘要随 Release 验证资产及
`docs/PROGRESS.md` 记录。

合成测试与便携验证不构成真实歌曲采音、Timing、osu! 实际试打或玩家盲评。对音清楚、声部
和段落表达、6–10K/LN 实际手感的长期音乐质量目标仍未完成验收。
