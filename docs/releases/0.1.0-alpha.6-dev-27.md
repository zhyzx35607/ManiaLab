# ManiaLab 0.1.0-alpha.6-dev.27

Windows x64 Extended profile 公开试用预发布说明（发布准备中）。本版保持 dev.26 的产品功能，并减少 Windows 便携包里一份重复的 CPU runtime；不替换 dev.26 Release。

## 变更

- 基于 dev.26：6–10K osu!mania 本地制谱、四/六声部分离、four-piano 主声部、Beat This、钢琴 ONNX、吉他 FL、Tsumugi bass/other、2–10 首批量分析及四种制谱预设。
- Extended 打包构建在检查音频 worker 身份之后，比较主程序根目录 `_internal/torch_cpu.dll` 与隔离音频 worker 内的同名文件。大小和 SHA-256 完全相同才从**本次构建的主程序目录**移除根目录副本；两个隔离 worker 的运行库保持原样。Core profile 不做去重；运行库缺失或身份不符时保留，不根据文件名盲目删除。
- dev.26 已发布包保持不变。dev.27 使用精确版本 tag 重新构建自己的 Extended EXE 与 ZIP。

## 包与下载

精确 tag、单文件 ZIP 大小、SHA-256、GitHub Release 及最终验证报告将在精确 tag 构建和便携检查完成后补录。Release 将提供一个直接下载的 Windows x64 Extended ZIP，并附 SHA256SUMS 与验证摘要。

## 验证范围

构建通过条件包括 app/worker runtime 身份比较、`release-manifest.json` payload inventory、完整 ZIP CRC、精确文件清单、实际 EXE 的 four/six/four-piano 合成分离与导出、取消/错误恢复、关停以及 worker 子进程回收。还将验证未匹配或缺失 DLL 时构建逻辑保留应用副本，并保留两个隔离 worker 中的 runtime。

这些是 Windows 工程与合成输入检查，不代表真实歌曲采音、Timing、osu! 试打、6–10K/LN 玩家手感或音乐质量验收。
