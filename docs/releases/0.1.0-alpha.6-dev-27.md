# ManiaLab 0.1.0-alpha.6-dev.27

Windows x64 Extended profile 公开试用预发布说明。已于 2026-11-25 发布；本版保持 dev.26 的产品功能，并减少 Windows 便携包里一份重复的 CPU runtime。dev.26 Release 与资产保持不变。

## 变更

- 基于 dev.26：6–10K osu!mania 本地制谱、四/六声部分离、four-piano 主声部、Beat This、钢琴 ONNX、吉他 FL、Tsumugi bass/other、2–10 首批量分析及四种制谱预设。
- Extended 打包构建在检查音频 worker 身份之后，比较主程序根目录 `_internal/torch_cpu.dll` 与隔离音频 worker 内的同名文件。大小和 SHA-256 完全相同才从**本次构建的主程序目录**移除根目录副本；两个隔离 worker 的运行库保持原样。Core profile 不做去重；运行库缺失或身份不符时保留，不根据文件名盲目删除。
- dev.26 已发布包保持不变。dev.27 使用精确版本 tag 重新构建自己的 Extended EXE 与 ZIP。

## 验证范围

精确 tag Windows workflow run `45521432476` 成功：Python/API `3667 passed, 161 skipped, 1 warning`，Edge Playwright `82 passed`，并通过 Core 便携验证。独立 Extended EXE 检查通过：20 项 portable verifier、four/six 声部分析与导出、four-piano 合成分析/制谱/导出、取消与错误恢复、关停和 worker 子进程回收；ZIP CRC 与 `release-manifest.json` payload inventory 也通过。Release 附件中的验证 JSON 记录检查范围。

真实吉他音频探针和 Tsumugi 的 EXE 级真实音频接口检查没有在本版重跑，因为冻结音频样例已不存在。包内复用的 Tsumugi worker 与 dev.25 相同，并保留其四组既有真实音频 parity 记录；它们不能代替本版新的 EXE 检查，因此完整聚合验证报告未生成。

这些是 Windows 工程与合成输入检查，不代表真实歌曲采音、Timing、osu! 试打、6–10K/LN 玩家手感或音乐质量验收。
