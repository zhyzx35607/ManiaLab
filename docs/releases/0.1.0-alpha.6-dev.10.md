# ManiaLab 0.1.0-alpha.6-dev.10

Windows x64 开发测试版。dev.10 将源码快照对齐到包含 PR #63 和 #64 的 `main`。
PR #63 修复训练集听审包构建器对规范化音频文件名的误拒；PR #64 记录了本地听审包
的构建与校验结果。这些改动没有改变应用运行逻辑、默认采音行为或模型权重。

## 本版内容

- 源码包含训练集表达音频听审构建器与进度记录；实际听审包位于开发机忽略目录，
  不随 Windows 便携包分发。
- 不包含新模型、音频、用户数据或研究权重。

## 功能范围与限制

- 本版发布不代表采音准确率或音乐质量提升。起音、Timing、声部清晰度和 LN 表达仍需
  结合原声听检与 osu! 试打；CI 通过不代表音乐验收完成。
- Demucs 代码的 MIT 许可不覆盖预训练 checkpoint；随包模型的单独再分发授权尚未核实。
  详情见 `THIRD_PARTY_NOTICES.md`。

## 发布门槛

仅在此 tag 的 Windows CI 完整通过后发布。GitHub Release 应附 Windows ZIP、
对应的 SHA-256 校验文件和便携验证报告；实际测试数、产物哈希和验证范围以该报告为准。
