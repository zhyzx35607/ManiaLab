# ManiaLab 0.1.0-alpha.6-dev.13

Windows x64 开发测试版。dev.13 重新打包对齐包含 PR #76、#77 的当前
`main`。自 dev.12 以来的源码差异仅更新进度和发布记录，不包含应用代码变化。

## 本版范围

- 不改变应用运行逻辑、默认采音行为或模型权重。
- 用户音频、参考谱、模型权重、逐曲标签及其他研究产物保留在本机 ignored
  目录，不进入源码提交或 Windows 便携包。
- 此次重新打包用于让版本标签和 Windows 便携包源码快照对应本次发布的主线提交。

## 限制

- 本版不代表采音准确率、Timing 或音乐质量提升。人工原声听审、标签复核及
  osu! 试打仍待完成；自动检查与候选定位不代替声音判断。
- Demucs 代码的 MIT 许可不覆盖预训练 checkpoint；随包模型的单独再分发授权尚未核实。
  详情见 `THIRD_PARTY_NOTICES.md`。

## 发布验证

只有在 Windows tag CI、便携包离线运行和关停检查通过，并独立核对包内版本、
校验和及 GitHub 上传资产后，才会创建此版本的 GitHub Pre-release。具体测试结果、
工件位置和哈希将在验证完成后记录。
