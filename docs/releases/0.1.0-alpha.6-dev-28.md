# ManiaLab 0.1.0-alpha.6-dev.28

Windows x64 Extended 公开试用预发布版，包含 dev.27 的完整能力和本次批量制谱更新。下载单个 ZIP 后解压，运行 `ManiaLab.exe`。

## 主要更新

- 批量分析完成后，可一次选择键数、键型、制谱预设和密度，为所有分析成功的歌曲统一生成谱面。
- 生成结果可逐首下载 `.osz`，也可一次下载包含成功谱面的 ZIP。每首歌曲沿用自己的 BPM、Offset 和音频提前量；不稳定 Timing 需要明确确认，单首失败不会丢弃其他成功结果。
- “纯起音（不写 LN）”会在生成时强制关闭 LN。切换预设后，旧候选仍会保留供查看，但界面会显示旧候选的实际 LN 数，并在设置不一致时阻止误导性导出。
- 批量下载按候选 ID 绑定谱面，校验谱包中的音频身份，并在项目数据盘预检空间后分块创建 ZIP。
