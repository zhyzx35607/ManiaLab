# ManiaLab 0.1.0-alpha.6-dev.7

Windows x64 开发测试版。dev.7 修复便携包构建，不更改应用运行行为。

## 本版变更

- PyInstaller 的资源源路径和 `launcher.py` 入口改为仓库绝对路径，避免 spec 文件位于独立构建目录时把资源错误地解析到 spec 目录。
- 保留 dev.6 的 HTDemucs 固定 revision 镜像回退；每个来源仍校验预期字节数和 SHA-256，不关闭 TLS 校验。
- README 下载步骤改为指向 Releases 中最新已发布的 Windows ZIP，不再硬编码指向可能尚无 Release 资产的 tag。

## 功能范围与限制

- 本版没有应用运行逻辑或研究权重变化。
- Kiai 和书签是可编辑的段落边界提示，不识别主歌／副歌；连续人声乐句 LN 是逐段候选选择，不是人声身份识别或全谱 LN 配额。
- 起音、Timing、真实声部清晰度和 LN 表达仍需原声听检及 osu! 试打；CI 通过不代表音乐质量验收，也没有证据证明完整质量超过 Mapperatorinator。
- Demucs 代码的 MIT 许可不覆盖预训练 checkpoint；随包模型的单独再分发授权尚未核实。详情见 `THIRD_PARTY_NOTICES.md`。

## 发布验证

只在 dev.7 tag 的 Windows CI 完整通过后发布。Release 应附带 Windows ZIP、对应的 SHA-256 校验文件和便携验证报告；只有源码 ZIP/TAR 的 Tags 页面不是本项目的安装包发布页。
