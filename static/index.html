从音乐出发，逐步试谱

  1. 导入音频，点击「分析音频」。推理使用 CPU；界面显示实际耗时，再次分析会复用音高缓存。
  2. 切换「采音证据」试听。绿色表示检测到的有音高持续区间，橙色表示瞬态。深度分析后可切换鼓、贝斯、人声与伴奏分别试听；分离结果仍可能串音。
  3. 先在开头、中间和结尾试听拍线。新项目默认制谱提前量 22.5ms，与分析Timing的补偿一致；填 0 使用原始音频时间。可以粘贴分析Timing的 BPM / Offset；改 BPM 后也可点击重新估计 Offset。确认拍线后生成 10K。
  4. 生成后检查落线统计及采音；所有短键、LN 起点和尾端都量化到所选网格，量化可能向前或向后移动半个细分。落线不代表声音已采对。旧版候选需要重新分析并生成后才能导出。
  5. 已有谱面可直接严格定轨，无需重新采音。.osz 包会保留原始音频与支持的图片、音效文件。

本版包含四声部采音、跨音高人声长条和小型定轨先验；尚无端到端的 10K 制谱专训模型。复杂混音、歌声滑音和混响可能产生误检。结构校验通过只表示没有同轨重叠等错误，不代表音乐表达或难度已合格。
