从音乐出发，逐步试谱

  1. 导入音频，点击「分析音频」。推理使用 CPU；界面显示实际耗时，再次分析会复用音高缓存。
  2. 切换「采音证据」试听。绿色表示检测到的有音高持续区间，橙色表示瞬态。它们不代表已分离的乐器。
  3. 保留默认参数，先生成 10K。检查 LN 的开始、结束和占轨，再通过参数尝试其他布局。
  4. 先打开节拍器，在开头、中间和结尾试听拍线。必要时换 BPM 候选或手动输入；确认后生成并导出 .osz。
  5. 已有谱面可直接严格定轨，无需重新采音。.osz 包会保留原始音频与支持的图片、音效文件。

本版提供采音与编排工作流，尚未训练专用 10K 模型。复杂混音、歌声滑音和混响可能产生误检。结构校验通过只表示没有同轨重叠等错误，不代表音乐表达或难度已合格。
